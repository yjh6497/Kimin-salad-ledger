🐾 우리 병원 비서 키트
코드를 몰라도 돼요. 파일을 두 번 클릭하고, 시트 메뉴를 차례로 누르면 끝나요.

[들어 있는 것]
1_구글비서/   구글 시트 하나 + 텔레그램 봇 + 태블릿 화면 4개 코드 (직접 열 필요 없어요)
2_설치/       설치 파일 (맥: .command, 윈도우: .bat)
우리병원/     터미널 비서(Claude Code)가 일하는 병원 폴더. 작업 파일을 두 번 클릭하면 돼요.

[맥 순서]
1. 2_설치/1_처음설치_맥.command 를 두 번 클릭
   - "확인되지 않은 개발자" 창이 뜨면: 파일을 오른쪽 클릭 → 열기 → 열기
   - Claude Code 설치 + 홈 폴더에 '우리병원' 폴더 복사
2. 2_설치/2_구글비서_올리기_맥.command 를 두 번 클릭
   - Apps Script API 켜기(한 번) → 구글 로그인 → '우리 병원 비서' 시트가 열려요
3. 시트 위쪽 메뉴 「🐾 병원 비서」에서
   ① 처음 설정 → ② 병원 정보 넣기 → ③ 텔레그램 연결 → ④ 자동 실행 켜기
   (처음 누를 때 '권한 검토 → 계정 선택 → 고급 → 이동 → 허용'이 떠요. 내 계정에서 내 코드가 도는 거라 괜찮아요)
4. 텔레그램 봇 만들기: 텔레그램에서 @BotFather → /newbot → 이름 두 번 → 받은 토큰을 ③에 붙여 넣기
5. 홈 → 우리병원 폴더 → 01_블로그_초안.command 처럼 작업 파일을 두 번 클릭

[윈도우 순서]
같은 순서로 .bat 파일을 두 번 클릭. 우리병원 폴더는 C:\Users\내이름\우리병원 에 생겨요.

[텔레그램에서 쓰는 말]
오늘 / 대기 / 재고 / 재고 품목코드  ·  버튼이 오면 눌러서 승인·선택
버튼 메시지에 '답장'으로 글을 쓰면 메모로 남아요.

[지키는 것]
- 보호자 이름·연락처·진단·마약류 정보는 텔레그램과 AI에 보내지 않아요.
- 토큰·키는 시트의 스크립트 속성에만. 이 폴더를 다른 사람에게 보낼 때 도구/텔레그램.env 는 빼요.
- 브라우저 작업은 저장·발행·제출 버튼 앞에서 멈춰요. 버튼은 원장님이 눌러요.

강의: 동물병원 개원·운영 AI 실습 코스 「키트로 한 번에 설치」
