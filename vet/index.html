    AI가 대신 못 하는 일은 세 가지

    계정 만들기, 재료 모으기(사진·병원 정보), 올리기 전 확인. 첫 주에 아래를 하나씩 끝내세요.

    1. 플레이스·블로그를 모두 이 아이디로 운영해요. 나중에 직원에게 관리 권한을 나눠 주거나 병원을 양도할 때도 개인 아이디와 섞이지 않아요.
      자세히 따라 하기접기
      1. PC에서 naver.com → 회원가입
      2. 아이디는 병원 이름 영문이 들어가게(예: happyvet_seoul). 블로그 주소가 이 아이디로 정해져서 바꾸기 어려워요
      3. 휴대폰 번호는 원장님 번호, 2단계 인증 켜기이미 개인 아이디로 블로그를 오래 했다면 그 블로그를 쓰는 것도 방법이에요. 단, 개인 글은 비공개로 돌리세요.
    2. 구글 드라이브에 사진과 장부를 모아 둬요.
      자세히 따라 하기접기
      1. drive.google.com → 병원 공용 구글 계정으로 로그인
      2. + 새로 만들기 → 새 폴더 → 이름 병원 마케팅
      3. 그 안에 사진, 글, 백업 폴더휴대폰에 Google Drive 앱을 깔면 찍은 사진을 바로 '사진' 폴더로 올릴 수 있어요.
    3. 둘 중 하나만 고르면 돼요. 위쪽 '내 AI'에서 고르면 그 AI 설명만 보여요.이 코스를 Claude 기준으로 보고 있어요.이 코스를 ChatGPT 기준으로 보고 있어요.
      자세히 따라 하기접기
      1. Claude: claude.ai 접속 → Google로 계속하기 → 병원 구글 계정
      2. ChatGPT: chatgpt.com 접속 → 회원가입 → Google로 계속하기
      3. 휴대폰 앱스토어·플레이스토어에서 같은 이름의 앱 설치 → 같은 계정으로 로그인
      4. 결제는 PC 웹에서 하세요휴대폰 앱에서 결제하면 앱스토어 가격이 적용돼 더 비쌀 수 있어요.
    4. 보호자 이름·연락처가 섞일 수 있으니, 내 대화가 AI 개선에 쓰이지 않게 먼저 꺼 둬요.
      자세히 따라 하기접기
      1. Claude: 왼쪽 아래 내 이름 → 설정 → 개인정보 → 모델 개선에 대화 사용 끄기
      2. ChatGPT: 왼쪽 아래 내 이름 → 설정 → 데이터 제어 → '모두를 위한 모델 개선' 끄기
      3. 병원 규칙으로 정해 두기: 보호자 이름·전화번호·주소, 차트 번호는 AI에 넣지 않기. 아이 이름은 보호자 동의를 받은 경우만
    5. 블로그·인스타에 반려동물 사진과 진료 이야기를 쓰려면 보호자 동의가 먼저예요. 접수지 아래에 동의 칸을 넣어 두면 개원 첫날부터 재료가 쌓여요.

  var sh = SpreadsheetApp.getActive().getSheetByName('글달력');
  var rows = sh.getDataRange().getValues();
  var now = new Date(); now.setHours(0, 0, 0, 0);
  var end = new Date(now.getTime() + 7 * 24 * 60 * 60 * 1000);
  var booked = 0, late = [];
  for (var i = 1; i < rows.length; i++) {
    var d = rows[i][0], ch = rows[i][2], topic = rows[i][3], st = rows[i][5];
    if (!(d instanceof Date)) continue;
    if (d >= now && d <= end && (st === '예약' || st === '게시')) booked++;
    if (d < now && st !== '게시') late.push(Utilities.formatDate(d, 'Asia/Seoul', 'M/d') + ' ' + ch + ' ' + topic);
  }
  if (booked > 0 && late.length === 0) return;
  var body = '다음 7일 예약된 글: ' + booked + '개\n';
  if (late.length) body += '\n날짜가 지났는데 게시되지 않은 글:\n- ' + late.join('\n- ');
  MailApp.sendEmail(Session.getActiveUser().getEmail(), '[병원 마케팅] 이번 주 글을 확인해 주세요', body);
}
