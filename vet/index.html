    추천이나 순위가 아니에요. 2026년 11월 기준 공개된 회사 페이지·기사로 정리했고, 회사가 스스로 밝힌 실적·순위 주장은 옮기지 않았어요. 가격과 서비스는 계약 전에 꼭 다시 확인하세요.

    AI로 고르는 7단계

    1. 병원 소개서(강의)를 AI에게 주고 "직접 할 일 / 단건 외주 / 정기 대행"으로 나눠 달라고 해요. 월 예산 상한과 원하는 결과를 숫자로 적어요(예: 리뷰 개수보다 '신규 보호자 월 ○명').
    2. 웹 검색이 되는 AI에게 "동물병원 마케팅을 실제로 해 온 업체 5곳, 각 회사의 공개 서비스·가격·동물병원 사례 주소"를 표로 부탁해요. 출처 주소가 없는 정보는 지워요.
    3. 업체가 운영했다는 병원의 블로그·플레이스 주소를 받아, 글 몇 편을 복사해 AI에게 보여 줘요. 광고 규칙 위반(최상급·완치·비교), 병원마다 같은 문장 복붙, 사진 도용 흔적, 대가 표시 없는 체험단 글을 찾아 줘요.
    4. 업체마다 다른 모양의 제안서를 받으면 비교가 안 돼요. 아래 'RFP(제안 요청서)' 부탁문으로 질문지를 만들어 같은 걸 보내요.
    5. 받은 제안서를 모두 올리고 '비교 점수표' 부탁문. 가중치는 원장님이 정해요(예: 동물병원 경험 25, 계정·데이터 소유 20, 광고 규칙 준수 20, 보고 방식 15, 가격 20).
    6. 업체가 맡았던 병원 원장님 1~2분께 직접 물어봐요. 아래 질문지를 AI가 만들어 줘요.
    7. 처음부터 1년 약정 대신 3개월. 계약서에 계정 소유, 해지 조건, 매달 보고 항목, 리뷰 조작·체험단 대가 표시 준수를 넣고, 법률·세무 도우미(강의)로 한 번 점검해요. 영업 전화를 거르는 법은 다음 강의에.

    이런 말을 들으면왜 위험한가

    "최적화 블로그 빌려 드려요"블로그 매매·임대는 네이버 약관 위반, 글이 병원 이름으로 남아요

    동물병원은 이 순서로 고르세요

    1. 동물병원은 진료비를 차트에서 계산하고 단말기로 받아요. 차트와 단말기가 연동되지 않으면 금액을 두 번 치고, 매출이 두 군데로 갈라져요. "우리 차트와 연동되는 단말기·밴사 목록, 연동 비용"을 서면으로 받으세요.
    2. 개원 첫해 신규 보호자 대부분이 네이버 지도로 온다면, 결제 직후 리뷰를 받는 커넥트의 장점이 커요. 플레이스 플러스(차트 데이터로 진료 통계를 보여 주는 기능)에 우리 차트가 들어가는지도 확인하세요.
    3. 차트가 매출 통계를 충분히 주면 포스는 필요 없어요. 용품·사료 판매가 많아 재고까지 관리해야 하면 토스포스 같은 포스가 도움이 돼요.
    4. 같은 단말기라도 약정·설치비·A/S가 달라요. 다음 강의의 비교표로 정리해요.

    두 회사가 다투는 중이에요. 토스플레이스가 2026년 11월 2일, 네이버가 플레이스 플러스 포스 연동에서 토스포스를 빼 검색 노출에서 불리하게 했다며 공정거래위원회에 신고했어요. 네이버는 포스 회사를 차례로 연동하는 중이라고 반박했고 결론은 나지 않았어요. 연동 범위가 앞으로 바뀔 수 있으니, 지금 조건만 보고 긴 약정을 하지 마세요.

    알림은 각 회사의 공식 앱이, 답글 초안은 AI가, 게시는 원장님이. 자동으로 올리지는 않아요.

    왜 완전 자동이 아닌가요? 네이버와 카카오는 리뷰를 읽고 답글을 올리는 공개 API를 사장님에게 열어 두지 않았어요. 리뷰를 긁어 오거나 답글을 자동으로 올린다는 비공식 프로그램·매크로는 계정 제한 위험이 있고, 병원 이름으로 잘못된 답이 올라갈 수 있어요. 그래서 이 강의는 공식 앱 알림 + AI 초안 + 원장님 게시로 시간을 줄여요.

    1. 자세히 따라 하기접기
      1. 네이버: 휴대폰 네이버 스마트플레이스센터 앱 → 병원 아이디 로그인 → 앱 설정의 알림에서 리뷰 알림 켜기
      2. 카카오: 카카오비즈니스 파트너센터 앱(또는 카카오톡 채널 관리자 앱) → 병원 계정 로그인 → 알림 설정에서 매장 후기·채팅 알림 켜기
      3. 휴대폰 설정 → 알림에서 두 앱의 알림이 허용돼 있는지 확인. 진료 중엔 소리 대신 배너로알림 항목 이름은 앱 업데이트로 바뀌어요. 안 보이면 설정 화면을 캡처해 AI에게 "새 리뷰 알림은 어디서 켜?"라고 물어보세요.
    2. '01 플레이스 매니저' 채팅에 아래 '답글 규칙'을 보내 두면, 그 뒤로는 리뷰만 붙여도 같은 규칙으로 답해요. 원장님이 마음에 든 답글 3개를 함께 보여 주면 말투까지 맞춰요.

    function checkWeek() {
  var sh = SpreadsheetApp.getActive().getSheetByName('글달력');
  var rows = sh.getDataRange().getValues();
  var now = new Date(); now.setHours(0, 0, 0, 0);
  var end = new Date(now.getTime() + 7 * 24 * 60 * 60 * 1000);
  var booked = 0, late = [];
  for (var i = 1; i < rows.length; i++) {
    var d = rows[i][0], ch = rows[i][2], topic = rows[i][3], st = rows[i][5];
    if (!(d instanceof Date)) continue;
    if (d >= now && d <= end && (st === '예약' || st === '게시')) booked++;
    if (d < now && st !== '게시') late.push(Utilities.formatDate(d, 'Asia/Seoul', 'M/d') + ' ' + ch + ' ' + topic);
  }
  if (booked > 0 && late.length === 0) return;
  var body = '다음 7일 예약된 글: ' + booked + '개\n';
  if (late.length) body += '\n날짜가 지났는데 게시되지 않은 글:\n- ' + late.join('\n- ');
  MailApp.sendEmail(Session.getActiveUser().getEmail(), '[병원 마케팅] 이번 주 글을 확인해 주세요', body);
}

  var today = new Date(); today.setHours(0, 0, 0, 0);

    }
  }
  if (!list.length) return;
  list.sort();
  MailApp.sendEmail(Session.getActiveUser().getEmail(),
    '[재방문] 이번 2주 연락할 아이 ' + list.length + '명',
    '연락 동의(Y)한 분만 모았어요. 번호는 차트에서 찾아 주세요.\n\n- ' + list.join('\n- '));
