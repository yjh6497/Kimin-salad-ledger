3D 모델에게 "계단 몇 개야, 폭은 맞아?"라고 묻기

스케치업·레빗·아키캐드에 새로 들어온 AI 기능을 고르고, 모델 속 정보를 꺼내 검토하는 데 써요. 스케치업은 AI 이미지와 Ruby 스크립트, 레빗·아키캐드는 공식 MCP(AI에 끼우는 연결 장치)로 Claude 또는 ChatGPT 데스크톱 앱이 모델을 직접 읽게 할 수 있어요.

이게 뭐예요3D 모델에 '말로 묻는 창구'를 다는 거예요. 일람표를 일일이 만들지 않고 "2층 문 목록 줘"라고 물어요.
끝나면우리 프로그램에 맞는 AI 기능 한 가지를 켜 보고, 모델에서 뽑은 계단·문 목록을 법 기준과 맞춰 본 표

먼저 '읽기'만 시켜요. 레빗 공식 MCP는 아직 읽기 전용이에요. 아키캐드 MCP는 모델을 고칠 수도 있어서, 처음에는 "고치지 말고 목록만 보여 줘"라고 꼭 적어요.

  1. 모델 파일을 '_시험' 이름으로 복사하고 그 파일만 열어요. 협업 중인 중앙 모델(팀원과 같이 쓰는 파일)은 절대 바로 열지 않아요.
  2. 자세히 따라 하기접기
    1. AI Render는 유료 구독에 크레딧이 들어 있어요. 아이콘이 안 보이면 도구 막대 설정에서 찾아요맥: 보기 → 도구 막대 사용자화에서 끌어다 놓아요. 크레딧 수는 구독마다 달라서 화면에서 확인해요.
    2. 스크립트는 확장 프로그램(Extensions) → Developer → Ruby Console에 붙여 넣어요. 데스크톱판에만 있어요(웹판은 없음).
    3. 아래 '스케치업 Ruby 부탁문'을 보내 받은 코드를 콘솔에 붙이고 Enter. 결과가 이상하면 ⌘+Z / Ctrl+Z
  3. 자세히 따라 하기접기
    1. 레빗: Autodesk 계정(accounts.autodesk.com)의 Revit 2027 항목에서 'Revit MCP Server' 추가 기능을 받아 설치 → Claude 데스크톱을 다시 열면 자동으로 잡혀요. 첫 질문은 "열려 있는 Revit 찾아 줘"
    2. 아키캐드: 옵션 → Desktop AI Tool Connection 창에서 명령 줄과 인수를 복사 → AI 데스크톱 앱 설정의 MCP 칸에 붙이기(종류를 물으면 stdio) → 앱 다시 시작 → "열려 있는 아키캐드 프로젝트가 뭐야?"로 확인
    3. 둘 다 내 PC에서 도는 연결이라 웹 브라우저 채팅이 아니라 데스크톱 앱에서 써요막히면: 설정 화면을 캡처해 "MCP 서버를 연결하려고 해. 어디에 붙여?"라고 AI에게 물어요. 레빗은 2027 버전부터예요.
  4. 아래 'BIM 계단 목록 부탁문'을 보내요. 스케치업이면 Ruby로 그룹·컴포넌트 이름과 크기를 CSV로 받아요. 받은 목록은 다음 단계에서 법 기준과 맞춰요.
  5. AI가 "맞음"이라고 해도 그대로 믿지 않아요. 기준에 걸리는 줄만 모델에서 직접 재 보고, 결과는 도면 검토 보조 표(강의)에 옮겨요.
스케치업 Ruby 부탁문
나는 건축사사무소 소장이고 코딩은 몰라. 스케치업 (2026 / 맥 또는 윈도우) 데스크톱판을 써.
Ruby Console에 붙여 넣어 돌릴 스크립트를 만들어 줘.
- 모델의 모든 컴포넌트를 이름별로 세고, 각 컴포넌트의 가로·세로·높이(mm)를 구해
- 결과를 바탕화면에 '컴포넌트목록_날짜.csv'로 저장(이름, 개수, 가로, 세로, 높이, 태그)
- 모델은 고치지 말고 읽기만
- 붙여 넣는 곳, 실행 방법, 되돌리는 법을 순서대로 알려 줘. 고칠 때는 전체 코드를 다시 줘.
BIM 계단 목록 부탁문 (MCP 연결 뒤)
연결된 (레빗 / 아키캐드) 모델에서 고치지 말고 읽기만 해 줘.
1. 모든 계단을 층별로 찾아 표로: 이름, 층, 유효너비(폭), 단높이, 단너비, 계단참 너비, 전체 높이
2. 값이 모델에 없으면 비워 두고 '모델에 값 없음'이라고 적어
3. 2층 이상 거실 바닥면적 합계도 층별로 구해 줘(계단 너비 기준을 고를 때 필요)
4. 결과 표를 CSV로도 줘. 내가 확인하기 전에는 모델을 절대 바꾸지 마.

괄호를 고르고 '설계 프로그램 도우미' 채팅(MCP는 데스크톱 앱)에 붙여 넣으세요. 다음 법령 상자 부탁문을 같은 채팅에 이어서 보내요.

법령 MCP로 근거 확인강의

계단 폭·단높이·단너비·계단참 기준은 「건축물의 피난·방화구조 등의 기준에 관한 규칙」 제15조에 있어요. 용도와 위층 거실 면적에 따라 기준이 달라지고, 2026년 10월 6일에도 일부 개정됐어요. 그래서 기억에 기대지 말고 매번 현행 원문으로 맞춰요.

계단 기준 대조 부탁문
법령 MCP의 search_law → get_law_text로 「건축물의 피난ㆍ방화구조 등의 기준에 관한 규칙」 제15조(계단의 설치기준) 원문을 찾아 시행일과 함께 인용해 줘. 시행 예정 개정이 있으면 그 날짜와 바뀌는 내용도.
1. 우리 건물 용도는 (○○, 예: 제2종 근린생활시설). 이 용도에 맞는 계단·계단참 유효너비, 단높이, 단너비, 계단참 간격 기준만 골라 줘.
2. 위에서 뽑은 계단 표와 한 줄씩 맞춰 '맞음 / 안 맞음 / 값 없음'을 붙여 줘.
3. 직통계단 개수·거리처럼 다른 조문이 걸리면 조문 이름만 알려 주고, 조례로 정하는 값이면 ordinance_radar(또는 자치법규 검색)로 (○○시) 조례를 찾아 줘.
못 찾거나 해석이 갈리면 '확인 필요'라고 쓰고 추측하지 마.
이 강의 자동화도구 고르는 법은 강의
  • MCP
    모델에게 바로 묻기일람표를 만들지 않고 "3층 문 목록", "방화문만"처럼 물어요. 레빗 공식 MCP는 뷰를 이미지·PDF로, 일람표를 CSV로 내보낼 수도 있어요.
  • Ruby
    컴포넌트 목록 한 번에창호·가구 개수와 크기를 CSV로 받아 엑셀 물량표(강의)에 붙여요.
  • AI
    모델 → 이미지스케치업 AI Render, 아키캐드 AI Visualizer로 초기 분위기 이미지를 빨리 만들어요. 보정은 강의, 손스케치에서 시작하면 강의

AI 이미지는 '참고용'이라고 적어요. AI가 만든 투시도는 실제 설계와 다를 수 있어요. 건축주 제안서에 넣을 때는 'AI 생성 이미지(참고용)'를 밝히고, 다른 사람 사진을 참고 이미지로 넣었다면 사용 허락을 확인해요. 모델·도면을 외부 AI에 보내기 전에는 사무소 규칙(강의)을 먼저 봐요.

AI 비서에 연결강의
어디서Claude·ChatGPT 데스크톱 앱의 사무소 AI 비서 프로젝트 → '설계 프로그램 도우미' 채팅
넣어 둘 것프로그램 버전, 사무소 모델링 규칙(계단·문 이름 붙이는 법), 잘 돌아간 스크립트 → 프로젝트 파일
세션프로젝트 하나에 채팅 하나. 검토 결과 표만 남기고 모델 자료는 채팅에 쌓아 두지 않아요.
