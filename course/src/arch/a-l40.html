건축사 업무에 바로 쓰이는 공공데이터 API를 한눈에 정리하고, 모든 API의 출발점인 주소 → 코드 바꾸기를 먼저 만들어요. 이 단계의 나머지 강의는 모두 이 코드를 씁니다.

모든 API의 공통 순서는 같아요. ① 사이트 가입 → ② 활용신청 → ③ 인증키 복사 → ④ AI에게 앱스 스크립트 받기 → ⑤ 키는 스크립트 속성에 저장 → ⑥ 시트 메뉴 버튼으로 실행. 붙이는 법은 강의와 같아요.

먼저 만들기: 주소 → 코드 변환

건축HUB·실거래가 API는 주소 대신 법정동코드와 번·지를, 브이월드는 PNU(필지 고유번호 19자리)를 받아요. 주소 검색 API가 주소를 넣으면 이 값을 돌려줘서, 코드표를 손으로 찾을 필요가 없어져요.

'대지' 탭 한 줄 · 예시주소 검색 API 결과
입력○○시 ○○동 123-4
코드행정구역코드 10자리 · 산여부 0 · 본번 123 · 부번 4
만든 값시군구 5자리 · 법정동 5자리 · 번 0123 · 지 0004 · PNU 19자리
  1. 자세히 따라 하기접기
    1. PC에서 검색창에 도로명주소 개발자센터 → 공식 사이트(business.juso.go.kr) 접속
    2. API 신청 → API 종류에서 검색API 선택 → 활용 목적 '사무소 내부 대지 조회', 시스템 URL 칸은 안내에 따라 입력
    3. 승인키를 복사해 메모장에 적어 두기개발용 승인키는 사용 기간이 정해져 있어요. 계속 쓰려면 안내에 따라 운영용으로 신청하세요. 공공데이터포털의 '행정안전부_실시간 주소정보 조회(검색API)'도 같은 서비스예요.
  2. 이 단계의 모든 조회가 이 탭을 출발점으로 써요. 앞 강의의 '대지조회' 탭이 있다면 이 탭으로 바꿔 써도 돼요.
  3. 아래 부탁문을 보내 붙이고, 주소 칸만 적은 뒤 메뉴 대지조회 → 주소를 코드로를 눌러요.
  4. 처음 한두 건은 토지이음 열람 화면의 지번과 같은지, 산 번지면 산여부가 1인지 확인해요.

주소 → 코드 변환 스크립트 부탁문
구글 시트 '사무소 대장'의 '대지' 탭(제목 줄 아래 붙임)에서, 주소 칸이 있고 변환일이 빈 줄마다 행정안전부 도로명주소 검색 API(검색API, JSON)를 호출해 다음을 채우는 앱스 스크립트를 써 줘.
- 도로명주소, 행정구역코드(10자리), 시군구코드(앞 5자리), 법정동코드(뒤 5자리), 산여부, 번(본번을 4자리로 0 채움), 지(부번 4자리)
- PNU 19자리 = 행정구역코드 10자리 + 필지구분 1자리(일반 1, 산 2) + 본번 4자리 + 부번 4자리
- 검색 결과가 여러 개면 메모 칸에 '결과 여러 개, 확인 필요'와 첫 3개 주소
- 승인키는 스크립트 속성 JUSO_KEY에 저장
- 시트 위쪽 메뉴 '대지조회 → 주소를 코드로' 만들기

응답 항목 이름은 API 안내서를 확인해서 맞춰 줘. 붙여 넣는 곳, 승인키 넣는 법, 처음 실행 권한을 순서대로 알려줘.
