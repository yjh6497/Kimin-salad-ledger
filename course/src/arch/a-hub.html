실습 · 약 40분 · 코드 없이

주소 하나 말하면 건축물대장·인허가·공시가격이 한 장으로

국토교통부 건축HUB의 건축물대장·건축인허가·주택인허가 자료를 AI가 바로 조회하게 해 주는 MCP 커넥터예요. 공용 인증키가 들어 있어서 주소(URL) 하나만 등록하면 끝나요. 건축물대장 자동 조회 강의(강의)가 시트에 매일 쌓는 방식이라면, 이 강의는 채팅에서 "○○동 ○○번지 건물 한눈에"처럼 말로 묻는 방식이에요. 법령 MCP(강의)와 같이 켜 두면 현황 → 법 기준 비교까지 한 채팅에서 끝나요.

왜 필요해요상담 전에 대장·인허가를 사이트마다 찾아 열람하면 필지 하나에 30분씩 걸려요. AI가 건축HUB에서 바로 꺼내 요약해 주면 몇 분 만에 종합카드를 들고 상담에 들어가요.
이게 뭐예요구청 민원 창구에 대장 열람을 신청하는 대신, AI 직원이 건축HUB 창고에서 서류를 바로 꺼내 와 요약해 주는 거예요.
끝나면상담 전 '한 필지 종합카드', 동네 노후 건물 목록, 주변 인허가 진행 현황을 채팅으로 받는 습관
필요한 것PC, Claude(무료도 커넥터 1개 가능) 또는 ChatGPT 유료, 40분 · 커넥터 연결이 처음이면 법령 MCP 강의(강의)와 같은 순서예요

1 · 연결하기 (한 번만)

  1. AI가 건축HUB를 열 수 있게 플러그를 꽂는 단계예요. 키를 받거나 넣을 필요가 없어요.
    자세히 따라 하기 (claude.ai)접기
    1. PC에서 claude.ai → 왼쪽 아래 내 이름 → 설정 → 커넥터 → 커스텀 커넥터 추가
    2. 이름 건축HUB, 원격 MCP 서버 주소에 아래 주소 붙여 넣기 → 추가
    3. 추가된 '건축HUB' 옆 구성 → 모든 도구 → 항상 사용으로 바꾸기 (질문할 때마다 허용 버튼을 안 눌러도 돼요)막히면: 무료 플랜은 커스텀 커넥터가 1개까지예요. 이미 법령 MCP를 연결했다면, 법규 질문용과 건축물 조회용 계정을 나누거나 유료로 바꿔 둘 다 켜요. 메뉴 이름은 바뀔 수 있으니 '커넥터'에서 '커스텀' 또는 '사용자 지정'이 들어간 버튼을 찾아요.
  2. 공식 안내는 Claude 기준이지만, 원격 MCP 주소를 받는 방식이라 법령 MCP와 같은 방법(유료 플랜의 개발자 모드 → 앱 만들기 → MCP 서버 주소, 인증 없음)으로 연결해 볼 수 있어요(강의).
  3. 새 채팅에서 "건축HUB로 ○○구 ○○동 법정동코드 찾아 줘"라고 보내요. 시군구코드·법정동코드가 나오면 성공이에요.

Claude 데스크톱 설정 파일·Claude Code로 넣고 싶다면접기
  1. claude.ai에서 추가한 커넥터는 같은 계정의 데스크톱 앱에도 보여요. 보통은 이걸로 충분해요
  2. Claude Code(터미널 AI)라면 한 줄: claude mcp add --transport http archhub https://mcp.gomdori.app/archhub
  3. 예전 주소(archhub-mcp.fly.dev)로 등록했다면 위 주소로 바꿔요. 예전 주소는 닫혔어요

2 · 이런 걸 물어볼 수 있어요

도구무엇을사무소 일에서
find_region주소 → 시군구·법정동코드, 번·지다른 도구의 출발점 (AI가 알아서 먼저 써요)
building_profile한 필지 종합카드: 용도지역·용도·구조·규모·건폐율/용적률·주차·사용승인일·내진·정화조건축주 첫 상담 전 현황 파악(강의)
building_floors층별 용도·면적용도변경·리모델링 검토
parcel_history필지 연혁: 허가·멸실(석면 표시)·가설건축물대지 검토 메모(강의)
permits_pipeline허가 났지만 사용승인 전인 건, 착공 여부주변 인허가 사례·동네 개발 흐름(강의)
district_stats동 단위 통계: 용도별·연대별·노후도·규모영업 지역 분석, 제안서 배경 자료
old_buildings사용승인 후 오래된 건물 순 목록리모델링·재건축 영업 대상 찾기
seismic_check내진 설계가 없을 가능성이 큰 건물 추정내진 보강 제안
temp_buildings가설건축물 존치기간: 만료·180일 안 만료건축주에게 연장 신고 안내
demolitions철거·멸실 현황(석면 자재 포함)동네 신축 수요 감 잡기
price_history공시가격 추이·증가율사업성 검토 참고(강의)
building_data원본 자료(대장·건축인허가·주택인허가)표를 엑셀로 받아 직접 분석(강의)

3 · 실무 부탁문

  1. 건축주가 주소만 알려 줘도 상담 전에 현황을 알고 들어갈 수 있어요. 아래 ①번 부탁문.
  2. 현재 건폐율·용적률(건축HUB)과 조례 허용치(법령 MCP, 강의)를 나란히 놓으면 증축·용도변경 가능성을 바로 말할 수 있어요. ②번 부탁문.
  3. ③번 부탁문으로 우리 동네 오래된 건물과 내진 취약 추정 건물을 표로 받아요. 개인 소유자 정보는 나오지 않아요.
  4. ④번 부탁문을 매달 1일에 돌리면 존치기간 만료가 다가오는 가설건축물을 미리 알 수 있어요.

아래 글을 건축HUB(필요하면 법령도) 커넥터를 켠 채팅에 붙여 넣으세요. ○○ 자리만 바꿔요.

① 한 필지 종합카드
건축HUB 도구로 ○○구 ○○동 ○○번지 건물을 조회해 줘.
1) 한 필지 종합카드 (용도지역, 주용도, 구조, 층수, 연면적, 건폐율·용적률, 주차, 사용승인일, 내진)
2) 층별 용도·면적 표
3) 필지 연혁 (허가·멸실·가설건축물)
4) 건축주 상담 때 물어볼 것 5가지
찾지 못한 값은 '자료 없음'으로, 추측하지 마.
② 현황 + 법 기준 비교 (건축HUB + 법령)
건축HUB 도구로 ○○구 ○○동 ○○번지의 현재 용도지역·대지면적·건축면적·연면적·건폐율·용적률을 조회하고,
법령 도구로 국토계획법과 ○○시 도시계획 조례의 이 용도지역 건폐율·용적률 허용치를 찾아서
표: 항목 | 현재 | 허용(근거 조문·조례·시행일) | 남은 여유
마지막에 증축 가능성 한 줄 의견 (최종 판단은 현장·허가권자 확인 필요라고 표시).
③ 동네 노후·내진 목록
건축HUB 도구로 ○○구 ○○동을 조회해 줘.
1) 동 단위 통계 요약 (용도별, 준공 연대별, 노후도)
2) 사용승인 후 30년 넘은 건물 상위 20개: 지번 | 주용도 | 연면적 | 사용승인연도
3) 내진 설계가 없을 가능성이 큰 건물 추정 목록
결과는 엑셀로 만들 수 있게 표로.
④ 가설건축물 존치 만료 확인
건축HUB 도구로 아래 필지들의 가설건축물 존치기간을 확인해 줘.
필지: ○○동 ○○번지, ○○동 ○○번지
표: 필지 | 가설건축물 | 존치기간 만료일 | 상태(만료/180일 안 만료/유효)
만료가 가까운 건은 건축주에게 보낼 안내 문자 초안(3줄)도.

공공데이터 그대로의 한계. 대장 등재가 늦거나 빠진 건이 있을 수 있어요. 위반건축물 여부는 이 도구로 조회되지 않으니 정부24 등 건축물대장 원본으로 확인해요. 공시가격은 실거래가가 아니에요. 큰 동은 느릴 수 있고 결과가 1만 줄에서 잘려요.

많이 쓴다면: 내 인증키로 직접 돌리기 (고급)접기
  1. 공용키는 짧은 시간에 많이 부르면 제한될 수 있어요. 매일 대량으로 쓴다면 공공데이터포털에서 건축HUB 서비스 활용신청 → 일반 인증키(Decoding)를 받아요
  2. 저장소(github.com/chrisryugj/archhub-mcp)를 내려받아 pip install -e .로 설치하고, 키를 ARCHHUB_SERVICE_KEY로 넣어 실행해요
  3. 이 과정은 터미널 AI(강의)에게 "이 저장소 README대로 내 키로 설치해 줘"라고 맡기면 쉬워요
이 강의 자동화손을 줄이는 방법
  • 예약 작업
    매달 1일 가설건축물·인허가 확인④번과 주변 인허가 파이프라인을 AI 예약 작업으로(유료).
  • AI 스킬
    '상담 준비' 스킬①+②를 하나로 묶어 "○○번지 상담 준비"만 말하면 되게(강의).

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 발표 자료는 markitdown 자료.pptx -o 자료.md로 글자만 뽑아 올리면 그림까지 읽지 않아 가벼워요.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
