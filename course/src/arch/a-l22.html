  2. "프로젝트 탭에 새 줄이 생기고 상태가 '진행'이 되면 드라이브 '프로젝트' 폴더 안에 규칙대로 폴더와 하위 폴더를 만들고, 폴더 링크를 메모 칸에 넣는 스크립트"를 받아요. 폴더 ID가 필요해요.
  3. CAD·BIM 원본은 지금 서버에 두되 폴더 이름은 같게. 그래야 드라이브의 문서와 서버의 도면이 한 프로젝트코드로 이어져요.
  4. 이미 쌓인 파일은 Finder에서 여러 개 골라 오른쪽 클릭 → 이름 변경으로 앞부분을 한 번에 바꿀 수 있어요. 복잡하면 AI에게 "이 파일 목록을 규칙 이름으로 바꾼 표 만들어 줘"라고 해 손으로 따라 바꿔요.
