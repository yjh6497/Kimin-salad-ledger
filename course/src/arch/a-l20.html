주소만 넣으면 건축물대장이 시트에

공공데이터포털의 국토교통부 건축HUB 건축물대장정보 서비스를 써요. 그러면 대장 표제부(주용도, 연면적, 건폐율, 용적률, 사용승인일 등)를 시트로 자동으로 받을 수 있어요. 리모델링·용도변경 상담 전 확인이 빨라져요.

이게 뭐예요정부 창고에 '대장 좀 보내 주세요' 주문서를 넣는 자동 심부름꾼을 시트에 두는 거예요. 주소 코드만 적고 버튼을 누르면 돼요.
끝나면'사무소 대장' 시트의 '대지조회 → 건축물대장 가져오기' 메뉴와, 결과가 쌓이는 '대장결과' 탭
필요한 것PC, 공공데이터포털 회원가입, 반나절 · 코드 붙이기가 처음이면 강의, 시트가 처음이면 강의 먼저
'대지조회' 탭시군구코드 · 법정동코드 · 번 · 지
건축HUB API건축물대장 표제부
'대장결과' 탭주용도 · 연면적 · 사용승인일

코드 없이 채팅으로 바로 묻고 싶다면 건축HUB MCP 커넥터를 연결하세요. "○○번지 건물 한눈에"라고만 해도 대장 내용과 한 필지 종합카드가 나와요. 시트에 날마다 쌓을 때는 이 강의 방식이 좋아요.(강의)

  1. 정부 자료를 받아 쓸 허락을 받는 단계예요. 신청하면 인증키(우리 사무소 출입증 같은 글자)가 나와요.
    자세히 따라 하기접기
    1. data.go.kr 로그인 → 검색창에 '건축HUB 건축물대장정보' → '국토교통부_건축HUB_건축물대장정보 서비스' 오픈API를 열어요
    2. 활용신청 → 목적 입력 → 신청을 눌러요. 자동승인이에요
    3. 마이페이지 → 데이터활용 → Open API에서 일반 인증키를 복사해요개발계정은 하루 요청 수가 정해져 있어요. 사무소 조회에는 충분해요.
  2. 주소를 숫자로 바꿔 넣어야 해서예요. API(프로그램끼리 자료를 주고받는 창구)는 주소 대신 법정동코드를 받아요. 10자리 중 앞 5자리가 시군구코드, 뒤 5자리가 법정동코드예요.
    자세히 따라 하기접기
    1. 검색창에 행정표준코드관리시스템 법정동코드를 넣어요. 공식 사이트(code.go.kr)에서 동 이름을 검색해요
    2. 10자리 코드에서 앞 5자리는 시군구코드 칸에, 뒤 5자리는 법정동코드 칸에 적어요
    3. 지번 123-4면 번=0123, 지=0004 (네 자리로 앞에 0을 채워요)자주 쓰는 동은 '법정동' 탭에 모아 두면 다음부터 고르기만 하면 돼요.
  3. 조회를 대신 해 줄 작은 프로그램을 시트에 다는 거예요. '09 자동화·연결' 채팅에 아래 부탁문을 보내면 앱스 스크립트 코드가 나와요. 붙이는 법은 강의와 같아요. 부탁문에 '대지조회' 메뉴를 만들어 달라고 적었어요. 그래서 시트 위 메뉴를 버튼처럼 눌러 쓰면 돼요.막히면: 처음 실행 때 '권한 검토' 창이 뜨면 사무소 계정 → 고급 → 이동 → 허용을 눌러요. 결과가 비어 있으면 인증키가 아직 활성화 전일 수 있어요. 한두 시간 뒤 다시 해 봐요.
  4. 자동 결과를 믿어도 되는지 확인하려는 거예요. 처음 몇 건은 정부24 열람본과 숫자가 같은지 봐요. 같으면 그다음부터는 상담 준비에 바로 써요. 제출용은 여전히 발급본을 써요.

제목 줄은 '대지조회' 탭 A1 칸에 붙여 넣으세요. 스크립트 부탁문은 그대로 복사해서 '09 자동화·연결' 채팅에 붙여 넣으면 돼요. 고칠 곳은 없어요.

프로젝트코드 | 주소(메모) | 시군구코드 | 법정동코드 | 대지구분 | 번 | 지 | 조회
건축물대장 조회 스크립트 부탁문
구글 시트 '사무소 대장'의 '대지조회' 탭(제목 줄: 프로젝트코드, 주소(메모), 시군구코드, 법정동코드, 대지구분, 번, 지, 조회)의 각 줄로 공공데이터포털 '국토교통부_건축HUB_건축물대장정보 서비스'의 표제부(getBrTitleInfo)를 조회해서 '대장결과' 탭에 넣는 앱스 스크립트를 써 줘.
- 엔드포인트: https://apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo , _type=json
- 조회 칸이 비어 있는 줄만 조회하고, 끝나면 조회 칸에 날짜
- 결과 칸: 프로젝트코드, 건물명, 동명칭, 주용도, 구조, 지상·지하 층수, 대지면적, 건축면적, 건폐율, 연면적, 용적률산정연면적, 용적률, 사용승인일, 위반건축물 여부 (응답 항목 이름은 API 문서를 확인해서 맞춰 줘)
- 인증키는 스크립트 속성에 저장
- 시트 위쪽 메뉴에 '대지조회 → 건축물대장 가져오기' 버튼을 만들어 줘
붙여 넣는 곳, 인증키 넣는 법, 처음 실행 권한을 순서대로 알려줘. 나는 초보야.

토지이용계획은 아직 손으로. 용도지역·지구 자료도 공공데이터로 있지만, 행위제한과 지구단위계획까지 보려면 토지이음 열람(강의)이 가장 확실해요.

법령 MCP로 근거 확인강의

건축물대장의 위반 표시, 용도, 사용승인일은 다음 설계의 출발점이에요. 위반이 있으면 어떤 조치가 걸리는지 원문으로 확인해요.

  • 「건축법」 제79조(위반 건축물 등에 대한 조치 등)
  • 「건축물관리법」(건축물대장 관련)

아래 글을 '법규 검토' 채팅(법령 커넥터 켜기)에 붙여 넣으세요.

근거 확인 부탁문
건축물대장 조회 결과(붙여 넣기)를 보고 법령 도구로 확인해 줘.
1) 위반 표시가 있으면 건축법 제79조로 걸리는 조치와 설계에 미치는 영향
2) 사용승인일 기준으로 그때와 지금 기준이 달라 조심할 항목(주차·피난 등)
3) 건축주에게 확인할 질문 3개
조문은 법령 도구로 찾은 현행 원문과 시행일을 붙이고, 못 찾은 건 지어내지 말고 '확인 필요'로.
이 강의 자동화도구 고르는 법은 강의
  • API
    메뉴 한 번으로 조회대지조회 탭에 줄을 추가하고 메뉴를 누르면 끝. 결과를 대지 검토 메모 부탁문에 그대로 붙여요.
  • MCP
    대화로 조회 (심화)건축물대장 API를 AI가 쓰게 묶은 공개 MCP도 있어요. 연결하면 "○○동 123-4 건축물대장 보여 줘"로 바로 물어볼 수 있어요.
토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
