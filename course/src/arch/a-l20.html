주소만 넣으면 건축물대장이 시트에

공공데이터포털의 국토교통부 건축HUB 건축물대장정보 서비스를 쓰면 대장 표제부(주용도, 연면적, 건폐율, 용적률, 사용승인일 등)를 시트로 자동으로 받을 수 있어요. 리모델링·용도변경 상담 전 확인이 빨라져요.

'대지조회' 탭시군구코드 · 법정동코드 · 번 · 지
건축HUB API건축물대장 표제부
'대장결과' 탭주용도 · 연면적 · 사용승인일
  1. 자세히 따라 하기접기
    1. data.go.kr 로그인 → 검색 건축HUB 건축물대장정보 → '국토교통부_건축HUB_건축물대장정보 서비스' 오픈API
    2. 활용신청 → 목적 입력 → 신청. 자동승인이에요
    3. 마이페이지 → 데이터활용 → Open API에서 일반 인증키 복사개발계정은 하루 호출 수가 정해져 있어요. 사무소 조회에는 충분해요.
  2. API는 주소 대신 법정동코드를 받아요. 앞 5자리가 시군구코드, 뒤 5자리가 법정동코드예요.
    자세히 따라 하기접기
    1. 검색창에 행정표준코드관리시스템 법정동코드 → 공식 사이트(code.go.kr)에서 동 이름 검색
    2. 10자리 코드에서 앞 5자리 → 시군구코드 칸, 뒤 5자리 → 법정동코드 칸
    3. 지번 123-4면 번=0123, 지=0004 (네 자리로 앞에 0을 채워요)자주 쓰는 동은 '법정동' 탭에 모아 두면 다음부터 고르기만 하면 돼요.
  3. '09 자동화·연결' 채팅에 아래 부탁문을 보내요. 붙이는 법은 강의와 같아요. 대장 시트에 '대지조회' 메뉴가 생기게 해 달라고 했으니, 버튼처럼 눌러 쓰면 돼요.
  4. 처음 몇 건은 정부24 열람본과 숫자가 같은지 확인해요. 같으면 그다음부터는 상담 준비에 바로 써요. 제출용은 여전히 발급본을 씁니다.

건축물대장 조회 스크립트 부탁문
구글 시트 '사무소 대장'의 '대지조회' 탭(제목 줄: 프로젝트코드, 주소(메모), 시군구코드, 법정동코드, 대지구분, 번, 지, 조회)의 각 줄로 공공데이터포털 '국토교통부_건축HUB_건축물대장정보 서비스'의 표제부(getBrTitleInfo)를 조회해서 '대장결과' 탭에 넣는 앱스 스크립트를 써 줘.
- 엔드포인트: https://apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo , _type=json
- 조회 칸이 비어 있는 줄만 조회하고, 끝나면 조회 칸에 날짜
- 결과 칸: 프로젝트코드, 건물명, 동명칭, 주용도, 구조, 지상·지하 층수, 대지면적, 건축면적, 건폐율, 연면적, 용적률산정연면적, 용적률, 사용승인일, 위반건축물 여부 (응답 항목 이름은 API 문서를 확인해서 맞춰 줘)
- 인증키는 스크립트 속성에 저장
- 시트 위쪽 메뉴에 '대지조회 → 건축물대장 가져오기' 버튼을 만들어 줘
붙여 넣는 곳, 인증키 넣는 법, 처음 실행 권한을 순서대로 알려줘. 나는 초보야.

토지이용계획은 아직 손으로. 용도지역·지구 자료도 공공데이터로 있지만, 행위제한과 지구단위계획까지 보려면 토지이음 열람(강의)이 가장 확실해요.
