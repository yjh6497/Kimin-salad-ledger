준공 사진 한 묶음이 일주일 치 콘텐츠로

준공 프로젝트 하나를 홈페이지 포트폴리오 글, 인스타그램 게시물 3개, 블로그 글 1개로 나눠 써요. 홈페이지는 무료로 만들 수 있어요.

이게 뭐예요준공 사진 한 묶음을 여러 접시에 나눠 담는 거예요. 같은 프로젝트로 홈페이지·인스타·블로그 글을 한 번에 받아요.
끝나면포트폴리오 글 1개, 인스타 게시물 3개, 블로그 글 1개, 그리고 (원하면) 무료 홈페이지 주소가 생겨요.
필요한 것PC, 준공 사진 10장, 건축주 게시 동의, 하루 · 파일 올리기가 처음이면 강의 먼저
월화수목금토일 대표 사진 설계 이야기 전후 비교

예시 · 준공 프로젝트 하나로 주 3회

  1. AI가 글을 쓰려면 재료가 한곳에 모여 있어야 해요. 프로젝트명(공개 가능한 이름), 위치(동 단위), 용도, 규모, 준공 연도, 설계 개념 3줄, 사진 10장을 한 장에 적어요. 건축주에게 게시 동의를 먼저 받아요.
  2. '05 이미지·발표' 채팅에 한 장 요약을 주고 아래 부탁문을 보내요.
  3. AI에게 "포트폴리오 홈페이지 HTML 한 파일로 만들어 줘"라고 해요. 받은 파일을 GitHub Pages에 올리면 무료예요. 손이 덜 가는 쪽은 네이버 블로그나 노션 공개 페이지예요.
    자세히 따라 하기 (GitHub Pages)접기
    1. github.com에 가입해요. + → New repository를 눌러 저장소(파일을 담는 폴더)를 만들어요. 이름은 예를 들어 office-portfolio, Public을 고르고 Create repository를 눌러요
    2. Add file → Upload files로 AI가 준 index.html과 사진을 올려요. 아래 Commit changes를 눌러 저장해요
    3. Settings → Pages → Deploy from a branch → main / root → Save를 눌러요. 잠시 뒤 위에 주소가 떠요막히면: 주소가 안 뜨면 1~2분 뒤 새로고침해요. 파일 이름이 꼭 index.html인지도 봐요.사진은 긴 변 2000px 정도로 줄여 올리세요. 원본은 너무 커서 느려요.
  4. 매번 올리는 날을 챙기지 않으려고 미리 예약해요. 인스타그램은 메타 비즈니스 스위트에서 날짜를 정해 예약해요.

이 글을 그대로 복사해서 '05 이미지·발표' 채팅에 붙여 넣으세요. 프로젝트 한 장 요약과 사진 설명을 같이 첨부해요.

채널별 글 부탁문
첨부한 프로젝트 요약과 사진 설명으로 다음을 써 줘.
1) 홈페이지 포트폴리오 글 (개요표 + 설계 이야기 400자)
2) 인스타그램 게시물 3개: 대표 사진 / 설계 이야기 / 전후 비교. 각각 캡션 200자 이내, 해시태그 8개(지역+용도+사무소명)
3) 블로그 글 1개: 건축주가 궁금해할 '이 집을 짓기까지' 과정, 1,200자
과장된 표현(최고, 완벽한)과 시공사·자재 회사 광고처럼 보이는 표현은 빼 줘. 건축주 개인 정보는 쓰지 마.
이 강의 자동화도구 고르는 법은 강의
  • 예약 게시
    한 번에 세 개메타 비즈니스 스위트로 일주일 치를 한 번에 예약해요.
  • 지침·스킬
    사무소 소개 문장 고정홈페이지 소개문을 프로젝트 파일에 넣어 두면 모든 글이 같은 소개로 끝나요.
토큰 아끼기강의
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
  • 정기 브리핑·분석은 같은 채팅에 계속 쌓지 말고 달마다 새 채팅. 지난달 요약 10줄만 붙여 이어가요.
