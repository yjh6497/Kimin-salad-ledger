주소 하나 넣고 버튼 한 번, 상담 준비 끝

이 단계에서 만든 조회를 한 버튼으로 묶어요. 주소를 적고 대지조회 → 한 장 리포트를 눌러요. 그러면 코드 변환 → 건축물대장 → 토지정보 → 주변 인허가 → 실거래가 차례로 돌아요. 결과는 '리포트' 탭에 한 장으로 정리돼요. 그 한 장을 AI에게 주면 대지 검토 메모가 나와요.

이게 뭐예요여러 창구를 도는 심부름을 한 번에 맡기는 거예요. 주소 한 줄만 적으면 시트가 대장·토지·인허가·실거래를 차례로 찾아와요.

대지 검토 메모법령 MCP로 근거까지
  1. 하나라도 안 되면 묶어도 안 돼요. 코드 변환, 건축물대장, 토지정보, 주변 인허가, 실거래를 한 번씩 눌러 봐요. 모두 결과가 나와야 묶을 수 있어요.
  2. 새로 짜는 게 아니에요. 있는 함수(작은 일 한 덩어리)를 차례로 부르는 함수 하나만 더해요. 지금 Apps Script에 있는 코드 전체를 복사해요. '09 자동화·연결' 채팅에 붙이고 아래 부탁문을 보내요.막히면: 실행할 때 권한 허용 창이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용을 눌러요. 오류가 나면 빨간 글씨를 캡처해 같은 채팅에 보내요.
  3. 리포트 한 장이 상담 준비 자료가 돼요. '02 대지·법규 검토' 채팅에 리포트 탭 내용과 건축주 희망을 주고 '리포트 → 메모' 부탁문을 보내요. 법령 MCP(강의)가 연결돼 있으면 용도·주차 근거까지 바로 조회해요.
  4. 행위제한·지구단위계획은 API로 다 오지 않아요. 그래서 마지막에 토지이음 열람(강의)으로 '확인 필요' 줄을 지워요.

첫 부탁문은 '복사'를 눌러 '09 자동화·연결' 채팅에 붙여 넣으세요. 맨 아래 [코드 붙여 넣기] 자리에 Apps Script 코드 전체를 넣어요.

한 장 리포트 묶기 부탁문
아래는 지금 '사무소 대장' Apps Script 코드 전체야. 이미 있는 함수들(주소→코드, 건축물대장, 토지정보, 주변 인허가, 실거래)을 고른 줄 하나에 대해 차례로 실행하고, 결과를 '리포트' 탭에 한 장으로 정리하는 함수를 추가해 줘.
- 리포트 구성: 대지 개요(주소, PNU, 지목, 면적, 용도지역·지구, 공시지가) / 기존 건축물(주용도, 연면적, 사용승인일, 위반 여부) / 주변 허가 요약(최근 3년 용도별 건수·평균 연면적) / 실거래 요약(유형별 ㎡당 중간값) / 조회일
- 중간에 하나가 실패해도 나머지는 계속하고, 실패한 항목은 '조회 실패: 이유'로 표시
- 메뉴 '대지조회 → 한 장 리포트'
기존 코드는 바꾸지 말고 추가할 부분만 줘.

리포트 → 대지 검토 메모 부탁문
'리포트' 탭의 대지 한 장 리포트와 건축주 희망(○○ 용도, 대략 ○○㎡, ○층)으로 대지 검토 메모를 써 줘. 법령 도구로 용도지역 건축제한과 주차 기준을 조회해 근거를 붙이고, 주변 허가 사례와 시세는 '참고'로만. 리포트에 없는 것(행위제한, 지구단위계획, 도로 조건)은 '토지이음·현장 확인 필요'로 표시해. 1쪽 이내.
법령 MCP로 근거 확인강의

대지 한 장 리포트에 법령 근거 칸을 더하면 상담용 자료가 그대로 검토 근거 자료가 돼요.

  • 조례 값까지 이어 보기(강의)
  • 애매한 조항은 해석례(강의)
  • 기준 날짜 남기기(강의)

아래 글을 '법규 검토' 채팅(법령 커넥터 켜기)에 붙여 넣으세요.

근거 확인 부탁문
대지 한 장 리포트(붙여 넣기)의 항목마다 법령 도구로 근거 칸을 채워 줘.
칸: 항목 | 값 | 근거 법령·조문 | 조례 | 시행일 | 확인일(오늘 날짜)
애매한 항목은 관련 법제처 해석례를 짧은 검색어로 찾아 번호와 결론 한 줄을 붙이고, 없으면 '찾지 못함'.
조문은 법령 도구로 찾은 현행 원문과 시행일을 붙이고, 못 찾은 건 지어내지 말고 '확인 필요'로.
이 강의 자동화도구 고르는 법은 강의
  • API
    버튼 하나로 다섯 가지새 상담이 잡히면 주소 한 줄, 버튼 한 번. 상담 전날 저녁 10분이면 준비가 끝나요.
  • 구글 폼
    상담 신청과 연결상담 신청 폼(강의)의 대지 주소가 '대지' 탭에 자동으로 들어오게 하면, 신청이 오는 순간 리포트까지 돌게 만들 수도 있어요.
토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
