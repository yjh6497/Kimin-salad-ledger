용도지역과 필지 경계를 시트와 지도로

브이월드(공간정보 오픈플랫폼) API로 PNU를 넣어 필지의 용도지역·지목·면적·공시지가를 받고, 필지 경계를 지도 파일로 받아요. 배치 스터디 바탕으로도 써요.

  1. 자세히 따라 하기접기
    1. PC에서 vworld.kr → 회원가입 → 로그인
    2. 오픈API → 인증키 발급 → 서비스 분류에서 데이터 API(2D 데이터)를 고르고, 활용 URL에는 안내에 따라 입력
    3. 발급된 인증키를 복사인증키에는 사용 기간이 있어요. 만료 안내 메일이 오면 같은 메뉴에서 연장하세요.
  3. 아래 부탁문을 '09 자동화·연결' 채팅에 보내요. 브이월드는 기능별로 데이터 이름이 달라서, AI에게 브이월드 API 레퍼런스를 확인해 맞추라고 부탁문에 적어 두었어요.
  4. 연속지적도 데이터를 GeoJSON으로 받으면 구글 어스나 QGIS에서 열 수 있어요. CAD로 가져갈 때는 좌표계를 꼭 확인하세요. 측량 성과를 대신하지 못해요.
  5. 토지정보 탭 한 줄을 대지 검토 메모 부탁문(강의)에 함께 주면 PDF 없이도 첫 메모가 나와요. 다만 행위제한·지구단위계획은 여전히 토지이음 열람으로 확인해요.
토지정보 탭 제목 줄
프로젝트코드 | PNU | 지목 | 토지면적(㎡) | 용도지역 | 용도지구·구역 | 개별공시지가(원/㎡) | 기준연도 | 조회일 | 메모
토지정보 조회 스크립트 부탁문
구글 시트 '사무소 대장'의 '대지' 탭 PNU로 브이월드 오픈API를 조회해 '토지정보' 탭을 채우는 앱스 스크립트를 써 줘.
- 지목·토지면적·개별공시지가(토지특성·공시지가 관련 데이터), 용도지역·지구(용도지역지구 관련 데이터)를 PNU로 조회
- 사용할 API와 데이터 이름은 브이월드 데이터 API 레퍼런스를 확인해서 정확히 맞추고, 어떤 걸 썼는지 코드 맨 위 주석에 적어 줘
- 같은 PNU가 이미 있으면 건너뛰기, 결과가 없으면 메모에 '조회 결과 없음'
- 추가 기능: 선택한 줄의 필지 경계(연속지적도)를 GeoJSON 파일로 드라이브 '프로젝트' 폴더에 저장
- 인증키는 스크립트 속성 VWORLD_KEY에 저장, 메뉴 '대지조회 → 토지정보 가져오기', '대지조회 → 필지 경계 저장'
제목 줄: 프로젝트코드 | PNU | 지목 | 토지면적(㎡) | 용도지역 | 용도지구·구역 | 개별공시지가(원/㎡) | 기준연도 | 조회일 | 메모
나는 초보야. 붙여 넣는 곳과 실행 순서를 알려줘.

공간정보는 참고용이에요. 데이터 갱신 시점에 따라 실제 결정·고시와 다를 수 있어요. 허가 도서에는 토지이용계획확인서와 측량 성과를 씁니다.
