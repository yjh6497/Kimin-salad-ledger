수식은 AI가 짜고, 계산은 엑셀이 하고, 확인은 소장님이

사무소의 면적표·설계비 산정표는 대부분 엑셀이에요. AI에게 숫자를 바로 계산시키지 말고, 엑셀 파일과 수식을 만들게 해요. 반복 정리는 VBA(엑셀에 붙이는 작은 프로그램)로 줄여요.

이게 뭐예요엑셀 양식을 AI가 대신 만들어 주는 거예요. 계산 자체는 엑셀 수식이 하니 결과를 믿을 수 있어요.
끝나면층별 면적표 + 설계비 산정표가 든 엑셀 파일 1개, 시트 정리 매크로 1개
필요한 것PC, 엑셀(Microsoft 365 권장), 끝난 프로젝트 면적표 1건, 1시간 · 구글 시트로 하려면 강의
  1. Claude는 설정 → 기능(Capabilities) → 코드 실행 및 파일 생성을 켜면 무료 플랜에서도 .xlsx 파일을 만들어 내려받게 해 줘요. ChatGPT도 채팅에서 스프레드시트 파일을 만들어 내려받게 해 줘요. 아래 '양식 부탁문'을 보내고 받은 파일을 열어요.막히면: 파일 대신 표만 나오면 "xlsx 파일로 만들어서 내려받기 링크를 줘"라고 한 번 더 말해요.
  2. 합계 칸을 눌러 위쪽 수식 입력줄에 =SUM(…)처럼 수식이 보여야 해요. 숫자만 적혀 있으면 AI가 계산해 넣은 거예요. "모든 계산 칸을 엑셀 수식으로 바꿔 줘"라고 다시 부탁해요.
  3. 이미 허가받은 프로젝트 숫자를 넣어 허가 도서의 연면적·용적률과 같은지 봐요. 설계비는 실제 계약서 금액과 비교해요. 맞아야 새 일에 써요.
  4. 엑셀 창 안에서 바로 물어볼 수도 있어요.
    어떤 게 있나요접기
    1. Claude in Excel: Microsoft AppSource에서 'Claude for Microsoft 365'를 받아 Claude 계정으로 로그인해요. Pro 이상 유료 플랜용이에요. 윈도우(Microsoft 365), 맥(16.46 이상), 웹 엑셀에서 돼요. 수식 설명, #REF! 오류 원인 찾기, 표 정리를 해요. 매크로·VBA는 못 다뤄요.
    2. 엑셀 Copilot: Microsoft 365 Personal·Family 구독에 들어 있어요(Family는 구독 주인만). 파일을 OneDrive에 저장해 두면 안전해요.
    3. 엑셀 2016·2019 같은 영구 라이선스는 둘 다 안 될 수 있어요. 그때는 1번처럼 채팅에서 파일을 받아요
  5. 프로젝트마다 하는 '빈 줄 지우기·숫자 서식 맞추기·인쇄 영역 잡기'를 버튼 하나로 해요. 꼭 파일 사본에서 먼저 해요. 매크로로 바뀐 것은 되돌리기(⌘+Z / Ctrl+Z)가 안 돼요.
    자세히 따라 하기접기
    1. 맥: Excel → 환경설정 → 리본 및 도구 모음 → 기본 탭 → 개발 도구 체크 → 저장
    2. 윈도우: 파일 → 옵션 → 리본 사용자 지정 → 개발 도구 체크 → 확인
    3. 개발 도구 → Visual Basic → 왼쪽 파일 이름에서 오른쪽 클릭 → 삽입 → 모듈 → AI가 준 코드 붙여 넣기
    4. 엑셀로 돌아와 개발 도구 → 매크로 → 이름 고르고 실행
    5. 저장할 때 형식을 Excel 매크로 사용 통합 문서(.xlsm)로 골라요. 그냥 .xlsx로 저장하면 코드가 사라져요
    막히면: 노란 줄이나 오류 창이 뜨면 그 글자를 그대로 복사해 "이 오류가 났어. 고친 코드 전체를 다시 줘"라고 보내요(강의).

면적표는 '02 대지·법규 검토' 채팅, 설계비 표와 VBA는 '01 사무장·정산' 채팅에 붙여 넣어요. ○○ 자리만 바꿔요.

양식 부탁문 (엑셀 파일 받기)
엑셀(.xlsx) 파일을 만들어 줘. 시트 3개:
1) 층별면적: 층 | 용도 | 바닥면적(㎡) | 용적률 제외(㎡) | 제외 사유 | 산정용 면적(㎡). 맨 아래 연면적·산정용 연면적 합계
2) 한도: 대지면적, 건축면적, 건폐율=건축면적/대지면적, 용적률=산정용 연면적/대지면적, 한도 칸과 비교해 '적합/초과'
3) 설계비: 공사비 | 요율(%) | 설계비 = 공사비×요율 | 부가세 | 합계. 요율 칸은 비워 두고 '근거' 칸을 옆에 둬
조건: 모든 계산은 엑셀 수식으로(숫자를 직접 넣지 말 것), 입력 칸은 노란색, 소수점 둘째 자리, 인쇄 시 A4 가로 한 장. 나는 엑셀 수식을 잘 몰라서 칸마다 무슨 수식인지 표로 설명해 줘.
VBA 부탁문
엑셀 VBA 매크로를 만들어 줘. 나는 코딩을 몰라.
하는 일: 현재 시트에서 B열이 빈 줄을 모두 지우고, C~F열 숫자를 '#,##0.00' 서식으로, A1부터 마지막 줄까지 인쇄 영역으로 잡고 A4 가로 한 장에 맞추기.
조건: 실행 전에 "정말 실행할까요?" 확인 창을 띄우고, 시트를 먼저 '백업_날짜' 이름으로 복사해 둔 뒤 작업해. 맥 엑셀과 윈도우 엑셀 둘 다 되게.
① 붙여 넣을 곳 ② 실행 방법 ③ .xlsm 저장법을 번호 순서로 알려 줘. 고칠 때는 전체 코드를 다시 줘.
법령 MCP로 근거 확인강의

설계비 요율은 AI가 기억으로 채우면 틀려요. 공공 발주 건은 「건축사법」 제19조의3에 따라 국토교통부 고시 「공공발주사업에 대한 건축사의 업무범위와 대가기준」을 적용해요. 민간 건은 이 기준을 준용할 수 있어요. 면적 산정은 「건축법 시행령」 제119조가 근거예요. 요율·근거 칸은 원문을 확인한 뒤에 채워요.

법령 MCP 부탁문
법령 MCP의 search_law → get_law_text로 「건축사법」 제19조의3 원문을 시행일과 함께 인용해 줘. 이어서 행정규칙(고시) 「공공발주사업에 대한 건축사의 업무범위와 대가기준」을 그대로 검색해 현행 발령일과, 공사비 구간별 설계 대가 요율표가 있는 별표를 찾아 줘. 「건축법 시행령」 제119조에서 연면적·용적률 산정 때 빼는 면적 항목도 원문으로. 엑셀 '근거' 칸에 넣을 수 있게 '법령명 · 조문/별표 · 시행일(발령일)' 형식으로 정리해. 못 찾으면 '확인 필요'.

AI 숫자는 그대로 쓰지 않아요. 엑셀 수식 값 = 허가 도서 숫자 = AI 검산, 셋이 맞을 때만 계약서·도서에 써요.

이 강의 자동화도구 고르는 법은 강의
  • 수식
    입력하면 바로 적합/초과층별 면적만 바꾸면 건폐율·용적률·설계비가 다시 계산돼요.
  • 매크로
    버튼 하나로 출력 정리VBA 매크로를 '양식.xlsm'에 넣어 두고 프로젝트마다 복사해 써요.
