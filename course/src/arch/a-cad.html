실습 · 약 40분 · PC

레이어 정리와 면적 합계, 명령어 한 줄로 끝내기

AI에게 AutoLISP(오토캐드에 붙이는 작은 프로그램)를 받아, 복사본 도면에서 불러오고 실행해요. 연습 과제는 두 개예요. ① 'TEMP' 레이어 끄고 치수 레이어 색 바꾸기 ② 실 경계선(닫힌 폴리선) 면적을 레이어별로 더해 표로 내보내기.

이게 뭐예요오토캐드에 '단축 명령어'를 새로 하나 만들어 주는 거예요. 열 번 클릭하던 일을 명령어 한 줄로 해요.
끝나면내 오토캐드에 TEMPOFF·AREASUM 두 명령어, 실별 면적 CSV(엑셀에서 열리는 표 파일)
필요한 것오토캐드가 깔린 PC, 연습용 도면 복사본, 40분 · 코드 붙이기가 처음이면 강의 먼저
AI 스크립트 공통 순서모든 AutoLISP에 같아요
① 받기버전·맥/윈도우를 적고 부탁문 보내기
② 저장메모장(맥은 텍스트 편집기)에 붙여 .lsp로 저장
③ 불러오기명령행에 APPLOAD → 파일 고르기 → 로드
④ 실행복사본 도면에서 명령어 입력 → 확인 → 이상하면 UNDO

내 오토캐드에서 되는지 먼저 봐요. 일반 오토캐드는 윈도우·맥 모두 AutoLISP가 돼요. AutoCAD LT는 2024 윈도우판부터 AutoLISP를 지원해요.

맥에서는 일부가 안 돼요. 맥용 오토캐드는 ActiveX(윈도우 전용 연결 기술)가 없어서, 이름이 vla-, vlax-로 시작하는 함수가 대부분 안 돌아요. Visual LISP 편집기도 윈도우 전용이에요. 그래서 부탁문에 "맥용, vla- 함수 쓰지 마"를 꼭 넣어요. AutoCAD LT 맥판은 LISP를 지원하지 않는다는 사용자 답변이 많으니 메뉴에서 먼저 확인하세요.

  1. 스크립트는 한 번에 도면 전체를 바꿔요. 원본 옆에 '도면이름_시험.dwg'를 만들고 거기서만 연습해요.막히면: 파일 탐색기(맥은 Finder)에서 도면을 고르고 복사·붙여넣기 한 뒤 이름만 바꾸면 돼요.
  2. 아래 '레이어 정리 부탁문'의 괄호를 우리 사무소 레이어 이름으로 바꿔 보내요. 도면 파일은 올리지 않아도 돼요. 레이어 이름 목록만 있으면 충분해요.
    자세히 따라 하기접기
    1. 오토캐드에서 LAYER 입력 → 레이어 관리자 화면을 캡처(강의)
    2. 캡처에 건축주 이름이나 현장 주소가 보이면 가리고 보내요
    3. 받은 코드 전체를 복사
  3. 자세히 따라 하기접기
    1. 메모장 열기 → 붙여넣기 → 파일 → 다른 이름으로 저장 → 파일 형식 '모든 파일', 이름 tempoff.lsp, 인코딩은 AI가 알려 준 대로
    2. 텍스트 편집기 열기 → 포맷 → 일반 텍스트로 만들기 → 붙여넣기 → 이름 tempoff.lsp로 저장'.txt를 붙일까요?' 창이 뜨면 '.lsp 사용'을 눌러요.
    3. 사무소 공용 폴더에 'LISP' 폴더를 만들어 모아 두기
    4. 오토캐드 명령행에 APPLOAD → 파일 고르기 → 로드 → 닫기막히면: '보안 경고' 창이 뜨면 내가 만든 파일일 때만 '한 번 로드'를 눌러요. 남이 보낸 파일이면 AI에게 "이 코드가 무슨 일을 해?"라고 먼저 물어요.
  4. 명령행에 TEMPOFF 입력 → 레이어가 바뀌었는지 확인 → 일부러 UNDO를 한 번 눌러 되돌아가는지도 봐요. 스크립트 시작에 UNDO 묶음을 넣어 달라고 했으면 한 번에 전부 되돌아가요.
  5. 실 경계 레이어(예: A-AREA)에 닫힌 폴리선이 있어야 해요. 아래 '면적 합계 부탁문'을 보내고 같은 순서로 불러와 AREASUM을 실행해요. 나온 CSV는 엑셀 면적표(강의)나 면적·주차 검토표(강의)에 붙여요.막히면: 명령행에 나온 빨간 글자(오류)를 그대로 복사해 "이 오류가 났어. 고친 코드 전체를 다시 줘"라고 보내요(강의).
레이어 정리 부탁문
나는 건축사사무소 소장이고 코딩은 몰라. (오토캐드 2027 / 윈도우 또는 맥 / LT인지 일반인지) 를 써.
현재 도면에서 이름에 'TEMP'가 들어간 레이어를 모두 끄고, 치수 레이어(이름: A-DIMS)의 색을 8번으로 바꾸는 AutoLISP를 만들어 줘.
- 명령어 이름은 TEMPOFF
- 시작할 때 UNDO 묶음(_UNDO _Begin)을 걸고 끝에 _End, 그래서 UNDO 한 번에 전부 되돌아가게
- 끝나면 명령행에 '꺼진 레이어 ○개, 색 바꾼 레이어 ○개'라고 보여 줘
- 맥이거나 LT라면 vla-·vlax- 함수와 Express Tools(acet-) 함수는 쓰지 마
불러오는 법(APPLOAD)과 실행 명령어를 순서대로 알려 주고, 고칠 때는 전체 코드를 다시 줘.

괄호 안과 레이어 이름을 우리 사무소 것으로 바꿔 '설계 프로그램 도우미' 채팅에 붙여 넣으세요.

면적 합계 부탁문
같은 조건으로 AutoLISP를 하나 더 만들어 줘. 명령어 이름은 AREASUM.
- 레이어 A-AREA에 있는 닫힌 폴리선마다 면적(㎡, 도면 단위가 mm면 1,000,000으로 나눠서)을 구해
- 폴리선 안의 문자(실 이름)를 찾아 같이 적고, 없으면 '이름 없음'
- 층 구분은 폴리선이 있는 레이아웃이 아니라 문자 'F1', 'F2' 같은 층 표시 레이어 A-FLOR 기준
- 결과를 도면과 같은 폴더에 '면적표_날짜.csv'로 저장(층, 실 이름, 면적, 소수 둘째 자리)
- 열린 폴리선은 세지 말고 '열린 선 ○개 건너뜀'이라고 알려 줘
도면은 고치지 말고 읽기만 해 줘.
법령 MCP로 근거 확인강의

AREASUM은 그린 선대로 더해요. 그런데 바닥면적은 벽·기둥의 중심선으로 재고, 발코니(노대)는 일정 폭을 빼고 넣어요(건축법 시행령 제119조 제1항 제3호). 실 경계 폴리선을 벽 안쪽 선으로 그렸다면 법정 면적과 달라져요. 그리는 기준을 정하기 전에 원문을 받아 사무소 규칙에 적어 두세요.

바닥면적 기준 확인 부탁문
법령 MCP의 search_law → get_law_text로 건축법 시행령 제119조 제1항 제3호(바닥면적) 원문을 찾아 시행일과 함께 인용해 줘.
1. 벽 중심선 기준, 노대등 면적 빼는 계산(가장 긴 외벽 길이 × 1.5m), 필로티·다락을 빼는 조건을 오토캐드에서 폴리선 그리는 규칙으로 바꿔 줘(어느 선을 따라 그릴지).
2. 연면적에서 용적률 산정 때 빼는 면적(같은 조 제4호)도 표로.
3. 조례로 정하는 값이 걸리면 ordinance_radar(또는 자치법규 검색)로 (○○시) 조례를 찾아 줘.
못 찾거나 해석이 갈리면 '확인 필요'라고 쓰고 추측하지 마.
이 강의 자동화도구 고르는 법은 강의
  • LISP
    명령어 하나로 정리레이어 끄기·색 바꾸기·면적 합계를 TEMPOFF·AREASUM으로. 사무소 공용 'LISP' 폴더에 모으면 직원 모두 같은 명령어를 써요.
  • AI
    Autodesk Assistant (오토캐드 안의 AI)오토캐드 2027 윈도우판의 Autodesk Assistant는 조건으로 객체 고르기(예: 특정 레이어의 특정 블록), 길이 0인 선 찾기, 표준 도면(.dwt·.dws)과 비교 검사를 해요. 아직 미리보기(기술 프리뷰)이고 도면 그리기·고치기나 PDF 내보내기는 안 된다고 안내돼 있어요.
  • 맥
    맥판 AI 비서2027 맥판에도 AI 안내 비서가 들어왔지만, 윈도우판처럼 작업을 직접 해 주는(MCP 기반) 비서는 아직 맥에서 안 된다고 안내돼 있어요. 메뉴에서 확인하세요.
