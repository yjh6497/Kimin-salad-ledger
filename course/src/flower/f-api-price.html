매일 아침, 어제 경매 시세가 장부에 들어와요

화면에서 시세를 캡처하던 일(강의)을 자동으로 바꿔요. 화훼유통정보 오픈 API(프로그램끼리 자료를 주고받는 창구)가 품목·품종·등급별 최고·평균·최저 단가와 거래량을 줘요. 스크립트가 이 값을 '경매시세' 탭에 날마다 쌓아요. 내가 자주 쓰는 꽃이 지난주보다 많이 오르면 알려 줘요. 오른 값은 상품 원가(강의)에 바로 반영돼요.

이게 뭐예요장부에 '알람 시계'를 달아 두는 거예요. 매일 아침이 되면 시트가 알아서 어제 꽃 경매 값을 받아 적고, 많이 오른 꽃은 알려 줘요.
끝나면날마다 쌓이는 '경매시세' 탭, 많이 오른 꽃 알림 메일, 시세를 따라 저절로 바뀌는 상품 원가
필요한 것PC, '꽃집 운영 장부' 시트, 화훼 API 키(앞 강의에서 넣은 것), 2시간 · 코드 붙이기가 처음이면 강의 먼저
'경매시세' 탭 한 줄 · 예시숫자는 지어낸 예시예요

단가최고 ○○ · 평균 ○○ · 최저 ○○ · 거래량 ○○
지난주 대비평균 +28% → '내 꽃' 목록이라 알림
  1. 모든 품목을 볼 필요는 없어요. 실제로 사는 꽃 10~20가지만 [품목 | 품종(비우면 전체) | 쓰는 등급 | 알림 기준 %] 로 적어요. 예: 장미, 카네이션, 거베라, 리시안셔스, 안개꽃, 국화.
  2. 아래 부탁문을 보내고, 받은 코드를 '꽃집 운영 장부'의 Apps Script에 붙여 넣어요. 키는 앞 강의에서 넣은 스크립트 속성 FLOWER_KEY를 읽어요.
    자세히 따라 하기접기
    1. 확장 프로그램 → Apps Script → 왼쪽 + → 스크립트 → 이름 '경매시세' → 받은 코드 붙여 넣기 → 저장
    2. 함수 fillAuction을 고르고 실행 → 권한 허용'Google에서 확인하지 않은 앱'은 내가 만든 스크립트라 뜨는 정상 안내예요. 고급 → 이동 → 허용.
    3. '경매시세' 탭에 줄이 생겼는지 확인. 빨간 오류가 나면 오류 문장을 그대로 같은 채팅에 붙여 넣기
  3. 메뉴 꽃집 데이터 → 지난 4주 채우기를 한 번 눌러 비교할 바탕을 만들어요. 경매가 없는 날은 결과가 비어 있는 게 정상이에요.
  4. Apps Script 왼쪽 시계 모양 트리거 → + 트리거 추가 → fillAuction · 시간 기반 · 일 단위 · 오전 6~7시. 경매 결과가 늦게 확정되는 날도 있으니 오전 10시 한 번 더 걸어 두면 빠짐이 줄어요.
  5. '구성' 탭(꽃다발별 들어가는 꽃 수량)의 꽃값 칸을 '경매시세' 최근 7일 평균 × 도매 가산율(내가 정한 값, 예: 1.3)로 바꾸면 상품 원가가 저절로 따라와요. 가산율은 실제 영수증과 몇 주 비교해서 맞춰요.
경매 시세 수집 스크립트 부탁문
구글 시트 '꽃집 운영 장부'에 붙일 Apps Script를 만들어 줘. 나는 코딩을 몰라.
[호출] https://flower.at.or.kr/api/returnData.api
  파라미터: kind=f001, serviceKey=(스크립트 속성 FLOWER_KEY), baseDate=YYYY-MM-DD,
            flowerGubn=1(절화), dataType=json, countPerPage=5000
  응답: response.resultCd, response.items 배열(항목이 하나면 객체로 올 수 있음)
        각 항목 pumName(품목) goodName(품종) lvNm(등급) maxAmt minAmt avgAmt totAmt totQty
  ※ 위 이름은 공개된 예제 코드 기준이야. 첫 실행 때 응답 원문 앞부분을 '로그' 탭에 남겨서 필드 이름이 다르면 맞춰 줘.
[저장] '경매시세' 탭: 날짜 | 구분 | 품목 | 품종 | 등급 | 최고 | 평균 | 최저 | 거래량 | 거래금액
  - 같은 날짜를 다시 받으면 그 날짜 줄을 지우고 새로 쓰기(중복 금지)
  - 숫자의 쉼표는 지우고 숫자로
[함수] fillAuction(): 어제 날짜 / fillPast(28): 지난 28일 / 경매 없는 날은 건너뛰기
[알림] '내 꽃' 탭 목록(품목, 품종, 등급, 알림 기준 %)만 보고,
  최근 3거래일 평균이 그 전 4주 평균보다 기준 % 이상 오르거나 내리면 '시세알림' 탭에 한 줄 + 나에게 메일
[메뉴] 꽃집 데이터 → 어제 시세 받기 / 지난 4주 채우기 / 시세 알림 보기
키는 시트·로그에 절대 쓰지 말고, 오류가 나면 초보가 할 일을 한 줄로 '로그' 탭에 적어 줘.

'꽃집 운영 장부'의 '경매시세' 최근 2주, '주문' 탭의 이번 주 예약, '구성' 탭을 보고
이번 주 사입 목록을 만들어 줘.
1) 표: 품목 | 품종 | 필요 수량(단) | 최근 평균 단가 | 예상 금액 | 지난주 대비
2) 많이 오른 꽃은 비슷한 색·느낌의 대체 꽃 2가지 (최근 시세 함께)
3) 예약이 몰린 날 전에 사야 할 것과 당일 사도 되는 것
시세는 경매가라 도매상 값은 더 높다는 점을 전제로, 숫자가 없는 건 지어내지 말고 '없음'.

경매가는 농가 → 도매 단계 값이에요. 도매상에서 사는 값과 다르니, 자동 원가는 '방향'을 보는 용도로 쓰고 실제 영수증 값으로 가산율을 맞춰요. 시세 숫자를 손님 안내나 광고에 그대로 쓰지 마세요.
