시세·대목·날씨·배송지, 꽃집에 붙는 공공데이터 여섯 줄

꽃집 일의 큰 흐름은 사입 → 대목 준비 → 제작 → 배송이에요. 단계마다 나라가 무료로 여는 데이터가 있어요. 이 강의에서는 어떤 데이터가 어디에 쓰이는지 한 장으로 봐요. 그리고 필요한 인증키(자료를 받을 때 쓰는 비밀번호)를 한 번에 받아 '꽃집 운영 장부'에 보관해요. 이 단계의 나머지 강의는 모두 이 키를 써요.

이게 뭐예요나라가 여는 무료 자료실의 '출입증'을 미리 받아 두는 거예요. 출입증만 있으면 시트가 시세·날씨·학교 일정을 알아서 가져와요.
끝나면세 곳의 인증키가 장부의 스크립트 속성에 안전하게 들어가고, '키점검' 탭에서 키가 되는지 확인돼요.
필요한 것PC, 휴대폰(본인 인증), 구글 계정, '꽃집 운영 장부' 시트, 1시간 · 스크립트를 처음 붙인다면 강의 먼저

개업 준비라면시세·학교 데이터만 먼저 받아도 첫 대목 준비가 훨씬 쉬워요. 날씨·배송은 문 연 뒤에 붙여도 늦지 않아요.

이미 운영 중이라면지난해 대목 매출과 올해 경매 시세를 같은 시트에 두면 "작년보다 얼마나 더 사야 하나"를 숫자로 정할 수 있어요.

모든 API(자료를 프로그램으로 받아 오는 창구)는 같은 순서예요. ① 사이트 가입 → ② 활용(이용) 신청 → ③ 인증키 복사 → ④ AI에게 앱스 스크립트 받기 → ⑤ 키는 코드가 아니라 스크립트 속성(장부 안의 비밀 금고)에 저장 → ⑥ 트리거(정해진 시간에 저절로 실행되게 하는 알람)로 매일 자동 실행. 마지막에 이 모든 결과를 아침 브리핑 한 통으로 묶어요(강의).

키 받기: 세 군데면 끝나요

  1. 공공데이터포털은 키 하나로 여러 API를 써요. API마다 활용신청만 따로 눌러요.
    자세히 따라 하기접기
    1. PC에서 data.go.kr → 회원가입 → 개인회원을 눌러요. 휴대폰으로 본인 인증을 해요
    2. 검색창에 위 표의 이름을 하나씩 넣어요. 'API'라고 적힌 결과에서 활용신청을 눌러요. 활용 목적은 "꽃집 내부 운영 참고"로 쓰고 신청해요
    3. 마이페이지 → 데이터활용 → Open API → 활용신청 현황에서 일반 인증키(Decoding)를 복사해요승인 직후에는 키가 바로 안 될 수 있어요. 몇 시간 뒤 다시 해 보세요. 장례식장 현황은 파일(CSV)로 받아도 충분해요.
  2. 화훼 경매 시세 API는 공공데이터포털이 아니라 aT 화훼유통정보에서 따로 키를 받아요.
    자세히 따라 하기접기
    1. flower.at.or.kr 접속 → 회원가입을 해요
    2. 메뉴에서 오픈 API(정보 공개) 안내 화면을 찾아 이용 신청을 해요. 승인되면 서비스키를 복사해요메뉴 이름이 바뀌었으면 첫 화면을 캡처해 AI에게 "오픈 API 신청은 어디야?"라고 물어보세요.
  3. 졸업식·입학식 날짜를 가져오려면 나이스 키가 따로 필요해요.
    자세히 따라 하기접기
    1. open.neis.go.kr 접속 → 회원가입 → 로그인을 해요
    2. 인증키 신청 화면에서 활용 목적을 "꽃집 대목 일정 확인"으로 써요. 발급된 키를 복사해요키 없이도 시험 호출(시험 삼아 요청 보내기)은 되지만 가져오는 줄 수가 적어요. 키를 받아 쓰세요.
  4. 키를 코드 안에 적으면 코드를 남에게 복사해 줄 때 같이 새어 나가요. 그래서 따로 금고에 넣어요. '꽃집 운영 장부'에서 확장 프로그램 → Apps Script → 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성 → 속성 추가를 눌러요. 아래 이름으로 하나씩 넣고 저장해요. 막히면: 이름은 대문자·밑줄까지 똑같이 써야 해요. 키 앞뒤에 빈칸이 들어가지 않았는지도 봐요.
스크립트 속성 이름 (이대로 쓰면 뒤 강의 부탁문과 맞아요)
DATA_GO_KR_KEY   = 공공데이터포털 일반 인증키(Decoding)
FLOWER_KEY       = 화훼유통정보 서비스키
NEIS_KEY         = 나이스 인증키
SHOP_LAT, SHOP_LON = 꽃집 위도·경도 (네이버 지도에서 가게를 길게 눌러 나오는 좌표)
키가 되는지 한 번에 확인하는 부탁문
'꽃집 운영 장부' 구글 시트에 붙일 Apps Script를 만들어 줘.
스크립트 속성 DATA_GO_KR_KEY, FLOWER_KEY, NEIS_KEY를 읽어서 각각 아주 작은 요청을 한 번씩 보내고,
'키점검' 탭에 [이름 | 성공/실패 | 받은 줄 수 | 오류 메시지 | 확인 시각]을 적는 함수 checkKeys를 만들어 줘.
- 공공데이터포털: 한국천문연구원_특일 정보의 공휴일 조회, 올해 1월
- 화훼유통정보: 경매 시세(kind=f001), 지난 평일 하루, 절화
- 나이스: 학교기본정보, 학교 이름 '○○초등학교'
키 값은 시트나 로그에 절대 쓰지 말고, 실패하면 초보가 할 일을 한 줄로 적어 줘.
시트 메뉴 '꽃집 데이터 → 키 점검'으로 실행되게 해 줘.
