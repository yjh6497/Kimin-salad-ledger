새 리뷰가 오면 휴대폰이 울리고, 답글 초안이 30초 안에

네이버 플레이스와 카카오맵에 리뷰가 달리면 바로 알림을 받아요. 리뷰를 복사해 한 번 누르면 AI가 답글 초안 3개와 급한 정도를 제안해요. 이 흐름을 만들어요. {{owner:은}} 하나 골라 한 줄 고치고 올리기만 해요.

이게 뭐예요리뷰가 오면 '초인종'이 울리고, 답장 초안은 AI 비서가 써 주는 거예요. 올리는 건 {{owner:이}} 직접 해요.

알림은 각 회사의 공식 앱이, 답글 초안은 AI가, 게시는 {{owner:이}}. 자동으로 올리지는 않아요.

왜 완전 자동이 아닌가요? 네이버와 카카오는 리뷰를 읽고 답글을 올리는 공개 API를 {{owner}}들에게 열어 두지 않았어요. 리뷰를 긁어 오거나 답글을 자동으로 올린다는 비공식 프로그램·매크로도 있어요. 하지만 계정 제한 위험이 있어요. {{place}} 이름으로 잘못된 답이 올라갈 수도 있어요. 그래서 이 강의는 공식 앱 알림 + AI 초안 + {{owner}} 게시로 시간을 줄여요.

  1. 자세히 따라 하기접기
    1. 네이버: 휴대폰 네이버 스마트플레이스센터 앱 → {{place}} 아이디 로그인 → 앱 설정의 알림에서 리뷰 알림 켜기
    2. 카카오: 카카오비즈니스 파트너센터 앱(또는 카카오톡 채널 관리자 앱) → {{place}} 계정 로그인 → 알림 설정에서 매장 후기·채팅 알림 켜기
    3. 휴대폰 설정 → 알림에서 두 앱의 알림이 허용돼 있는지 확인. {{work}} 중엔 소리 대신 배너로알림 항목 이름은 앱 업데이트로 바뀌어요. 안 보이면 설정 화면을 캡처해 AI에게 "새 리뷰 알림은 어디서 켜?"라고 물어보세요.
  2. 매번 설명하지 않으려는 거예요. '01 플레이스 매니저' 채팅에 아래 '답글 규칙'을 한 번 보내 둬요. 그 뒤로는 리뷰만 붙여도 같은 규칙으로 답해요. {{owner:이}} 마음에 든 답글 3개를 함께 보여 주면 말투까지 맞춰요.
  3. 부탁문을 매번 찾아 붙이지 않으려는 거예요. 리뷰를 복사한 뒤 단축어를 한 번 누르면 부탁문과 리뷰가 합쳐져요. 합친 글은 클립보드(복사해 둔 글이 잠깐 머무는 곳)에 담기고 AI 앱이 열려요. 붙여 넣기만 하면 돼요.
    아이폰 · 단축어 앱접기
    1. 단축어 앱 → 오른쪽 위 + → 이름 리뷰 답글
    2. 동작 추가: 클립보드 가져오기
    3. 동작 추가: 텍스트 → 아래 '단축어용 짧은 부탁문'을 붙여 넣고, 맨 끝에 변수 클립보드를 넣기
    4. 동작 추가: 클립보드에 복사(방금 만든 텍스트) → 앱 열기 → Claude 또는 ChatGPT
    5. 완료 → 길게 눌러 홈 화면에 추가. 쓰는 법: 리뷰 길게 눌러 복사 → 단축어 누르기 → AI 앱의 '01 플레이스 매니저' 채팅에 붙여 넣기처음 실행 때 클립보드 접근 허용을 물어보면 '항상 허용'을 누르세요.
    갤럭시 · 키보드 상용구접기
    1. 삼성 키보드 → 설정 → 스마트 입력 → 텍스트 단축키(또는 상용구) → 단축키 ㄹㅂ, 내용에 '단축어용 짧은 부탁문'
    2. 쓰는 법: AI 채팅창에 ㄹㅂ 입력 → 부탁문 선택 → 한 줄 띄우고 복사한 리뷰 붙여 넣기
  4. 리뷰가 많을 때 한 번에 정리하려는 거예요. Claude 유료 플랜에서 쓸 수 있는 크롬 확장 프로그램(Claude in Chrome)을 설치해요. 그러면 {{owner:이}} 로그인한 스마트플레이스 리뷰 화면을 Claude가 읽어요. 답글 안 한 리뷰 목록과 초안을 표로 정리해 줘요. 답글 게시 버튼은 {{owner:이}} 직접 눌러요.
    자세히 따라 하기접기
    1. PC 크롬에서 Claude 확장 프로그램 설치 → {{place}} Claude 계정 로그인
    2. 스마트플레이스 → 리뷰 화면을 열어 두고, 확장 프로그램 패널에 아래 'PC 모아 보기 부탁문'
    3. 사이트 접근 허용을 물으면 그 사이트만 허용. 표가 나오면 초안을 골라 {{owner:이}} 직접 붙여 넣고 등록Claude에게 '답글 등록'까지 맡기지 마세요. 칸에 입력까지 시험해 보고 싶다면 다음 강의의 연습판에서 먼저(강의).
  5. 별점 1~2점, 또는 '사고', '죽었''다쳤', '고소', '환불' 같은 말이 있으면 AI가 [급함]으로 표시해요. 급함은 그날 안에 {{owner:이}} 직접 확인해요. 필요하면 답글보다 전화를 먼저 해요(강의).
  6. 알림이 올 때마다 답하면 일이 끊겨요. 점심시간과 진료 마감하루 마감 뒤, 하루 두 번 쌓인 리뷰를 몰아서 답해요. 리뷰 탭에 한 줄씩 남겨 두세요. 그러면 월요일 브리핑(강의)에 '답 안 한 리뷰 수'가 나와요.

    주간 리뷰 요약유료매주 월요일 "장부 리뷰 탭에서 지난주 네이버·카카오 리뷰 수, 평균 별점, 답 안 한 것, 반복된 불만"을 브리핑에 넣어요.무료월요일 휴대폰 알림이 울리면 같은 문장을 한 번 보내요.
