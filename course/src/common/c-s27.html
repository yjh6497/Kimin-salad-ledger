화면은 예시입니다.

  1. 휴대폰에서 웹앱이나 홈페이지를 열고 첫 화면, 입력 화면, 결과 화면 3장. 직원 이름·연락처는 가리고 찍어요.
  2. '09 배달앱·매장 개선07 자동화 도우미' 채팅에 캡처와 아래 '디자인 리뷰' 부탁문을 보내요.
  3. {{place}} 대표색, 글꼴, 버튼 모양, 말투를 정해 두면 웹앱·홈페이지·메뉴판가격표·안내문·SNS가 한 {{place}}처럼 보여요.
    자세히 따라 하기접기
    1. 간판·로고·{{place}} 사진을 찍어 아래 '디자인 가이드' 부탁문과 함께 보내기
    2. 받은 가이드를 드라이브에 구글 문서 디자인 가이드로 저장
    3. 프로젝트 파일에 Google Drive로 추가 (업무일지 연결과 같은 방법). 이제 모든 직원 채팅이 같은 색과 글꼴을 써요
  4. 자세히 따라 하기 · Claude접기
    1. 왼쪽 아래 내 이름 → 설정 → 기능(Capabilities)에서 코드 실행과 파일 만들기 켜기
    2. 사용자 지정(Customize) → 스킬에서 디자인 관련 스킬(예: Frontend Design) 켜기목록에 없으면 마켓플레이스에서 찾거나, 대화에서 "web-artifacts-builder 스킬로 만들어줘"라고 요청해요.
    3. 필요하면 설정 → 커넥터에서 Canva나 Figma 연결 → 그 앱 계정으로 로그인 → 허용
    자세히 따라 하기 · ChatGPT접기
    1. 왼쪽 아래 내 이름 → 앱 및 커넥터에서 Canva나 Figma 찾기 → 연결 → 그 앱 계정으로 로그인 → 허용
    2. 대화에서 쓸 때는 입력창의 +에서 앱을 고르거나, 문장을 "Canva로…"처럼 앱 이름으로 시작
    3. 웹앱·홈페이지 코드는 캔버스에서 고쳐요. 디자인 가이드 문서를 함께 첨부하세요
  5. 여러 안을 보고 싶으면 Google Stitch(stitch.withgoogle.com)에 아래 '시안 요청' 문장을 넣어 3안을 받고, 마음에 드는 화면을 캡처하거나 HTML로 내보내요.
  6. 자세히 따라 하기접기
    1. 지금 코드를 준비해요. 웹앱은 Apps Script의 index 파일 전체 복사, 홈페이지는 GitHub의 index.html
    2. '08 자동화·연결07 자동화 도우미' 채팅에 코드 + 디자인 가이드 + (있으면) 고른 시안을 주고 아래 '디자인 적용' 부탁문 보내기
    3. 웹앱: index 파일에 새 코드를 붙여 저장 → 배포 → 배포 관리 → 연필 → 새 버전 → 배포 (주소 그대로)
    4. 홈페이지: GitHub 저장소에서 index.html 열기 → 연필 아이콘 → 새 코드로 바꾸기 → Commit changes바꾸기 전 코드는 메모장이나 구글 문서에 붙여 백업해 두세요. 이상하면 그대로 되돌리면 돼요.
  7. 아래 점검표로 직접 눌러 보고, 직원 한 명에게도 써 보게 해요.
  8. Canva 커넥터를 연결했다면 "디자인 가이드 색과 글꼴로 A4 메뉴판가격표·안내문을 Canva에 만들어줘". 만든 디자인은 Canva에서 열어 가격과 사진을 직접 고쳐요.
디자인 리뷰 부탁문
첨부한 캡처는 우리 {{biz}}의 ○○(직원 웹앱/홈페이지) 화면이야. 쓰는 사람은 ○○(알바생{{staff}}/{{customer}})이고 주로 휴대폰으로 써.
1) 첫눈에 무엇을 하는 화면인지 알 수 있는지
2) 글씨 크기, 버튼 크기, 색 대비가 휴대폰에서 충분한지
3) 자주 쓰는 기능이 찾기 쉬운 자리에 있는지
4) {{place}} 분위기와 어울리는지
문제점을 중요한 순서로 5개, 각각 어떻게 바꾸면 좋을지 알려줘.
디자인 가이드 부탁문
첨부한 간판·로고·{{place}} 사진을 보고 우리 {{biz}}의 디자인 가이드를 한 장으로 만들어줘.
대표색 1개와 보조색 2개(색 코드 포함), 제목·본문 글꼴(구글 폰트에서 무료로 쓸 수 있는 한글 글꼴), 버튼 모양과 크기, 사진 스타일, 문구 말투.
웹앱·홈페이지·메뉴판가격표·안내문·SNS에 똑같이 쓸 수 있게 정리하고, 글씨와 배경 색 대비가 충분한지도 확인해줘.
시안 요청 문장 · Google Stitch
{{biz}} 직원용 모바일 웹앱. 첫 화면에 큰 출근·퇴근 버튼, 그 아래 식자재 소진 입력과 마감 체크 버튼오픈·마감 체크리스트 버튼, 이번 주 근무표. 대표색 ○○, 밝고 깔끔한 느낌, 한국어, 엄지로 누르기 쉬운 큰 버튼.
디자인 적용 부탁문 · 자동화 엔지니어자동화 도우미
첨부한 코드는 우리 {{place}} ○○(직원 웹앱/홈페이지)이야. 기능과 서버 코드, 데이터 저장 방식은 하나도 바꾸지 말고 화면 디자인만 바꿔줘.
- 첨부한 '디자인 가이드'의 색·글꼴·버튼 모양을 따르기
- (있으면) 첨부한 시안 캡처의 배치를 참고하기
- 휴대폰 기준, 본문 글씨 16px 이상, 버튼은 엄지로 누르기 쉽게, 다크 모드에서도 잘 보이게
- 흔한 기본값 디자인 말고 우리 {{place}}만의 느낌으로
바뀐 코드 전체를 주고, 무엇을 바꿨는지 5줄로 요약해줘. 붙여 넣는 곳과 다시 배포하는 방법도 알려줘.
이 강의 자동화도구 고르는 법은 강의
  • 지침·스킬
    다음 화면도 같은 디자인완성한 디자인 가이드를 프로젝트 파일에 넣어 두면 새 웹앱·홈페이지를 만들 때 따로 말하지 않아도 같은 색·글꼴로 만들어요.
  • 웹앱
    바꾼 디자인은 새 버전으로웹앱은 배포 관리 → 새 버전으로 다시 배포하면 주소는 그대로예요. 문제가 생기면 이전 버전으로 되돌려요.
