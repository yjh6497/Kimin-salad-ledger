숫자는 예시예요.

  1. 근무 숫자를 그래프로 한눈에 보려고 해요. Looker Studio(시트 숫자를 그래프 화면으로 만드는 무료 도구) 보고서(강의)에서 페이지 → 새 페이지를 만들어요. 데이터 추가 → Google Sheets로 '직원 데이터' 요약 탭을 연결해요. 직원별 근무시간 막대와 요일·시간대별 근무 인원 표를 넣어요. 이 페이지는 {{owner}}만 봐요.막히면: 메뉴 이름이 다르면 화면을 캡처해 '06 성과 분석' 채팅에 "여기서 새 페이지와 데이터 추가는 어디야?"라고 물어요.
  2. 다음 달 근무표를 고칠 근거를 얻으려고 해요. 아래 부탁문을 '06 성과 분석' 채팅에 보내요. 유료면 매달 1일 예약 작업으로 걸어 둬요.
  3. 직원별 근무 기록 요약과 {{owner}} 메모를 주고 면담 질문을 받아요. 면담 기록은 직원과 함께 확인한 사실만 짧게 남겨요. AI에는 이름 대신 직원번호로 적어요.
