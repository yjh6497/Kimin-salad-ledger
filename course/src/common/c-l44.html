방법좋은 점이럴 때

③ 시트로 고치는 안내 화면 앱시트 한 줄로 추가, 기간 지나면 저절로 숨김, 오늘 {{hours}}·휴진휴무 자동, QR 자동, 10분마다 반영오래 쓸 때, 직원이 고칠 때
  1. 대기실 크기에 맞는 화면을 골라요. 작은 대기실은 태블릿 가로 거치대가 좋아요(접수 태블릿과 따로, 강의). 넓으면 안 쓰는 TV를 써요. 크롬캐스트(크롬 '전송'), 스마트 TV 브라우저, 또는 HDMI로 연결한 안 쓰는 노트북(강의) 중에서 골라요. 자동 잠금·절전은 꺼요. 진료영업 시작·끝에 맞춰 전원 타이머를 걸어요. 통신사의 매장 TV 안내 서비스(IPTV에 홍보 화면)도 있어요.
  2. 멀리서도 읽히는 짧은 글이 필요해요. 아래 '안내 화면 부탁문'을 '05 상담·응대' 채팅에 보내요. 안내 10~12장이 시트 줄(또는 슬라이드 문구)로 나와요. 제목은 20자, 본문은 3줄 안쪽이에요. 올리기 전에 광고 점검을 한 번 거쳐요.
  3. 코드 없이 오늘 바로 할 수 있는 방법이에요.
    자세히 따라 하기접기
    1. 구글 슬라이드에서 새 프레젠테이션 '대기실 안내'를 만들어요. 16:9 크기로, 글자는 40pt 이상으로 안내를 한 장씩 넣어요.
    2. 파일 → 공유 → 웹에 게시를 눌러요. 슬라이드 자동 넘기기(예: 10초), '슬라이드쇼 마지막에 다시 시작', '로드 후 바로 시작'에 체크해요. 게시를 누르고 링크를 복사해요.
    3. 태블릿·TV 브라우저에서 그 링크를 열고 전체 화면으로 해요. 슬라이드를 고치면 게시 화면도 바뀌어요(게시 설정의 '변경사항 자동 게시' 확인).막히면: 고쳐도 화면이 그대로면 '변경사항 자동 게시'가 켜져 있는지 보고, 화면을 새로고침해요.
  4. 오래 쓰거나 직원이 고칠 때 편한 방법이에요. 시트 한 줄이 안내 한 장이 돼요. 앱스 스크립트(시트에 붙이는 작은 프로그램) 코드 두 개를 붙여요.
    자세히 따라 하기접기
    1. 새 스프레드시트 '안내화면'을 만들고 탭 이름도 '안내화면'으로 바꿔요. 아래 제목 줄을 붙이고, 부탁문으로 받은 줄을 그 아래 붙여 넣어요. 사진을 넣으려면 드라이브에 올린 이미지의 파일 ID(주소 /d/ 뒤)를 '이미지' 칸에 적어요(1MB 안쪽 권장).
    2. 확장 프로그램 → Apps Script를 열어요. Code.gs 자리에 'Sign.gs'를 붙여요. + → HTML로 이름이 sign인 파일을 만들고 'sign.html'을 붙여요. 저장해요.
    3. 스크립트 속성(왼쪽 톱니바퀴 '프로젝트 설정' → 스크립트 속성)에 세 가지를 넣어요. SIGN_KEY(영문·숫자 12자 이상), CLINIC_NAME(병원가게 이름), HOURS(예: 9:00–19:00, 점심 13–14시)예요. 요일마다 다르면 HOURS_토 = 9:00–15:00처럼 따로 넣어요.
    4. 배포 → 새 배포 → 웹 앱(실행: 나, 액세스: 모든 사용자)으로 배포해요. 받은 URL 끝에 ?k=SIGN_KEY값을 붙여요. 태블릿·TV에서 열고 홈 화면에 추가해요.막히면: '권한 검토' 창이 뜨면 {{place}} 계정을 고르고 허용해요. '안내 화면 주소를 확인해 주세요'가 나오면 ?k= 뒤의 값이 SIGN_KEY와 똑같은지 봐요.
    5. 휴진휴무이 있는 날은 캘린더 '{{place}} 일정'(강의)에 "휴진 · 학회""휴무 · 개인 사정"처럼 넣으면 위쪽 띠가 바뀌어요.고친 내용은 10분 안에 화면에 반영돼요. 바로 보려면 화면을 한 번 새로고침해요.

// 대기실 안내 화면 (안내화면 시트의 Apps Script)
// 안내화면 탭: 순서 | 켜기(Y/N) | 시작일 | 끝일 | 제목 | 본문 | 이미지(드라이브 파일 ID) | QR 링크 | 초(보여 줄 시간)
var P = PropertiesService.getScriptProperties();

function doGet(e) {
  if (!e || !e.parameter || e.parameter.k !== P.getProperty('SIGN_KEY')) {
    return HtmlService.createHtmlOutput('<p style="font:20px sans-serif;padding:40px">안내 화면 주소를 확인해 주세요.</p>');
  }
  var t = HtmlService.createTemplateFromFile('sign');
  t.key = e.parameter.k;
  t.clinic = P.getProperty('CLINIC_NAME') || '우리 {{biz}}';
  return t.evaluate().setTitle(t.clinic + ' 안내').addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

function slides(key) {
  if (key !== P.getProperty('SIGN_KEY')) throw new Error('기기 확인 실패');
  var today = new Date(); today.setHours(0, 0, 0, 0);
  var rows = SpreadsheetApp.getActive().getSheetByName('안내화면').getDataRange().getValues().slice(1);
  var list = rows.filter(function (r) {
    if (r[1] !== 'Y' || !r[4]) return false;
    if (r[2] instanceof Date && r[2] > today) return false;        // 아직 시작 전
    if (r[3] instanceof Date && r[3] < today) return false;        // 기간 지남 → 저절로 숨김
    return true;
  }).sort(function (a, b) { return Number(a[0]) - Number(b[0]); }).map(function (r) {
    var img = '';
    if (r[6]) { // 드라이브 이미지를 화면에 바로 넣어요(공유 설정 없이)
      var blob = DriveApp.getFileById(String(r[6]).trim()).getBlob();
      img = 'data:' + blob.getContentType() + ';base64,' + Utilities.base64Encode(blob.getBytes());
    }
    return { title: r[4], body: String(r[5] || ''), img: img, qr: String(r[7] || ''), sec: Number(r[8]) || 12 };
  });
  return { slides: list, today: todayLine() };
}

function todayLine() { // 위쪽 띠: 오늘 {{hours}}·휴진휴무 ({{place}} 일정 캘린더에 '휴진휴무'이 있으면 그걸로)
  var s = new Date(); s.setHours(0, 0, 0, 0); var e = new Date(s); e.setDate(e.getDate() + 1);
  var cal = CalendarApp.getCalendarsByName('{{place}} 일정')[0];
  var off = cal ? cal.getEvents(s, e).filter(function (ev) { return ev.getTitle().indexOf('휴진휴무') >= 0; })[0] : null;
  if (off) return '오늘 ' + off.getTitle();
  var day = ['일', '월', '화', '수', '목', '금', '토'][new Date().getDay()];
  return '오늘(' + day + ') 진료영업 ' + (P.getProperty('HOURS_' + day) || P.getProperty('HOURS') || '');
}

        (s.qr ? '<div class="qr" id="qr"></div><small>휴대폰 카메라로 비춰 보세요</small>' : '') + '</div>';
    }
    st.innerHTML = '<div class="txt"><h1>' + esc(s.title) + '</h1><p>' + esc(s.body) + '</p></div>' + side;
    if (s.qr) { if (window.QRCode) new QRCode($('qr'), { text: s.qr, width: 400, height: 400 }); else $('qr').textContent = s.qr; } // QR이 안 그려지면 주소 글자로
    $('dots').innerHTML = LIST.map(function (_, k) { return '<i' + (k === i ? ' class="on"' : '') + '></i>'; }).join('');
    st.classList.remove('fade');
    timer = setTimeout(function () { i = (i + 1) % LIST.length; show(); }, s.sec * 1000);
  }, 600);

대기실 화면은 모두가 보는 게시판이에요. {{customer}} 이름·대기 번호와 이름을 함께, 진료일하는 중 사진, 직원 개인 정보는 띄우지 않아요. 반려동물{{customer}} 사진은 사진 활용 동의(강의)가 있는 것만. 화면 주소(키 포함)는 대기실 화면 기기에만 넣어요.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 발표 자료는 markitdown 자료.pptx -o 자료.md로 글자만 뽑아 올리면 그림까지 읽지 않아 가벼워요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
