장부의 글달력이 저절로 캘린더에

마케팅 장부 글달력(강의)에 적은 블로그·인스타·소식·카톡 발행일을 'SNS·콘텐츠' 캘린더에 옮겨요. 버튼 한 번이면 되고, 매일 밤 자동으로 하게 할 수도 있어요. 휴대폰에서 "오늘 올릴 글"이 바로 보여요.

이게 뭐예요장부에 적은 글 올릴 날짜를 휴대폰 달력에 대신 옮겨 적어 주는 심부름꾼을 두는 거예요.
끝나면휴대폰 구글 캘린더에 "오늘 올릴 글"이 날짜마다 떠요. 글달력을 고치면 다음 날 달력도 바뀌어요.
필요한 것PC, 마케팅 장부, 'SNS·콘텐츠' 캘린더, 40분 · 코드 붙이기가 처음이면 강의 먼저
  1. 같은 일정이 두 번 생기지 않게 하려는 칸이에요. 스크립트가 만든 일정 번호를 여기에 적어 둬요. K1 칸에 캘린더ID라고 적으면 돼요.
  2. 장부와 캘린더를 이어 주는 작은 프로그램을 장부에 붙여요. 아래 순서대로 따라 하면 돼요.
    자세히 따라 하기접기
    1. 마케팅 장부를 열고 확장 프로그램 → Apps Script로 들어가요. 새 파일에 아래 '글달력 → 캘린더 스크립트'를 붙여 넣고 저장해요.
    2. 위쪽 함수 목록에서 syncContent를 고르고 실행해요. 권한 허용 창이 뜨면 캘린더 접근을 허용해요. 막히면: '확인되지 않은 앱' 창이 나오면 고급 → (안전하지 않음)으로 이동 → 허용을 눌러요. 내가 만든 스크립트라 괜찮아요.
    3. 구글 캘린더 'SNS·콘텐츠'에 일정이 생겼는지 확인해요. 막히면: "캘린더가 없어요" 오류가 나면 캘린더 이름이 'SNS·콘텐츠'와 한 글자도 다르지 않은지 봐요.
    4. 왼쪽 시계 아이콘을 눌러 + 트리거 추가로 가요. syncContent, 시간 기반, 일 단위, 밤 11시~자정을 고르고 저장해요. 트리거는 정해진 시간에 저절로 실행되게 하는 알람이에요.
  3. 게시한 글과 아직인 글을 달력에서 바로 구별하려는 거예요. 상태를 '게시'로 바꾸면 다음 실행 때 일정 제목 앞에 ✓가 붙어요. 날짜를 바꾸면 일정도 그 날로 옮겨져요.

아래 코드를 그대로 복사해서 Apps Script 새 파일에 붙여 넣으세요. 고칠 곳은 없어요.

글달력 → 캘린더 스크립트
function syncContent() {
  var cal = CalendarApp.getCalendarsByName('SNS·콘텐츠')[0];
  if (!cal) throw new Error("'SNS·콘텐츠' 캘린더가 없어요. 이름을 확인하세요.");
  var sh = SpreadsheetApp.getActive().getSheetByName('글달력');
  var rows = sh.getDataRange().getValues();
  for (var i = 1; i < rows.length; i++) {
    var d = rows[i][0], ch = rows[i][2], topic = rows[i][3], st = rows[i][5], id = rows[i][10];
    if (!(d instanceof Date) || !topic) continue;
    var title = (st === '게시' ? '✓ ' : '') + '[' + ch + '] ' + topic + (st && st !== '게시' ? ' (' + st + ')' : '');
    var ev = id ? cal.getEventById(id) : null;
    if (ev) {
      if (ev.getTitle() !== title) ev.setTitle(title);
      var s = ev.getAllDayStartDate();
      if (s.toDateString() !== d.toDateString()) ev.setAllDayDate(d);
    } else {
      ev = cal.createAllDayEvent(title, d, { description: '대표키워드: ' + rows[i][4] });
      ev.addPopupReminder(15 * 60); // 전날 09시쯤 알림
      sh.getRange(i + 1, 11).setValue(ev.getId());
    }
  }
}

스크립트는 장부와 캘린더만 다뤄요. 네이버·인스타에 접속하거나 글을 올리지 않아요. 실제 게시는 예약 발행·예약 게시(강의, 강의)로 해요.

토큰 아끼기강의
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
  • 정기 브리핑·분석은 같은 채팅에 계속 쌓지 말고 달마다 새 채팅. 지난달 요약 10줄만 붙여 이어가요.
  • 주제가 바뀌면 새 채팅. 반복해서 쓰는 자료(소개서·규칙)는 프로젝트 파일에 한 번만 넣어 둬요.
