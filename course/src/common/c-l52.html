공식 API로, 승인한 글만 정한 시간에 저절로 올라가요

네이버와 달리 인스타그램은 공식 게시 API(Instagram API 콘텐츠 게시)가 있어요. 프로페셔널 계정(비즈니스·크리에이터)이면 내 계정에 사진·캐러셀·릴스를 프로그램으로 올릴 수 있어요. 시트에 글을 쌓고 → 텔레그램으로 승인하면 → 앱스 스크립트(클라우드)나 터미널 봇이 게시일시가 되면 자동 게시해요. 예약 게시(강의)를 익힌 다음 단계예요.

1 · 시트인스타 탭에 한 줄게시일시·캡션·이미지 주소
2 · 승인텔레그램 「승인」광고 점검·사진 동의 확인 후
3 · 봇15분마다 확인앱스 스크립트 또는 터미널
4 · API컨테이너 → 게시graph.instagram.com
5 · 알림"게시됨" 텔레그램미디어 ID가 시트에

릴스media_type=REELS와 영상 공개 주소. 처리 시간이 있어 상태(status_code)가 FINISHED가 된 뒤 게시
한도API 게시는 24시간 기준 한도가 있어요(문서에 100건, 계정에 따라 더 적을 수 있음). {{place:은}} 하루 1~2건이라 넉넉하지만, content_publishing_limit로 확인할 수 있어요

  1. 자세히 따라 하기접기
    1. developers.facebook.com → {{place}} 메타 계정으로 로그인 → 내 앱 → 앱 만들기(비즈니스 용도)
    2. 제품 추가에서 Instagram → 'Instagram 로그인으로 API 설정' → {{place}} 인스타 계정 연결 → 위 두 권한 허용
    3. 화면의 액세스 토큰 생성 → 토큰과 인스타 계정 ID(IG ID)를 복사. 이 토큰은 비밀번호예요, 채팅·시트에 붙이지 않고 스크립트 속성에만
    4. 내 계정에만 올리는 용도면 앱을 '개발 모드'로 두고, {{owner}} 계정이 앱 관리자·테스터로 등록돼 있으면 돼요. 메뉴 이름·심사 조건은 자주 바뀌니 화면 안내를 따라요'07 자동화 도우미'에게 지금 보이는 화면 캡처를 보여 주며 "다음에 뭘 눌러?"라고 물으면 빨라요. 토큰이 보이는 부분은 가리고.
  2. API는 파일을 올리는 게 아니라 주소를 알려 주면 Meta가 가져가는 방식이에요. 드라이브 공유 링크는 바로 안 되는 경우가 많아, 이미지만 두는 공개 저장소(예: 공개 GitHub 저장소, 무료 이미지 호스팅)를 하나 정하고 시험 1건으로 확인해요. 공개 주소라 누구나 볼 수 있으니 게시할 사진(동의 받은 것)만 올려요(강의).
  3. 장부(강의)에 '인스타' 탭 → 아래 제목 줄. '03 인스타 담당'이 만든 캡션(강의)을 광고 점검(강의) 뒤 한 줄씩. 상태는 '초안'으로 두고 텔레그램 승인함(강의)에서 「승인」을 누르면 '승인'으로 바뀌게(쓸 곳: 장부ID|인스타|B행).
  4. 자세히 따라 하기접기
    1. 장부 → 확장 프로그램 → Apps Script → 새 파일 Insta → 아래 'Insta.gs' 붙여 넣기
    2. 스크립트 속성: IG_TOKEN, IG_ID, (선택) TG_TOKEN·TG_CHAT
    3. 시험: 게시일시를 지금으로 한 줄(상태 '승인') → postDue 실행 → 인스타에 올라가고 시트에 미디어 ID가 남으면 성공
    4. 트리거: postDue 15분마다, refreshToken 매월 1일(장기 토큰은 약 60일이라 미리 새로 받아요). 컴퓨터를 켜 둘 필요가 없어요한 번 실행에 한 건만 올려요. 같은 시간에 여러 줄이 있으면 15분 간격으로 차례로 올라가요.
  5. 터미널이 편하면 {{owner}} 컴퓨터나 24시간 자동화 컴퓨터(강의)에서 Claude Code에게 '터미널 봇 부탁문'을 주세요. 사진 폴더 → JPEG 변환·크기 조정 → 공개 저장소에 올리기 → API 게시까지 한 스크립트로 만들고, 승인된 줄만 올리게 해요. 토큰은 .env 파일에 두고 저장소에 올리지 않아요.
  6. 텔레그램 "게시됨"을 받으면 앱에서 한 번 열어 사진 순서·캡션 줄바꿈을 확인해요. 댓글·DM은 여전히 사람이(강의). 실패하면 시트 메모에 오류가 남아요. 대부분 이미지 주소(공개 안 됨·JPEG 아님)나 토큰 만료예요.

// 인스타그램 공식 API 자동 게시 (장부 파일의 Apps Script)
// 인스타 탭: 게시일시 | 상태(초안/승인/게시됨/실패) | 종류(사진/캐러셀/릴스) | 캡션 | 이미지 URL(공개 JPEG, 캐러셀은 쉼표로 최대 10) | 영상 URL(릴스) | 결과(미디어 ID) | 메모
// 스크립트 속성: IG_TOKEN(장기 액세스 토큰), IG_ID(인스타 계정 ID), TG_TOKEN·TG_CHAT(선택)
var P = PropertiesService.getScriptProperties();
var IG = 'https://graph.instagram.com/';

function igPost(path, params) {
  params.access_token = P.getProperty('IG_TOKEN');
  var r = UrlFetchApp.fetch(IG + path, { method: 'post', payload: params, muteHttpExceptions: true });
  var j = JSON.parse(r.getContentText());
  if (j.error) throw new Error(j.error.message);
  return j;
}
function igGet(path) {
  var r = UrlFetchApp.fetch(IG + path + (path.indexOf('?') < 0 ? '?' : '&') + 'access_token=' + P.getProperty('IG_TOKEN'), { muteHttpExceptions: true });
  return JSON.parse(r.getContentText());
}
function waitReady(id) { // 영상은 처리 시간이 걸려요. 20초마다 최대 4분
  for (var k = 0; k < 12; k++) {
    var s = igGet(id + '?fields=status_code').status_code;
    if (s === 'FINISHED') return;
    if (s === 'ERROR' || s === 'EXPIRED') throw new Error('미디어 처리 실패: ' + s);
    Utilities.sleep(20000);
  }
  throw new Error('처리 시간이 길어요. 다음 실행 때 다시 시도');
}

function postDue() { // 트리거: 15분마다
  var sh = SpreadsheetApp.getActive().getSheetByName('인스타');
  var rows = sh.getDataRange().getValues(), now = new Date(), me = P.getProperty('IG_ID');
  for (var i = 1; i < rows.length; i++) {
    var r = rows[i];
    if (r[1] !== '승인' || r[6] || !(r[0] instanceof Date) || r[0] > now) continue;
    try {
      var cap = String(r[3] || ''), kind = r[2] || '사진', id;
      if (kind === '릴스') {
        id = igPost(me + '/media', { media_type: 'REELS', video_url: r[5], caption: cap }).id;
        waitReady(id);
      } else if (kind === '캐러셀') {
        var kids = String(r[4]).split(',').map(function (u) { return u.trim(); }).filter(String).slice(0, 10)
          .map(function (u) { return igPost(me + '/media', { image_url: u, is_carousel_item: 'true' }).id; });
        id = igPost(me + '/media', { media_type: 'CAROUSEL', children: kids.join(','), caption: cap }).id;
        waitReady(id);
      } else {
        id = igPost(me + '/media', { image_url: String(r[4]).split(',')[0].trim(), caption: cap }).id;
        waitReady(id);
      }
      var media = igPost(me + '/media_publish', { creation_id: id }).id;
      sh.getRange(i + 1, 2).setValue('게시됨');
      sh.getRange(i + 1, 7).setValue(media);
      notify('📸 인스타 게시됨 · ' + cap.split('\n')[0].slice(0, 40));
    } catch (e) {
      sh.getRange(i + 1, 2).setValue('실패');
      sh.getRange(i + 1, 8).setValue(String(e.message).slice(0, 300));
      notify('⚠️ 인스타 게시 실패 · ' + e.message);
    }
    return; // 한 번 실행에 한 건만, 천천히
  }
}

function refreshToken() { // 트리거: 매월 1일. 장기 토큰은 약 60일이라 미리 새로 받아요
  var j = JSON.parse(UrlFetchApp.fetch(IG + 'refresh_access_token?grant_type=ig_refresh_token&access_token=' + P.getProperty('IG_TOKEN')).getContentText());
  if (j.access_token) P.setProperty('IG_TOKEN', j.access_token); else notify('⚠️ 인스타 토큰 갱신 실패: 토큰을 다시 만들어 주세요');
}

function checkLimit() { // 24시간 게시 한도 사용량 확인
  Logger.log(JSON.stringify(igGet(P.getProperty('IG_ID') + '/content_publishing_limit?fields=quota_usage,config')));
}

function notify(t) {
  if (!P.getProperty('TG_TOKEN')) return;
  UrlFetchApp.fetch('https://api.telegram.org/bot' + P.getProperty('TG_TOKEN') + '/sendMessage', {
    method: 'post', payload: { chat_id: P.getProperty('TG_CHAT'), text: t }, muteHttpExceptions: true });
}
터미널 봇 부탁문 (Claude Code)
이 폴더에 인스타그램 공식 API로 자동 게시하는 파이썬 스크립트를 만들어 줘.
- 입력: 장부 '인스타' 탭을 CSV로 내려받은 파일(또는 구글 시트 API), 상태가 '승인'이고 게시일시가 지난 줄만
- 사진은 '인스타사진/날짜' 폴더에서: JPEG로 변환, 긴 변 1440px, EXIF 위치 정보 지우기
- 공개 저장소(○○)에 올려 공개 URL을 만든 뒤 graph.instagram.com의 /media → status_code 확인 → /media_publish
- 캐러셀(최대 10장), 릴스(처리 완료까지 기다리기) 지원
- 결과(미디어 ID·실패 이유)를 CSV와 텔레그램으로, 한 번에 한 건씩
- 토큰은 .env에서 읽고 절대 출력·커밋하지 않기, .gitignore에 .env
- 실행 예시와 하루 2번 자동 실행(macOS는 launchd, 윈도우는 작업 스케줄러) 설정 방법까지

공식 API와 '자동 게시 앱'은 달라요. 이 강의는 Meta가 제공하는 공식 API만 써요. 비밀번호를 받아 대신 로그인해 올려 준다는 앱·매크로, 브라우저로 인스타 화면을 눌러 올리는 봇은 계정 제한 위험이 있어 쓰지 않아요(강의). 자동 게시라도 승인은 사람, 광고 규칙 점검과 {{customer}} 사진 동의는 그대로. 네이버 블로그는 공식 게시 API가 없어서 이 방법이 안 돼요(강의).
