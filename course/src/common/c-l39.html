AI가 디자인 도구를 직접 열어 동의서·안내문·앱 화면을 만들어요

디자인 MCP(커넥터)를 연결하면 AI가 Canva에서 동의서·안내문·포스터를 만들고 PDF로 내보내고, Figma에서 태블릿 앱 화면 시안을 그리거나 그 시안을 읽어 코드에 반영해요. "이 문구로 A4 동의서 만들어 줘" 한마디면 {{owner:은}} 고르고 고치기만 하면 돼요.

도구{{place}}에서 만드는 것연결 주소·조건
Canva (추천 1순위)동의서·접수지(A4 인쇄용), 대기실 안내문, QR 안내판, 퇴원 안내이용 안내, 블로그 대문, 인스타 카드뉴스, 명함Claude 커넥터 목록의 Canva, 또는 MCP 주소 https://mcp.canva.com/mcp. Canva 무료 계정도 연결돼요(일부 기능은 유료)
Figma태블릿 접수·동의 앱(강의), 직원 웹앱(강의) 화면 시안 → 시안대로 코드 고치기, 인테리어 동선 메모(FigJam)Claude 커넥터 목록의 Figma, 또는 MCP 주소 https://mcp.figma.com/mcp. Figma 유료 요금제(Professional 이상)에서 편집 권한이 있는 계정이어야 제대로 써요. Figma 용어로는 Full 시트(디자인 편집) 또는 Dev 시트(개발용 보기)이고, 무료 계정이나 보기 전용 계정은 사용 횟수가 제한될 수 있어요
Pablooo (화면 레퍼런스)만들기 전에 "다른 앱은 접수·체크인·예약·동의 화면을 어떻게 만들었나" 실제 앱 화면 스크린샷을 찾아보기. 태블릿 앱·직원 웹앱·안내 화면의 버튼 배치·순서 아이디어MCP 주소 https://mcp.pablooo.club. 무료, 가입·키 없이 연결. 약 8,000장의 모바일·데스크톱 화면과 흐름(해외 앱 위주)
구글 문서 (연결 없이도)동의서 문구 원본, 매뉴얼Google Drive 커넥터(강의)로 읽기. 문구 원본은 여기, 디자인은 Canva

정리: 인쇄물·이미지는 Canva, 앱 화면은 Figma, 만들기 전 참고는 Pablooo, 문구 원본은 구글 문서. 처음엔 Canva 하나만 연결해도 충분하고, 앱 화면을 만들 때 Pablooo를 더해요. 비슷한 화면 레퍼런스 서비스로 Mobbin·Refero도 있어요(유료 위주).

  1. 자세히 따라 하기접기
    1. Claude 웹·데스크톱(유료 요금제): 새 채팅 입력창의 검색 및 도구 → 커넥터 관리 → Canva 찾기 → 연결 → Canva 로그인 → 허용. 목록에 없으면 커넥터 둘러보기에서 검색
    2. 목록에서 못 찾으면 설정 → 커넥터 → 사용자 지정 커넥터 추가에 https://mcp.canva.com/mcp
    3. ChatGPT: 설정 → 앱에서 Canva를 찾아 연결해요(메뉴 이름은 자주 바뀌어요)
    4. 연결 확인: "Canva에서 A4 빈 문서 하나 만들어 줘" → Canva에 새 디자인이 생기면 성공{{place}} 공용 Canva 계정으로 연결하세요. {{owner}} 개인 계정이면 디자인이 개인 폴더에 쌓여요.
  2. 자세히 따라 하기접기
    1. Claude: 커넥터 관리에서 Figma → 연결 → Figma 로그인·허용. 목록에 없으면 사용자 지정 커넥터에 https://mcp.figma.com/mcp
    2. 터미널 Claude Code를 쓰면: claude mcp add --transport http figma https://mcp.figma.com/mcp → /mcp에서 figma 인증
    3. Figma에서 새 디자인 파일 '{{place}} 앱' → 파일 주소를 복사해 AI에게 주면 그 파일에서 작업해요. 특정 화면만이면 그 프레임을 선택하고 선택 항목 링크 복사
  3. 자세히 따라 하기접기
    1. Claude 웹·데스크톱: 설정 → 커넥터 → 사용자 지정 커넥터 추가 → 이름 Pablooo, 주소 https://mcp.pablooo.club → 추가(가입·키 없음)
    2. 터미널 Claude Code: claude mcp add --transport http pablooo --scope user https://mcp.pablooo.club → /mcp에서 확인
    3. ChatGPT: 앱(플러그인) 목록에서 Pablooo를 찾아 설치해요(메뉴 이름은 바뀔 수 있어요)
    4. 확인: "Pablooo에서 체크인·접수 화면 예시 6개 보여 줘" → 실제 앱 화면이 나오면 성공해외 앱 위주라 글자는 영어예요. 버튼 크기·순서·진행 표시처럼 구조만 참고하고, 화면을 그대로 베끼지 않아요.
  4. {{place}} 브랜드(강의)의 색 2~3개, 글꼴, 로고 파일을 Canva·Figma에 올려 두고, AI에게 "늘 이 기준으로"라고 해요. Canva 브랜드 키트는 유료 기능이라, 무료면 '디자인 기준' 디자인 한 장을 만들어 두고 매번 참고하게 해요. 글꼴은 상업적 이용이 되는 것만.
  5. 동의 문구(강의)가 확정되면 아래 '동의서 디자인 부탁문'. 체크 칸이 항목마다 따로인 A4 한 장과 PDF가 나와요. 태블릿 앱의 '동의문구' 탭과 같은 문구·같은 버전으로 맞춰 두면, 태블릿이 고장 난 날 종이로 바로 받을 수 있어요.
  6. '앱 화면 시안 부탁문'으로 태블릿 가로 화면 5장({{customer}}·반려동물방문 내용·동의·서명·완료) 시안 → {{owner:이}} Figma에서 직접 고치거나 말로 고치기 → '시안대로 코드 고치기 부탁문'으로 index.html(강의)의 색·크기·배치를 맞춰요. 직원 웹앱도 같은 방법.
  7. QR 접수 안내판, 진료 순서 안내, 예방접종 달력,이용 순서 안내, 철마다 바뀌는 안내판, 블로그 대문(강의), 인스타 카드뉴스(강의)를 같은 기준으로. 텔레그램 승인함(강의)에 「인쇄 / 수정」을 걸어 두면 출퇴근길에 고를 수 있어요.
화면 레퍼런스 부탁문 (Pablooo → Figma)
Pablooo에서 '체크인·접수·동의·서명' 흐름이 있는 앱 화면을 6~8개 찾아 줘.
1) 화면마다: 앱 이름, 무엇을 잘했는지(버튼 크기, 단계 표시, 필수·선택 구분, 큰 글씨)
2) 우리 대기실 태블릿 접수 앱에 가져올 점 5가지와 피할 점 3가지
3) 그걸 반영한 우리 앱 화면 구조(5장) 설명 — 그대로 베끼지 말고 구조만
다음 단계로 이 구조를 Figma 시안으로 만들 거야.
동의서 디자인 부탁문 (Canva)
Canva에서 우리 {{place}} 첫 방문 접수·동의서를 A4 세로 한 장으로 만들어 줘.
- 디자인 기준: 색 ○○, ○○ / 글꼴 ○○ / 로고는 '디자인 기준' 디자인의 것
- 위: {{place}} 이름·로고, 접수 칸({{customer}} 이름, 연락처, 반려동물 이름·종류·나이, 방문 이유)
- 가운데: 동의 3가지, 항목마다 체크 칸 따로(① 개인정보 수집·이용 필수 ② 광고성 정보 수신 선택 ③ 사진·진료이용 이야기 활용 선택), 문구는 아래 그대로: ○○
- 아래: 날짜, 서명란, "선택 동의를 하지 않아도 진료이용에 불이익이 없어요"
- 글자는 11pt 이상, 흑백 인쇄해도 읽히게
- 보통 글씨 버전(A4 1장)과 큰 글씨 버전(14pt 이상, A4 2장까지)을 두 개의 디자인으로 따로 만들고 파일 이름에 (보통)/(큰 글씨)
- 접수 칸에 "반려동물 사진(진료 기록용, 선택) — 접수대에서 찍어요" 한 줄
- 만든 뒤 PDF로 내보내고 링크를 줘. {{customer}} 개인정보는 넣지 않은 빈 양식이야
앱 화면 시안 부탁문 (Figma)
이 Figma 파일(○○ 주소)에 대기실 태블릿 접수·동의 앱 화면 시안을 만들어 줘.
- 1024×768 가로 프레임 5개: {{customer}} 정보, 반려동물(종류·방문 이유는 큰 버튼)방문 내용(방문 이유는 큰 버튼), 동의(필수·선택 표시, 전문 펼치기), 손가락 서명, 접수 완료(접수번호)
- {{place}} 디자인 기준 색·글꼴, 버튼은 손가락으로 누르기 쉬운 크기(높이 56 이상), 글자 18 이상
- 진행 표시 점 4개, 화면마다 '이전/다음'
- 노인 {{customer}}도 읽기 쉽게 대비를 높게
시안대로 코드 고치기 부탁문 (07 자동화 도우미)
Figma 파일(○○ 주소)의 태블릿 접수 앱 시안을 읽고, 첨부한 index.html의 스타일을 시안에 맞춰 바꿔 줘.
- 색·글자 크기·버튼 크기·간격·배치만 바꾸고, 저장 동작(google.script.run, 입력 지우기, 첫 화면 복귀)은 그대로
- 바뀐 CSS와 HTML 부분만 보여 주고, 다시 배포는 '배포 관리 → 새 버전'

디자인 파일은 양식만. Canva·Figma에는 빈 양식과 안내물만 두고, 작성된 동의서·{{customer}} 사진·연락처는 올리지 않아요. 공유 링크는 '보기만'으로, 외부 디자이너에게 넘길 때는 필요한 디자인만. AI가 만든 그림은 실제 진료작업 사진처럼 쓰지 않아요.
