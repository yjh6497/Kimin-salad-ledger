준비 운동 · 약 40분 · PC

코딩은 몰라도 돼요. '붙여 넣고, 허락하고, 알람 걸기' 세 번이면 끝나요

이 코스의 자동화는 대부분 같은 순서예요. AI에게 앱스 스크립트(구글 시트에 붙이는 작은 프로그램)를 받아 → 시트에 붙여 넣고 → 한 번 실행해 허락하고 → 트리거(정해진 시간에 저절로 돌게 하는 알람)를 걸어요. 이 강의에서 그 순서를 연습 코드로 한 번 해 봐요.

이게 뭐예요장부에 '알람 시계 달린 직원'을 붙이는 거예요. 시간이 되면 시트가 알아서 계산하고 메일을 보내요.
끝나면버튼 한 번에 오늘 날짜가 적히는 시트, 매일 아침 저절로 도는 알람
필요한 것PC, 구글 시트(강의), 40분
모든 자동화 강의의 공통 순서이 강의에서 한 번 연습
① 받기AI에게 부탁문 보내고 코드 받기
② 붙이기시트 → 확장 프로그램 → Apps Script → 지우고 붙여 넣기 → 저장
③ 허락실행 → '권한 검토' → 내 계정 → 고급 → 이동 → 허용 (처음 한 번)
④ 알람시계 모양 → 트리거 추가 → 시간 고르기 → 저장
⑤ 오류면빨간 글자를 그대로 복사해 AI에게
  1. 아래 '연습 코드'는 시트에 메뉴를 하나 만들고, 누르면 '연습' 탭 맨 아래에 오늘 날짜를 적어요.
    자세히 따라 하기접기
    1. '{{place}} 장부' 시트 열기 → 위쪽 메뉴 확장 프로그램 → Apps Script (새 창이 열려요)
    2. 새 창 가운데에 있던 글자(function myFunction…)를 모두 선택해 지우기(⌘+A / Ctrl+A → Delete)
    3. 아래 연습 코드의 복사 → 그 자리에 붙여넣기 → 위쪽 디스크 모양(저장) 누르기
  2. 처음 실행할 때 구글이 "이 프로그램이 시트를 고쳐도 돼요?"라고 물어요. 내가 붙인 코드라서 허락해도 괜찮아요.
    자세히 따라 하기접기
    1. 위쪽 함수 고르는 칸에서 addToday 고르기 → 실행
    2. 권한 검토 → {{place}} 계정 고르기
    3. 'Google에서 확인하지 않은 앱' 화면이 나오면 왼쪽 아래 고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용놀라지 마세요: 회사가 만든 앱이 아니라 내가 붙인 코드라서 늘 나오는 안내예요. 남이 보낸 코드라면 허용하기 전에 AI에게 "이 코드가 무슨 일을 해?"라고 먼저 물어봐요.
    4. 시트로 돌아가 '연습' 탭에 오늘 날짜가 생겼는지 확인
  3. 시트를 새로고침(⌘+R / F5)하면 위쪽 메뉴 끝에 '연습 메뉴'가 생겨요. 연습 메뉴 → 오늘 날짜 적기를 누르면 한 줄이 더 생겨요. 이 코스의 자동화는 대부분 이렇게 시트 메뉴로 눌러요.
  4. 매일 아침 저절로 돌게 해 봐요. 연습이 끝나면 지워도 돼요.
    자세히 따라 하기접기
    1. Apps Script 창 왼쪽의 시계 모양(트리거) 누르기
    2. 오른쪽 아래 + 트리거 추가
    3. 실행할 함수 addToday · 이벤트 소스 시간 기반 · 유형 일 단위 타이머 · 시간 오전 6시~7시 → 저장
    4. 내일 아침 '연습' 탭에 날짜가 하나 더 생겼으면 성공. 지우려면 트리거 줄 오른쪽 점 세 개 → 삭제
  5. 빨간 줄의 글자를 그대로 복사해, 코드를 받은 채팅에 "이 오류가 났어. 고친 코드 전체를 다시 줘"라고 붙여 넣어요. 고친 코드를 받으면 ②번처럼 전부 지우고 다시 붙여요. 일부만 고치다 보면 더 꼬여요.
연습 코드 (Apps Script에 붙여 넣기)
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('연습 메뉴')
    .addItem('오늘 날짜 적기', 'addToday')
    .addToUi();
}

function addToday() {
  var sh = SpreadsheetApp.getActive().getSheetByName('연습')
        || SpreadsheetApp.getActive().insertSheet('연습');
  sh.appendRow([new Date(), '연습', '', '앱스 스크립트가 적었어요']);
}
AI에게 코드를 받을 때 늘 붙이는 한 줄
나는 코딩을 몰라. 구글 시트 Apps Script로 만들어 주고,
① 붙여 넣을 곳 ② 실행할 함수 이름 ③ 권한 허용 방법 ④ 트리거 설정을 번호 순서로 알려 줘.
비밀번호·인증키는 코드에 직접 쓰지 말고 '스크립트 속성'에서 읽게 해 줘.
고칠 때는 일부가 아니라 전체 코드를 다시 줘.

컴퓨터를 켜 둘 필요가 없어요. 앱스 스크립트는 구글 서버에서 돌아요. 맥북을 닫아도 아침 알람은 그대로 울려요.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
무료로 하기
  • 앱스 스크립트와 트리거는 무료 (하루 실행 횟수에 넉넉한 한도가 있어요)
