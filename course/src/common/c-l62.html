휴대폰 한 화면으로 {{place}} 상태 보기

허브 시트를 Looker Studio에 연결해요. 그러면 매출·신규·유입경로(어디서 알고 왔는지)·재방문 대상이 그래프로 한 화면에 나와요. 매달 1일엔 AI가 이 숫자로 {{owner}}께 한 장 브리핑을 써요.

왜 필요해요숫자를 보려고 시트를 열어 뒤지다 보면 바쁜 날엔 결국 안 보게 돼요. 휴대폰 화면 하나와 매달 1일 오는 A4 한 장 브리핑으로, 잠깐 사이에 {{place}} 상태를 알 수 있어요.
이게 뭐예요자동차 계기판처럼, {{place}} 숫자를 한눈에 보는 화면을 만드는 거예요. 시트 숫자가 바뀌면 그래프도 저절로 바뀌어요.
끝나면휴대폰 홈 화면에서 여는 매출·유입 그래프 보고서와, 매달 1일 받는 A4 한 장 경영 브리핑이 생겨요.
필요한 것PC, 구글 계정, '{{place}} 데이터 허브' 시트, 1시간 · 시트가 처음이면 강의 먼저
  1. 시트의 숫자를 그래프로 바꾸려면 두 곳을 이어야 해요. 한 번 이으면 그다음부터는 저절로 따라 바뀌어요.
    자세히 따라 하기접기
    1. lookerstudio.google.com에 {{place}} 구글 계정으로 들어가요. 빈 보고서를 눌러요
    2. 데이터 추가 → Google Sheets를 골라요. '{{place}} 데이터 허브' → '일매출' 탭을 고르고 추가를 눌러요막히면: '액세스 권한 승인' 창이 뜨면 승인을 눌러 구글 계정을 허용해요. 시트가 목록에 없으면 같은 구글 계정인지 확인해요.
    3. 그래프를 추가해요. 숫자 카드(이번 달 매출), 시계열(날짜별 선 그래프, 일매출), 막대(유입경로)를 넣어요. 다른 탭은 리소스 → 데이터 소스 추가로 더해요
    4. 휴대폰에서는 보고서 주소를 열고 홈 화면에 추가해 둬요공유는 {{owner}}만. 매출 화면을 직원에게 열어 줄 땐 매출 칸을 뺀 보고서를 따로 만들어요.
  2. 그래프만 보면 무엇을 할지 헷갈려요. 그래서 매달 AI에게 해석을 받아요. '06 성과 분석' 채팅에 아래 부탁문을 보내요. 유료면 앞에 "매달 1일 오전 8시에"를 붙여 예약 작업으로 걸어요.

이 글을 그대로 복사해서 '06 성과 분석' 채팅에 붙여 넣으세요. 고칠 곳은 없어요.

월간 경영 브리핑 부탁문
'{{place}} 데이터 허브'를 보고 지난달 경영 브리핑을 A4 한 장으로 써 줘.
1) 한 줄 요약
2) 숫자: 매출·건수·객단가, 신규/재방문, 지난달·전년 같은 달 대비 (허브에 있는 것만)
3) 유입경로 순위와 그 채널에서 지난달 올린 글 수(월성과 탭)
4) 재방문: 연락한 수, 예약으로 이어진 수, 지난 날짜인데 연락 못 한 수
5) 리뷰: 수, 평균 별점, 반복된 불만 1개와 {{place:이}} 고칠 것
6) 다음 달 할 일 3가지 (마케팅 1, 고객관리 1, 운영 1)
숫자는 시트에서 계산하고, 없으면 '데이터 없음'. 원인을 단정하지 말고 '가능성'으로.

    열 때마다 최신Looker Studio는 시트가 바뀌면 그래프도 바뀌어요.
  • AI 예약 작업

  • 텔레그램 승인
    월간 결정월간 브리핑의 결정 2~3개를 하나씩.버튼: 한다 / 안 한다
실행 방법내장 브라우저 · 크롬 · 터미널/봇 · 비서강의
내장 브라우저Claude 데스크톱 앱 내장 브라우저({{place}} 계정만 로그인)에 "브리핑 재료 모으기" 부탁: 관리 화면 숫자를 허브 시트로, 브리핑은 시트를 읽어서. 읽기만 하고 결과는 표로 받아요. ChatGPT라면 에이전트 모드에서 같은 부탁, 로그인 화면은 {{owner:이}} 넘겨받아요.
크롬평소 크롬 + Claude in Chrome 사이드 패널에 같은 부탁문. 확장 권한은 각 채널 통계 화면만 허락 · 자주 하면 단축 명령, 읽기는 예약도
터미널·봇월간 브리핑 예약 작업 + 텔레그램 요약.
비서 연동브라우저 AI가 읽은 결과·채운 내용 요약을 '06 성과 분석' 채팅에 붙이면 정리·초안·다음 할 일이 나와요. 결정할 것은 "승인함 한 줄로"라고 하면 텔레그램 버튼으로(강의). 결과 보관: 월간 브리핑 부탁문 → 이 채팅(유료면 예약 작업)

토큰 아끼기강의
  • PDF는 그대로 올리면 무거워요. markitdown 파일.pdf -o 파일.md로 바꿔 필요한 쪽만 붙여 넣어요. 스캔한 PDF는 그대로 올려요.
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 정기 브리핑·분석은 같은 채팅에 계속 쌓지 말고 달마다 새 채팅. 지난달 요약 10줄만 붙여 이어가요.
