동물병원 고객관리의 핵심은 예방접종·심장사상충·건강검진·스케일링처럼 주기가 있는 진료예요.단골을 만드는 핵심은 {{ex_revisit}}처럼 주기가 있는 계기예요. 구글 시트가 다음 날짜를 계산해요. 그리고 매주 월요일 "이번 2주 연락할 {{customer}}" 목록을 메일로 보내요. 연락은 실장님이 차트에서담당 {{staff:이}} 고객 명단에서 번호를 찾아 직접 해요.

이게 뭐예요단골 명단에 '알람 시계'를 달아 두는 거예요. 다시 올 때가 가까워지면 월요일 아침 메일로 알려 줘요.

시트에는 고객번호만, 전화번호는 차트고객 명단에만 있어요.

  1. 많은 동물병원 차트가 접종 예정 알림이나 문자 발송을 부가 기능으로 줘요.예약·포스·고객관리 프로그램이 다음 방문 알림이나 문자 발송을 부가 기능으로 주기도 해요. 있으면 그걸 쓰는 게 가장 정확해요. 이 강의는 그런 기능이 없을 때의 방법이에요. {{owner:이}} 직접 숫자를 보고 싶을 때도 좋아요.
  2. 명단을 한곳에 모으려는 거예요. 허브 시트(강의)를 먼저 만들었다면 거기에 만들어요. 아니면 새 시트에 만들어요. 화면 아래 + → 탭 이름 더블클릭 → '재방문'으로 탭을 만들고, 아래 제목 줄을 A1에 붙여 넣어요.막히면: 제목이 한 칸에 몰려 들어가면 데이터 → 텍스트를 열로 분할을 눌러요.
  3. 마지막 날짜에 주기를 더해 다음 날을 계산해요. G2 칸에 =IF(E2="","",E2+F2)를 넣어요. 그다음 G2 오른쪽 아래 작은 네모를 아래로 끌어 내려요. 주기(일)는 {{owner:이}} 진료 기준대로 정해요(예: 심장사상충 30, 종합백신 추가접종 365는 예시일 뿐).우리 {{place}} 기준대로 정해요(예: 30, 90, 365는 예시일 뿐).
  4. 매주 명단을 직접 뒤지지 않으려는 거예요. Apps Script에 코드를 붙이고 트리거(정해진 시간에 저절로 실행되게 하는 알람)를 걸어요.
    자세히 따라 하기접기
    1. 시트 메뉴 확장 프로그램 → Apps Script → 아래 '재방문 메일 스크립트' 붙여 넣기 → 저장
    2. 함수 remindList 선택 → 실행 → 권한 허용막히면: '확인되지 않은 앱' 창이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용을 눌러요. 내가 만든 코드라 괜찮아요. 대상이 없으면 메일이 오지 않는 게 정상이에요.
    3. 시계 아이콘 → + 트리거 추가 → remindList, 시간 기반, 주 단위, 월요일, 오전 8~9시 → 저장
  5. '카톡친구' 표시가 있는 분은 카카오톡 채널 친구그룹 메시지로 연락해요(강의). 나머지는 문자·전화로 해요. 실장님이 목록의 고객번호로 차트에서담당 {{staff:이}} 목록의 고객번호로 고객 명단에서 번호를 찾아 연락 → I열에 연락한 날, J열에 결과(예약함·나중에·연락안됨). 예약하면 E열을 새 날짜로.

재방문 메일 스크립트
function remindList() {
  var sh = SpreadsheetApp.getActive().getSheetByName('재방문');
  var rows = sh.getDataRange().getValues();
  var today = new Date(); today.setHours(0, 0, 0, 0);
  var limit = new Date(today.getTime() + 14 * 24 * 60 * 60 * 1000);
  var list = [];
  for (var i = 1; i < rows.length; i++) {
    var r = rows[i], due = r[6], ok = String(r[7]).toUpperCase(), done = r[8];
    if (!(due instanceof Date) || ok !== 'Y' || done) continue;
    if (due <= limit) {
      var tag = due < today ? '[지남] ' : '';
      list.push(tag + Utilities.formatDate(due, 'Asia/Seoul', 'M/d') + ' · 고객번호 ' + r[0] + ' · ' + r[1] + ' · ' + r[3] + (String(r[10]).toUpperCase() === 'Y' ? ' · 카톡친구' : ''));
    }
  }
  if (!list.length) return;
  list.sort();
  MailApp.sendEmail(Session.getActiveUser().getEmail(),
    '[재방문] 이번 2주 연락할 아이{{customer}} ' + list.length + '명',
    '연락 동의(Y)한 분만 모았어요. 번호는 차트고객 명단에서 찾아 주세요.\n\n- ' + list.join('\n- '));
}

이 시트를 바탕으로 안내 타이밍·템플릿·문자(맥·아이폰)·카톡 채널·알림톡 발송과 결과 기록까지 이어지는 강의가 바로 뒤에 있어요(강의).
