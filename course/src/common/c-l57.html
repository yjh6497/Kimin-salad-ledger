동물병원 고객관리의 핵심은 예방접종·심장사상충·건강검진·스케일링처럼 주기가 있는 진료예요.단골을 만드는 핵심은 {{ex_revisit}}처럼 주기가 있는 계기예요. 구글 시트가 다음 날짜를 계산하고, 매주 월요일 "이번 2주 연락할 {{customer}}" 목록을 메일로 보내요. 연락은 실장님이 차트에서담당 {{staff:이}} 고객 명단에서 번호를 찾아 직접 해요.

{{place}} 인수라면인수 전 기록으로 다음 접종일예정일을 이어서 계산해요. 이관된 차트에서 마지막 내원일 확인.넘겨받은 고객 명단에서 마지막 {{visit}}일 확인.

시트에는 고객번호만, 전화번호는 차트고객 명단에만 있어요.

  1. 많은 동물병원 차트가 접종 예정 알림이나 문자 발송을 부가 기능으로 줘요.예약·포스·고객관리 프로그램이 다음 방문 알림이나 문자 발송을 부가 기능으로 주기도 해요. 있으면 그걸 쓰는 게 가장 정확해요. 이 강의는 그런 기능이 없거나, {{owner:이}} 직접 숫자를 보고 싶을 때의 방법이에요.
  2. 다음 단계의 허브 시트(강의)를 먼저 만들었다면 거기에, 아니면 새 시트에. 아래 제목 줄을 A1에 붙여 넣어요.
  3. G2 칸에 =IF(E2="","",E2+F2) → G2 오른쪽 아래 작은 네모를 아래로 끌어 내리기. 주기(일)는 {{owner:이}} 진료 기준대로 정해요(예: 심장사상충 30, 종합백신 추가접종 365는 예시일 뿐).우리 {{place}} 기준대로 정해요(예: 30, 90, 365는 예시일 뿐).
  4. 자세히 따라 하기접기
    1. 시트 메뉴 확장 프로그램 → Apps Script → 아래 '재방문 메일 스크립트' 붙여 넣기 → 저장
    2. 함수 remindList 선택 → 실행 → 권한 허용
    3. 시계 아이콘 → + 트리거 추가 → remindList, 시간 기반, 주 단위, 월요일, 오전 8~9시 → 저장
  5. '카톡친구' 표시가 있는 분은 카카오톡 채널 친구그룹 메시지로(강의), 나머지는 문자·전화로. 실장님이 목록의 고객번호로 차트에서담당 {{staff:이}} 목록의 고객번호로 고객 명단에서 번호를 찾아 연락 → I열에 연락한 날, J열에 결과(예약함·나중에·연락안됨). 예약하면 E열을 새 날짜로.

재방문 메일 스크립트
function remindList() {
  var sh = SpreadsheetApp.getActive().getSheetByName('재방문');
  var rows = sh.getDataRange().getValues();
  var today = new Date(); today.setHours(0, 0, 0, 0);
  var limit = new Date(today.getTime() + 14 * 24 * 60 * 60 * 1000);
  var list = [];
  for (var i = 1; i < rows.length; i++) {
    var r = rows[i], due = r[6], ok = String(r[7]).toUpperCase(), done = r[8];
    if (!(due instanceof Date) || ok !== 'Y' || done) continue;
    if (due <= limit) {
      var tag = due < today ? '[지남] ' : '';
      list.push(tag + Utilities.formatDate(due, 'Asia/Seoul', 'M/d') + ' · 고객번호 ' + r[0] + ' · ' + r[1] + ' · ' + r[3] + (String(r[10]).toUpperCase() === 'Y' ? ' · 카톡친구' : ''));
    }
  }
  if (!list.length) return;
  list.sort();
  MailApp.sendEmail(Session.getActiveUser().getEmail(),
    '[재방문] 이번 2주 연락할 아이{{customer}} ' + list.length + '명',
    '연락 동의(Y)한 분만 모았어요. 번호는 차트고객 명단에서 찾아 주세요.\n\n- ' + list.join('\n- '));
}
