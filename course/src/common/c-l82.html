직원 휴대폰에 {{place}} 전용 앱 하나

구글 시트와 앱스 스크립트로 무료 웹앱(인터넷 주소로 여는 간단한 앱)을 만들어요. 직원은 PIN(숫자 비밀번호)으로 들어와요. 출퇴근을 누르고, 오늘의 오픈·마감·소독 체크리스트를 체크해요. 인수인계 메모를 남기고 휴가도 신청해요.

이게 뭐예요벽에 붙인 출근부와 체크리스트를 직원 휴대폰 속으로 옮기는 거예요. 앱스토어 없이 주소 하나로 열려요.
끝나면직원 휴대폰 홈 화면에 {{place}} 전용 앱 아이콘이 생기고, 기록은 '직원 데이터' 시트에 쌓여요.

같은 주소, PIN에 따라 다른 화면 · 예시. 웹앱은 {{owner}} 권한으로 시트를 읽고 써요. 그래서 직원에게 '직원 데이터' 파일을 공유하지 않아요.

  1. 앱에서 누른 기록이 쌓일 자리를 먼저 만들어요. 시트 아래 +로 탭을 만들고, 첫 줄에 아래 제목을 써요. 체크리스트(항목 | 시간대: 오픈/마감/소독 | 담당 역할), 체크기록(날짜 | 직원번호 | 항목 | 시각), 인수인계(날짜 | 직원번호 | 대상(입원 동물 번호주문·예약 번호) | 메모), 휴가신청(날짜 | 직원번호 | 종류 | 상태).
  2. 코드는 직접 쓰지 않고 AI에게 받아요. '07 자동화 도우미' 채팅에 아래 부탁문을 보내요. 그러면 Code.gs와 index.html 두 파일을 줘요.
  3. 배포는 앱을 인터넷 주소로 열 수 있게 내놓는 일이에요. 아래 순서대로 눌러요.
    자세히 따라 하기접기
    1. '직원 데이터' 시트를 열고 확장 프로그램 → Apps Script를 눌러요. Code.gs에 있던 글을 지우고 받은 코드를 붙여 넣어요
    2. 왼쪽 파일 + → HTML을 눌러요. 이름은 index로 써요. index.html 코드를 붙여 넣고 저장을 눌러요
    3. 배포 → 새 배포 → 유형 선택(톱니) → 웹 앱을 골라요. 실행 계정은 나, 액세스는 모든 사용자로 해요. 배포 → 권한 허용을 누른 뒤 주소를 복사해요막히면: '확인되지 않은 앱' 창이 뜨면 고급 → (프로젝트 이름)(으)로 이동 → 허용을 눌러요. 내가 만든 앱이라 괜찮아요.
    4. 고칠 때는 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 눌러요'새 배포'를 또 누르면 주소가 바뀌어요. 꼭 '배포 관리'에서 새 버전으로 해요.
  4. 매번 주소를 찾지 않게 아이콘으로 만들어요. 주소를 직원 단톡방에 올리고, 직원이 열어서 홈 화면에 추가를 눌러요. 첫 주는 실장님이 매일 출퇴근 탭을 보며 빠진 기록을 확인해요.

아래 글을 그대로 복사해서 '07 자동화 도우미' 채팅에 붙여 넣으세요. 고칠 곳은 없어요.

직원 웹앱 부탁문
구글 시트 '직원 데이터'로 {{biz}} 직원용 앱스 스크립트 웹앱을 만들어 줘. Code.gs와 index.html 두 파일로.
- 시작: 직원 탭에서 상태 '재직'인 사람 이름 고르기 + PIN 4자리. 5번 틀리면 10분 잠금, PIN은 화면에 안 보이게
- 모든 직원: 출근·퇴근 버튼(출퇴근 탭에 날짜·직원번호·시각, 같은 날 두 번 누르면 확인 창), 내 이번 주 근무표, 오늘의 체크리스트(내 역할 항목만, 체크하면 체크기록 탭에), 인수인계 메모 쓰기·오늘 메모 보기, 휴가 신청
- 실장 역할: 위에 더해 오늘 근무자, 출근 안 누른 사람, 대기 중 휴가 신청, 오늘 안 끝난 체크리스트
- 매출·급여·{{customer}} 연락처는 화면과 코드 어디에도 넣지 않기. 입원 동물은주문·예약은 번호로만
- 휴대폰 기준, 글씨 16px 이상, 큰 버튼, 어두운 화면에서도 읽히게
붙여 넣는 곳, 배포, 고칠 때 새 버전으로 하는 법까지 순서대로.

이 글도 같은 채팅에 붙여 넣으면 '체크리스트' 탭에 바로 붙일 표가 나와요.

체크리스트 항목 부탁문
{{biz}} 오픈·마감·소독 체크리스트를 역할별로 만들어 줘(실장·코디/동물보건사/미용). 항목은 한 줄 15자 안쪽으로, 시간대(오픈/마감/소독)와 담당 역할을 붙여 '체크리스트' 탭에 바로 붙일 표로. 마취기·산소, 냉장 약품 온도, 입원장, 진료대 소독, 의료폐기물, 방사선 장비 전원 같은 {{biz}} 항목 포함. 기준값(온도 등)은 [원장 확인]으로 비워 두기.{{biz}} 오픈·마감 체크리스트를 역할별로 만들어 줘(실장/{{staff}}). 항목은 한 줄 15자 안쪽으로, 시간대(오픈/마감)와 담당 역할을 붙여 '체크리스트' 탭에 바로 붙일 표로. {{stockitem}} 보관·정리, 청소, 장비 전원, 문단속 같은 우리 {{place}} 항목 포함. 기준값(온도 등)은 [{{owner}} 확인]으로 비워 두기.

PIN 웹앱은 작은 {{place}}용이에요. 강한 보안이 아니에요. 그러니 급여·매출·{{customer}} 개인정보는 넣지 마세요. 출퇴근 기록은 실장님이 매주 한 번 근무표와 맞춰 봐요.
