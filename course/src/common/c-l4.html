세 채널을 한 장부에서 관리해요

구글 시트 파일 하나에 네 가지를 모아요. 글 달력, 키워드, 리뷰, 한 달 성과예요. 업체가 매달 보내 주던 보고서를 이제 {{owner}} 장부가 대신해요.

이게 뭐예요홍보 일을 적는 '공책' 하나를 만드는 거예요. 공책 안에 칸막이(탭) 네 개를 나눠 두고, 글 계획·키워드·리뷰·성과를 따로 적어요.
끝나면탭 4개가 있는 '{{place}} 마케팅 장부' 시트 한 개가 생겨요.
필요한 것PC, 구글 계정, 40분 · 시트가 처음이면 강의 먼저

{{place}} 인수라면장부는 인수한 날부터 적어요. 인수 전 숫자는 허브 시트 '인수 전' 탭에강의.

  1. 모든 홍보 기록을 한곳에 모으려고 만들어요. 드라이브 폴더 안에서 새 시트를 만들고 이름을 붙여요.
    자세히 따라 하기접기
    1. 드라이브 '{{place}} 마케팅' 폴더 → + 새로 만들기 → Google 스프레드시트
    2. 왼쪽 위 '제목 없는 스프레드시트'를 눌러 {{place}} 마케팅 장부
    3. 맨 아래 +를 눌러 탭을 4개 만들어요: 글달력, 키워드, 리뷰, 월성과
    4. 탭 이름은 탭을 두 번 눌러 바꿔요. 막히면: 탭 위에서 마우스 오른쪽 버튼 → '이름 바꾸기'를 눌러도 돼요.
  2. 칸마다 무엇을 적을지 정해 두려고 해요. 아래 상자의 '복사'를 누르고, 탭의 맨 왼쪽 위 칸(A1)을 눌러 붙여 넣어요. 칸이 저절로 나뉘어요.막히면: 한 칸에 다 들어가 버리면 붙여 넣은 뒤 나오는 작은 아이콘에서 '텍스트를 열로 분할'을 눌러요.
  3. 매번 타자로 치지 않고 골라서 넣으려고 해요. 채널은 플레이스·블로그·인스타 중에서 골라요. 상태는 아이디어·초안·점검완료·예약·게시 중에서 골라요. '점검완료'가 아닌 글은 예약하지 않는 게 {{place}} 규칙이에요.
    자세히 따라 하기접기
    1. 글달력 탭의 C열 머리(C 글자)를 눌러 열 전체 선택
    2. 삽입 → 드롭다운 → 옵션에 플레이스, 블로그, 인스타를 하나씩 → 완료
    3. F열(상태)도 같은 방법으로 만들어요. 옵션은 아이디어, 초안, 점검완료, 예약, 게시예요.

아래 상자는 탭마다 하나씩이에요. '복사'를 눌러 같은 이름의 탭 A1 칸에 붙여 넣으세요. 고칠 곳은 없어요.

'어떻게 알고 오셨어요?'를 꼭 물어보세요. 접수지에주문서나 예약 메모에 '네이버 검색 / 지도 / 블로그 / 인스타 / 지인 / 지나가다' 체크 칸 하나만 있으면 돼요. 그러면 어느 채널에 시간을 더 써야 할지 숫자로 보여요. 업체 없이 운영할 때 가장 값진 자료예요.

  • 조건부 서식
    밀린 글 빨간색날짜가 지났는데 상태가 '게시'가 아니면 칸이 빨갛게 바뀌어요. "글달력 탭에 조건부 서식 넣는 법 알려줘"라고 AI에게 부탁하세요.
  • 트리거
    예약 글이 비면 메일다음 7일 안에 '예약' 상태인 글이 없으면 일요일 저녁에 메일이 와요. 이 일을 하는 앱스 스크립트(시트에 붙이는 작은 프로그램)는 강의에서 붙여요.
