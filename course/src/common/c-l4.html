세 채널을 한 장부에서 관리해요

구글 시트 한 파일에 글 달력, 키워드, 리뷰, 한 달 성과를 모아요. 업체가 매달 보내 주던 보고서를 {{owner}} 장부가 대신해요.

{{place}} 인수라면장부는 인수일부터. 인수 전 숫자는 허브 시트 '인수 전' 탭에강의.

  1. 자세히 따라 하기접기
    1. 드라이브 '{{place}} 마케팅' 폴더 → + 새로 만들기 → Google 스프레드시트
    2. 왼쪽 위 '제목 없는 스프레드시트'를 눌러 {{place}} 마케팅 장부
    3. 맨 아래 +로 탭 4개: 글달력, 키워드, 리뷰, 월성과
  2. 아래 상자를 복사해 각 탭의 A1 칸에 붙여 넣으면 칸이 저절로 나뉘어요.
  3. 채널: 플레이스·블로그·인스타. 상태: 아이디어·초안·점검완료·예약·게시. 점검완료가 없는 글은 예약하지 않는 게 {{place}} 규칙이에요.
    자세히 따라 하기접기
    1. 글달력 탭의 C열 머리(C 글자)를 눌러 열 전체 선택
    2. 삽입 → 드롭다운 → 옵션에 플레이스, 블로그, 인스타를 하나씩 → 완료
    3. F열(상태)도 같은 방법으로

'어떻게 알고 오셨어요?'를 꼭 물어보세요. 접수지에주문서나 예약 메모에 '네이버 검색 / 지도 / 블로그 / 인스타 / 지인 / 지나가다' 체크 칸 하나면, 어느 채널에 시간을 더 쓸지 숫자로 보여요. 업체 없이 운영할 때 가장 값진 데이터예요.

이 강의 자동화손을 줄이는 방법
  • 조건부 서식
    밀린 글 빨간색날짜가 지났는데 상태가 '게시'가 아니면 빨갛게. "글달력 탭에 조건부 서식 넣는 법 알려줘"라고 AI에게 부탁하세요.
  • 트리거
    예약 글이 비면 메일다음 7일 안에 '예약' 상태 글이 없으면 일요일 저녁 메일을 보내는 앱스 스크립트를 강의에서 붙여요.
