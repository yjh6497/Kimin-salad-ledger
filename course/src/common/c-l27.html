일요일에 올려 두면 평일엔 저절로

{{work}} 중에 인스타를 올릴 수는 없어요. 일요일에 세 개를 만들어 예약 게시로 화·목·토에 올라가게 해요.

  1. 자세히 따라 하기 (인스타그램 앱)접기
    1. + → 게시물 또는 릴스 → 사진·영상 고르기 → 캡션 붙여 넣기
    2. 공유 직전 화면 아래 고급 설정(또는 더 보기) → 이 게시물 예약 → 날짜·시간
    3. 예약. 예약한 글은 프로필 → ≡ → 예약된 콘텐츠에서 고칠 수 있어요메뉴가 안 보이면 프로페셔널 계정인지 먼저 확인하세요.
  2. 자세히 따라 하기접기
    1. PC에서 business.facebook.com → 페이스북 계정으로 로그인 → 연결된 {{place}} 인스타그램 선택
    2. 플래너(또는 콘텐츠) → 게시물 만들기 → 게시 위치에서 인스타그램만 체크
    3. 사진·캡션 → 예약 → 날짜·시간. 세 개 반복
  3. 글달력 탭 상태를 '예약'으로. 월요일 브리핑이 비어 있는 날을 알려 줘요.

올라간 뒤 30분은 들여다보기. 예약 시간을 점심시간 직전(12시 전)이나 퇴근 후(19~21시)로 잡으면, 올라간 직후 댓글에 바로 답할 수 있어요. 가장 반응 좋은 시간은 한 달 뒤 통계로 다시 정해요.

이 강의 자동화손을 줄이는 방법
  • 예약 게시
    세 개를 한 번에메타 비즈니스 스위트로 일주일 치를 한 자리에서 예약. 비용 없음.
  • 텔레그램 승인
    예약 게시 목록 승인일요일 예약 전에 이번 주 게시물.버튼: 승인 / 하나 빼기
실행 방법내장 브라우저 · 크롬 · 터미널/봇 · 비서강의
내장 브라우저Claude 데스크톱 앱 내장 브라우저({{place}} 계정만 로그인)에 "예약 게시 칸" 부탁: 메타 비즈니스 도구의 예약 게시 칸에 캡션·사진을 넣고 예약 버튼은 {{owner}}. 저장·제출 버튼 앞에서 멈추게 해요. ChatGPT라면 에이전트 모드에서 같은 부탁, 로그인 화면은 {{owner:이}} 넘겨받아요.
크롬평소 크롬 + Claude in Chrome 사이드 패널에 같은 부탁문. 확장 권한은 business.facebook.com만 허락 · 자주 하면 단축 명령으로 저장
터미널·봇공식 API 봇으로 승인한 글 자동 게시강의.
비서 연동브라우저 AI가 읽은 결과·채운 내용 요약을 '03 인스타 담당' 채팅에 붙이면 정리·초안·다음 할 일이 나와요. 결정할 것은 "승인함 한 줄로"라고 하면 텔레그램 버튼으로(강의). 결과 보관: 예약 날짜 → 장부 글달력

더 자동으로 하고 싶다면 인스타그램은 공식 게시 API가 있어서, 시트에 쌓고 텔레그램으로 승인한 글을 정한 시간에 저절로 올리게 할 수 있어요(강의). 예약 게시에 익숙해진 다음에.
