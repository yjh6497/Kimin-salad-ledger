  1. 여러 사람이 쓰는 기계라 먼저 안전하게 해 둬요. {{place}} 공용 구글 계정으로 로그인해요({{owner}} 개인 계정 아님). 화면 잠금 PIN(비밀번호 숫자)을 걸어요. 자동 업데이트는 밤에 되게 하고, 충전 거치대에 세워 둬요. 분실 대비로 '나의 찾기'(아이패드) 또는 '내 디바이스 찾기'(갤럭시 탭)를 켜요. 대기실용과 직원용은 가능하면 따로 둬요.
  2. 직원이 매일 쓰고 기록이 남아야 하는 화면은 이 방식이에요. 배포(만든 화면을 인터넷 주소로 내놓기)를 하면 주소가 생겨요.
    자세히 따라 하기접기
    1. 앱스 스크립트 편집기 오른쪽 위 배포 → 새 배포 → 유형 '웹 앱'
    2. 다음 사용자로 실행: 나 · 액세스 권한: 직원 앱은 모든 사용자(로그인 없이, 대신 PIN으로 사람 구분 강의)
    3. 배포 → 나온 웹 앱 URL 복사 → 카톡 '나에게'나 텔레그램으로 보내 태블릿에서 열기
    4. 고칠 때는 배포 → 배포 관리 → 연필 → 버전: 새 버전. 새 배포를 또 만들면 주소가 바뀌어요'모든 사용자'는 주소를 아는 누구나 열 수 있다는 뜻이에요. 주소를 대기실 게시물이나 SNS에 올리지 말고, PIN 없이는 아무것도 안 보이게 만들어요.
  3. {{customer:가}} 쓰는 화면은 만들기 쉽고 로그인이 필요 없는 구글 폼·사이트가 편해요.
    자세히 따라 하기접기
    1. 구글 폼 오른쪽 위 게시(또는 보내기) → 링크 아이콘 → URL 단축 → 복사. 응답자 권한이 '링크가 있는 모든 사용자'인지 확인
    2. {{place}} 안내 페이지는 구글 사이트(sites.google.com) → 만들기 → 게시 → 웹 주소 정하기 → 누구나 볼 수 있게
    3. 대기실 태블릿 대신 QR 코드도 좋아요. Chrome에서 주소 열기 → 공유 → QR 코드 → 접수대에 출력. {{customer:는}} 자기 휴대폰으로 써서 태블릿을 닦을 일도, 앞사람 입력이 남을 일도 없어요
  4. 매뉴얼·시안처럼 보여 주고 의견을 받을 페이지는 이 방식이에요. 아티팩트는 Claude가 만들어 주는 웹 페이지예요.
    자세히 따라 하기접기
    1. Claude에게 "이 매뉴얼을 태블릿에서 보기 좋은 페이지(아티팩트)로 만들어 줘"
    2. 만들어진 페이지를 웹 브라우저나 Claude 데스크톱 앱에서 열어요. 휴대폰 Claude 앱에서는 공유 설정을 바꿀 수 없어요
    3. 오른쪽 위 Share(공유) → Who has access(접근 권한): 개인 요금제는 '링크가 있는 모든 사람', 팀 요금제는 '조직의 모든 사람'이나 초대한 사람
    4. 링크 복사 → 카톡·텔레그램으로 보내기
    5. 꼭 확인: 로그인하지 않은 브라우저(시크릿 창)나 직원 휴대폰으로 열어 봐요. 로그인을 요구하면, 받는 사람에게도 Claude 계정이 필요한 설정이에요. 그때는 웹사이트 방식으로 옮기거나 계정이 있는 사람에게만 보내요
    6. 그만 나누려면 같은 곳에서 접근 권한을 '나만'으로무료 요금제는 새 아티팩트를 링크로 공유할 수 없어요. 메뉴 이름은 바뀔 수 있으니 안 보이면 Claude 고객센터의 '아티팩트 공유' 안내를 보세요.
  5. 주소를 매번 치지 않고 아이콘 하나로 열려고 해요. 아이패드:Safari로 주소 열기 → 주소창 옆 공유 버튼 → 홈 화면에 추가. 갤럭시 탭: Chrome으로 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가. 아이콘 이름은 '직원 앱', '재고', '온도'처럼 짧게.
  6. {{customer:가}} 다른 앱이나 사진을 열지 못하게 하려는 거예요. 아이패드: 설정 → 손쉬운 사용 → 사용법 유도를 켜요. 설문 화면에서 상단 버튼을 세 번 눌러 시작하면 다른 앱으로 못 나가요. 갤럭시 탭: 설정 검색에서 '앱 고정'을 켜고, 최근 앱 화면에서 고정해요. 자동 잠금은 길게, 밝기는 낮게 해요. 설문을 낸 뒤 첫 화면으로 돌아오는지, 앞사람 입력이 남지 않는지 확인해요.
  7. 어디에 무엇을 나눴는지 잊지 않으려는 거예요. 장부에 '공유 주소' 탭을 두고 이름 | 주소 | 방식 | 누가 여나 | 공개 범위 | 만든 날 | 끈 날을 적어요. 퇴사자가 생기면 이 표를 보고 PIN을 지우고 공유를 끊어요(강의).

실제 앱 화면(대기실 태블릿 가로). 첫 화면 「보통 글씨로 시작 / 큰 글씨로 시작」 → 1 {{customer}} → 2 반려동물(사진)방문 정보(사진) → 3 동의 → 4 서명 → 접수번호. 12초 뒤, 또는 3분 동안 손대지 않으면 첫 화면으로 돌아가고 입력·사진이 지워져요. 도중에도 오른쪽 위 「가 큰 글씨」로 바꿀 수 있어요.

  1. 접수 내용과 서명이 저장될 자리를 먼저 만들어요. {{place}} 구글 계정 → 새 스프레드시트 '접수·동의' → 탭 두 개 '접수동의', '동의문구'를 만들어요. 아래 제목 줄을 각 탭 A1에 붙여요. 동의문구 탭 2~4행에 privacy·ad·photo 세 줄을 넣어요. 전문은 동의서 부탁문(강의)으로 만든 문구를 붙여요. 드라이브에 '서명' 폴더와 '반려동물 사진참고 사진' 폴더도 하나씩. 두 곳 모두 {{owner}}·실장님만 볼 수 있게.
  2. 아래 두 코드를 Apps Script에 붙이고, 비밀값은 스크립트 속성(코드 밖 비밀 메모 칸)에 넣어요.
    자세히 따라 하기접기
    1. '접수·동의' 시트 → 확장 프로그램 → Apps Script → 원래 있던 Code.gs 내용을 지우고 아래 'Code.gs'를 붙여 넣기
    2. 왼쪽 파일 옆 + → HTML → 이름 index(확장자 없이) → 아래 'index.html'을 붙여 넣기 → 저장
    3. 톱니바퀴(프로젝트 설정) → 스크립트 속성: SHEET_ID(시트 주소 /d/ 와 /edit 사이), SIGN_FOLDER(서명 폴더 주소 folders/ 뒤), KIOSK_KEY(아무도 모를 영문·숫자 12자 이상), CLINIC_NAME, TERMS_VER(예: 2026-11), PHOTO_FOLDER(반려동물 사진참고 사진 폴더 주소 folders/ 뒤). 텔레그램 알림을 원하면 TG_TOKEN·TG_CHAT(강의)

  4. 태블릿 Safari(아이패드)·Chrome(갤럭시 탭)으로 태블릿 주소를 열어요 → 홈 화면에 추가(이름 '접수'). 대기실 태블릿은 위 단계의 '사용법 유도'·'앱 고정'으로 이 화면만 보이게 해요. 위쪽에 구글이 띄우는 "이 애플리케이션은 Google 사용자가 만들었습니다" 안내는 앱스 스크립트 웹앱이면 늘 보여요.

function doGet(e) {
  if (!e || !e.parameter || e.parameter.k !== P.getProperty('KIOSK_KEY')) {
    return HtmlService.createHtmlOutput('<p style="font:20px sans-serif;padding:40px">접수 태블릿 주소를 확인해 주세요.</p>');
  }

  t.key = e.parameter.k;
  t.big = e.parameter.big === '1'; // 큰 글씨 전용 주소: ...?k=키&big=1
  t.clinic = P.getProperty('CLINIC_NAME') || '우리 {{biz}}';
  t.terms = JSON.stringify(readTerms());
  return t.evaluate()
    .setTitle(t.clinic + ' 접수')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

function readTerms() { // 동의문구 탭: 코드 | 제목 | 전문 | 필수(Y/N)
  var sh = SpreadsheetApp.openById(P.getProperty('SHEET_ID')).getSheetByName('동의문구');
  return sh.getRange(2, 1, Math.max(sh.getLastRow() - 1, 1), 4).getValues()
    .filter(function (r) { return r[0]; })
    .map(function (r) { return { id: String(r[0]), title: r[1], body: r[2], required: r[3] === 'Y' }; });
}

function saveIntake(d) {
  if (!d || d.key !== P.getProperty('KIOSK_KEY')) throw new Error('기기 확인 실패');
  var terms = readTerms();
  terms.forEach(function (t) { if (t.required && !d.agree[t.id]) throw new Error('필수 동의가 빠졌어요'); });
  var no = 'R' + Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyMMdd-HHmmss');
  var sign = '';
  if (d.sign && d.sign.indexOf('data:image/png;base64,') === 0) {
    var blob = Utilities.newBlob(Utilities.base64Decode(d.sign.split(',')[1]), 'image/png', no + '.png');
    sign = DriveApp.getFolderById(P.getProperty('SIGN_FOLDER')).createFile(blob).getUrl();
  }
  var photo = '';
  if (d.photo && d.photo.indexOf('data:image/jpeg;base64,') === 0 && P.getProperty('PHOTO_FOLDER')) {
    var pb = Utilities.newBlob(Utilities.base64Decode(d.photo.split(',')[1]), 'image/jpeg', no + '_반려동물참고사진.jpg');
    photo = DriveApp.getFolderById(P.getProperty('PHOTO_FOLDER')).createFile(pb).getUrl();
  }
  var sh = SpreadsheetApp.openById(P.getProperty('SHEET_ID')).getSheetByName('접수동의');
  sh.appendRow([new Date(), no, d.owner, "'" + d.phone, d.pet, d.species, d.age, d.reason,
    d.agree.privacy ? 'Y' : 'N', d.agree.ad ? 'Y' : 'N', d.agree.photo ? 'Y' : 'N',
    sign, P.getProperty('TERMS_VER') || '', false, photo, d.big ? '큰 글씨' : '보통']);
  if (P.getProperty('TG_TOKEN')) { // 텔레그램에는 이름·번호 없이 건수만
    UrlFetchApp.fetch('https://api.telegram.org/bot' + P.getProperty('TG_TOKEN') + '/sendMessage', {
      method: 'post', payload: { chat_id: P.getProperty('TG_CHAT'), text: '📝 새 접수 ' + no }, muteHttpExceptions: true });
  }
  return no;
}
