{{place}} 일에 쓸 계정 두 개부터 만들어요

이 코스의 거의 모든 강의가 구글 계정과 네이버 아이디를 써요. 개인 계정과 섞이면 나중에 직원에게 넘기거나 정리하기 어려워요. 그래서 {{place}} 전용으로 하나씩 새로 만들고, 인터넷은 크롬으로 통일해요.

왜 필요해요계정이 개인 것과 섞여 있거나 비밀번호를 잊으면 강의마다 로그인에서 막혀요. {{place}} 계정과 크롬을 먼저 준비해 두면 다음 강의를 막힘 없이 따라가요.
이게 뭐예요{{place}} 이름으로 된 '열쇠 꾸러미'를 만드는 거예요. 열쇠(아이디·비밀번호)를 한 곳에 모아 두면 잃어버리지 않아요.
끝나면{{place}}용 구글 계정(지메일), 네이버 아이디, 크롬, 비밀번호 적어 둔 메모 한 장
필요한 것PC나 노트북, 휴대폰(본인 인증용), 30분
  1. 크롬은 구글이 만든 인터넷 창이에요. 이 코스의 화면 설명은 크롬 기준이라, 같은 화면을 보며 따라 하기 쉬워요.
    자세히 따라 하기접기
    1. 지금 쓰는 인터넷 창(엣지·사파리 등) 주소 칸에 google.com/chrome 입력 → 엔터
    2. Chrome 다운로드 누르기 → 받은 파일 열기
    3. 맥: 크롬 아이콘을 '응용 프로그램' 폴더로 끌어다 놓기
    4. 윈도우: 설치가 끝날 때까지 기다리기막히면: "이 화면에서 다음에 뭘 눌러?"라고 화면을 캡처해 AI에게 물어보세요(캡처 방법은 강의).
    5. 크롬을 열고 오른쪽 위 점 세 개 → 설정 → 기본 브라우저 → 기본 브라우저로 설정
  2. 구글 계정 하나로 지메일, 구글 시트(엑셀 같은 표), 드라이브(인터넷 서류함), 캘린더를 다 써요.
    자세히 따라 하기접기
    1. 크롬 주소 칸에 accounts.google.com/signup
    2. 이름 칸에 {{place}} 이름, 사용자 이름은 기억하기 쉬운 영어(예: ○○shop2027)
    3. 휴대폰 번호로 인증 → 가입 완료막히면: 휴대폰 번호 하나로 만들 수 있는 계정 수가 정해져 있어 오류가 날 수 있어요. 그때는 잠시 뒤 다시 하거나 다른 가족 번호로 인증해요.
    4. 크롬 오른쪽 위 동그란 사람 모양 → 추가로 새 '프로필'을 만들고 {{place}} 계정으로 로그인하면, 개인 계정과 창이 나뉘어 헷갈리지 않아요.
  3. 네이버 플레이스(지도), 블로그, 예약을 이 아이디로 운영해요. 개인 블로그·카페와 섞이지 않게 따로 만들어요.
    자세히 따라 하기접기
    1. naver.com → 오른쪽 위 회원가입 → 휴대폰 인증
    2. 아이디는 구글 계정과 비슷하게 맞추면 기억하기 쉬워요막히면: 네이버도 휴대폰 번호 하나당 만들 수 있는 아이디 수가 정해져 있어요. 이미 많다면 '단체 아이디'나 '비즈니스 계정' 안내를 확인해요.
  4. 계정이 여러 개라 꼭 잊어요. 종이 수첩 한 장이나 휴대폰의 비밀번호 앱(아이폰 '암호', 안드로이드 '구글 비밀번호 관리자')에 모아 둬요. AI 채팅창에는 비밀번호를 절대 쓰지 않아요.
  5. 비밀번호가 새어도 내 휴대폰이 없으면 못 들어오게 막는 자물쇠예요. 구글: 계정 관리 → 보안 → 2단계 인증. 네이버: 내정보 → 보안설정 → 2단계 인증.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
