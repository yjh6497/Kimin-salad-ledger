  3. {{owner}} 외부 일정이나 수술긴 예약 블록이 생기면, 같은 시간을 네이버 예약에서 '예약 불가'로 막아요. 잊지 않으려면 매주 월요일 브리핑(강의)에 한 줄을 넣어요. "캘린더 블록과 네이버 예약 가능 시간이 겹치는 곳"을 묻는 줄이에요.
  4. 구글 캘린더의 예약 일정(예약 페이지)으로 '{{customer}} 상담 30분'이나 '업체 미팅' 같은 시간을 열어 둘 수 있어요. 기본 기능은 개인 계정에서도 쓸 수 있어요. 결제·여러 페이지 같은 기능은 유료 계정에서 늘어나요. 진료 예약은 네이버 예약·차트로 받고평소 예약은 네이버 예약으로 받고, 이건 상담·미팅용으로만 써요.막히면: 구글 캘린더 화면 왼쪽 위 만들기 → 예약 일정에 있어요. 안 보이면 메뉴 이름이 바뀌었을 수 있으니 화면을 캡처해 AI에게 물어요.
