장부는 엑셀 대신 구글 시트 한 권에

구글 시트는 인터넷에 있는 엑셀이에요. 저장 버튼이 없어도 저절로 저장되고, 휴대폰에서도 열리고, AI와 자동화가 바로 읽을 수 있어요. 이 강의에서 새 시트 만들기, 탭 나누기, 강의 속 '제목 줄' 붙여 넣기, 공유하기를 연습해요.

이게 뭐예요장부 한 권이에요. 맨 아래 '탭'이 장부 안의 칸막이(매출, 주문, 재고…)예요.
끝나면'{{place}} 장부' 시트 한 권, 탭 두 개, 제목 줄이 들어간 표
필요한 것PC, {{place}} 구글 계정(강의), 40분
  1. 자세히 따라 하기접기
    1. 크롬 주소 칸에 sheets.new 입력 → 엔터 (바로 새 시트가 열려요)
    2. 왼쪽 위 '제목 없는 스프레드시트'를 눌러 이름을 {{place}} 장부로
    3. 드라이브의 '{{place}} AI' 폴더로 옮기기: 이름 옆 폴더 모양 → 폴더 고르기 → 이동
  2. 맨 아래 '시트1'이 첫 탭이에요. 왼쪽 아래 +를 누르면 탭이 하나 더 생겨요. 탭 이름을 두 번 누르면 바꿀 수 있어요. 연습으로 '연습'과 '메모' 탭을 만들어 봐요.
  3. 강의마다 "이 제목 줄을 A1 칸에 붙여 넣으세요"가 나와요. A1은 왼쪽 맨 위 칸이에요. 복사 버튼으로 복사한 뒤 A1을 한 번 누르고 붙여넣기 하면, 칸마다 알아서 나뉘어 들어가요.
    자세히 따라 하기접기
    1. 아래 '연습 제목 줄'의 복사 누르기
    2. '연습' 탭의 A1 칸 누르기 → 붙여넣기(⌘+V / Ctrl+V)
    3. A1, B1, C1… 칸마다 한 단어씩 들어갔으면 성공막히면: 한 칸에 다 들어갔다면 그 칸을 누르고 데이터 → 텍스트를 열로 분할을 눌러요.
    4. 제목 줄을 고정하기: 보기 → 고정 → 1행 (아래로 내려도 제목이 보여요)
  4. 2행에 아무 값이나 적어요. 휴대폰에 'Google Sheets' 앱을 깔고 같은 계정으로 열면 방금 적은 값이 보여요. 저장 버튼은 없어요.
  5. 오른쪽 위 공유 → 이메일 입력 → '뷰어'(보기만)나 '편집자'(고치기 가능) 고르기. '링크가 있는 모든 사용자'는 손님 정보가 있으면 쓰지 않아요.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
  • 주제가 바뀌면 새 채팅. 반복해서 쓰는 자료(소개서·규칙)는 프로젝트 파일에 한 번만 넣어 둬요.
