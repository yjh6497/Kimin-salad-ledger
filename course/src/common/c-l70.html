무료 플랜Claude 무료도 사용자 지정 커넥터 1개를 연결할 수 있어요. 법령 MCP를 그 1개로 두세요.ChatGPT의 MCP 연결은 유료 기능이에요. 무료라면 법률·세무 질문만 Claude 무료 계정에서 하는 것도 방법이에요.

유료 플랜여러 법령·해석례를 한 번에 엮어 찾는 긴 조사도 끊기지 않아요. 매달 개정 소식 예약 작업도 걸 수 있어요.

이게 뭐예요법전과 국세청 답변집을 대신 뒤져 주는 '조사 담당 직원'을 두는 거예요. 판단은 세무사·노무사가 하고, 이 직원은 근거를 찾아 와요.

실제로 법령 MCP로 고시 별표를 조회해 만든 예시예요.질문만 우리 업종에 맞게 바꾸면 돼요. 근거 조문은 늘 법령 도구가 찾아온 것만 믿어요.

  1. 도우미가 법전을 직접 찾으려면 이 연결이 있어야 해요. 아직이면 강의의 '법령 MCP 연결하기'로 https://mcp.gomdori.app/law 를 커넥터에 등록해요. 새 채팅에서 "법령 도구로 수의사법 제13조의2 원문을 보여 줘"가 되면 준비 끝.아직이면 강의대로, Claude 설정 → 커넥터 → 사용자 지정 커넥터 추가에AI 앱의 커넥터(MCP) 설정에 https://mcp.gomdori.app/law 를 등록해요. 새 채팅에서 "법령 도구로 근로기준법 제17조 원문을 보여 줘"가 되면 준비 끝.막히면: 원문 대신 기억으로 답하면 "법령 도구로 조회해서"라고 다시 부탁해요. 커넥터 메뉴가 안 보이면 설정 화면을 캡처해서 AI에게 물어요.
  2. 규칙을 먼저 알려 두면 매번 같은 방식으로 답해요. AI 비서실 프로젝트 안에 채팅을 만들어요(강의). 아래 '도우미 규칙'을 첫 메시지로 보내요. 프로젝트 지침 맨 아래에 붙여도 돼요.
  3. 법 조문만으로 답이 안 나올 때가 많아요. 질문할 때 "국세청 회신도 찾아 줘", "고용노동부 해석도", "비슷한 판례도"라고 덧붙여요. 그러면 해당 자료까지 찾아요.
  4. 세무사·노무사 상담 때 그대로 보여 주면 상담이 짧아져요. 드라이브에 법무·세무 메모 구글 문서를 만들어요. 답을 받을 때마다 "메모용으로 날짜·질문·결론·근거·확인할 곳 5줄로"라고 해요. 받은 5줄을 문서에 붙여 쌓아요.
