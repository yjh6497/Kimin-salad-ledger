준비 운동 · 약 40분 · PC

같은 일을 시켜도 AI 사용량을 크게 줄일 수 있어요

AI는 글자를 토큰이라는 조각으로 세어서 읽어요. 무료 플랜의 하루 사용량, 유료 플랜의 사용 한도가 모두 이 토큰으로 정해져요. 긴 PDF·사진·끝없이 길어진 채팅이 토큰을 가장 많이 먹어요. 이 강의에서 토큰을 아끼는 습관 7가지와, 파일을 AI가 읽기 쉬운 글자로 바꿔 주는 무료 도구 MarkItDown(마이크로소프트가 공개한 프로그램) 설치·사용법을 익혀요.

이게 뭐예요AI에게 서류를 줄 때 '두꺼운 책' 대신 '필요한 페이지만 타자로 친 종이'를 주는 거예요. AI가 덜 읽으니 빨라지고 한도도 덜 닳아요.
끝나면PDF·워드·엑셀·파워포인트를 한 줄 명령으로 글자 파일(.md)로 바꾸는 MarkItDown, 그리고 채팅을 짧게 쓰는 습관
필요한 것PC(맥 또는 윈도우), 인터넷, 40분 · 복사·붙여넣기(강의)

토큰을 아끼는 습관 7가지

습관왜 아껴지나이렇게 해요
1. 한 채팅에 한 일AI는 답할 때마다 그 채팅의 앞 내용을 처음부터 다시 읽어요. 채팅이 길수록 한 번에 쓰는 양이 커져요.주제가 바뀌면 새 채팅. 길어졌으면 "지금까지 요약 10줄"을 받아 새 채팅에 붙여 이어가기
2. 반복 자료는 프로젝트에 한 번소개서·규칙을 채팅마다 붙여 넣으면 매번 새로 읽어요.프로젝트 지침·파일에 한 번 넣어 두기(강의)
3. 파일은 글자로 바꿔서PDF·사진은 글자 말고도 그림 정보까지 읽느라 무거워요.MarkItDown으로 .md 파일로 바꿔 올리기 (아래)
4. 필요한 부분만100쪽 중 3쪽만 필요해도 100쪽을 다 읽어요.필요한 쪽·필요한 표만 잘라서. 엑셀은 필요한 열만 CSV로
5. 캡처보다 글자캡처 한 장은 같은 내용의 글자보다 무거운 편이에요.화면 글자를 복사할 수 있으면 복사해서. 캡처는 '어디를 눌러야 하나'처럼 화면 모양이 필요할 때만
6. 답 길이를 정하기AI가 길게 쓰면 그만큼 써요."5줄로", "표만", "바뀐 부분만"
7. 고칠 땐 고칠 곳만"처음부터 다시"는 전체를 다시 써요."3번 문단만 더 짧게", "코드는 바뀐 함수만"

MarkItDown 설치하기 (한 번만)

파이썬 3.10 이상에서 돌아요. 아래 방법은 uv(파이썬과 도구를 알아서 깔아 주는 설치 도우미)를 써서 파이썬을 따로 깔지 않아도 돼요.

  1. 터미널은 글자로 명령을 내리는 창이에요. ⌘ + 스페이스 → '터미널' 입력 → 엔터로 열어요.
    자세히 따라 하기접기
    1. 아래 '맥 설치 명령' 첫 줄을 복사해 터미널에 붙여 넣고 엔터 → 설치가 끝날 때까지 기다리기
    2. 터미널 창을 닫았다가 다시 열기 (새로 깐 도구를 알아보게 하려는 거예요)
    3. 둘째 줄을 붙여 넣고 엔터 → MarkItDown 설치
    4. markitdown --help를 쳐서 사용법 글이 나오면 성공막히면: "command not found"가 나오면 터미널을 완전히 끄고(⌘+Q) 다시 열어요. 그래도 안 되면 화면을 복사해 AI에게 "맥에서 uv로 markitdown 설치하다 이렇게 나왔어"라고 물어요(강의).
  2. PowerShell은 윈도우의 명령 창이에요. 시작 버튼 → 'PowerShell' 입력 → 열기.
    자세히 따라 하기접기
    1. 아래 '윈도우 설치 명령' 첫 줄을 복사해 붙여 넣고 엔터
    2. PowerShell을 닫았다가 다시 열기
    3. 둘째 줄을 붙여 넣고 엔터 → markitdown --help로 확인막히면: 빨간 '실행 정책' 오류가 나면 첫 줄 명령을 그대로 다시 붙여 넣었는지 확인해요(앞부분 -ExecutionPolicy ByPass가 그 문제를 풀어 줘요). 회사 PC라 막혀 있으면 관리자에게 물어요.
맥 설치 명령 (터미널에 한 줄씩)
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install 'markitdown[all]'
윈도우 설치 명령 (PowerShell에 한 줄씩)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv tool install "markitdown[all]"

MarkItDown 쓰기

  1. 명령 창에 cd (cd 뒤 한 칸 띄우기)를 치고, 파일이 있는 폴더를 창 안으로 끌어다 놓은 뒤 엔터. 폴더 위치가 자동으로 적혀요.
  2. markitdown 견적서.pdf -o 견적서.md → 같은 폴더에 견적서.md가 생겨요. 워드(.docx)·엑셀(.xlsx)·파워포인트(.pptx)·HTML·CSV도 같은 방법이에요.
  3. PDF 대신 .md를 올리거나, 열어서 필요한 부분만 복사해 붙여 넣어요. .md는 메모장(텍스트 편집기)으로 열 수 있는 글자 파일이에요.
  4. 아래 '한꺼번에 바꾸기'를 쓰면 폴더 안 PDF를 모두 .md로 바꿔요.주의: 스캔한 PDF(종이를 찍은 그림)는 글자가 거의 안 나올 수 있어요. 그런 파일은 그대로 AI에 올려 읽게 해요. 한글(HWP)은 지원 목록에 없으니 한글에서 PDF나 워드(DOCX)로 저장한 뒤 바꿔요.
맥: 폴더 안 PDF 한꺼번에 바꾸기
for f in *.pdf; do markitdown "$f" -o "${f%.pdf}.md"; done
윈도우: 폴더 안 PDF 한꺼번에 바꾸기
Get-ChildItem *.pdf | ForEach-Object { markitdown $_.FullName -o ($_.BaseName + ".md") }
설치가 어렵다면대신 이렇게
워드·구글 문서구글 문서로 열고 파일 → 다운로드 → 마크다운(.md)
엑셀·구글 시트필요한 탭만 파일 → 다운로드 → CSV
PDFPDF에서 필요한 쪽의 글자를 끌어 복사해 붙여 넣기
AI에게 맡기기Claude 데스크톱 앱이나 터미널 AI(강의)에게 "이 폴더 PDF를 markitdown으로 .md로 바꿔 줘"라고 부탁

바꾼 뒤 한 번 훑어보기. 표가 많은 PDF는 칸이 어긋날 수 있어요. 금액·면적 같은 숫자는 원본과 한 번 맞춰 봐요. 손님·건축주 개인정보가 든 파일은 바꾼 .md도 똑같이 조심해서 다뤄요.
