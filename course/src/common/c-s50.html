AI에게 손을 달아 주면 클릭과 입력도 대신해요

지금까지 AI 비서는 말로 답했어요. 손을 달아 주면 직접 움직여요. 사이트를 열어 칸을 채우고, 화면을 읽어 표로 모아요. 스크립트와 봇(정해진 일을 혼자 하는 작은 프로그램)도 직접 만들어 돌려요. 손은 세 가지예요. 내장 브라우저는 {{place}} 전용 브라우저, 크롬은 {{owner:이}} 로그인해 둔 브라우저, 터미널·봇은 정해진 시각에 혼자 도는 일꾼이에요. 강의마다 아래쪽에 있는 '세 가지 손으로 자동화' 상자는 이 강의 내용을 따라요.

무료 플랜브라우저 AI와 터미널 AI는 유료 플랜 기능이에요. 무료라면 채팅에서 받은 초안·스크립트를 {{owner:이}} 붙여 넣어요. 자동화는 스크립트 트리거·텔레그램 봇(무료)으로 해요.

유료 플랜세 가지 손을 모두 쓸 수 있어요. 처음엔 하나만 켜고, 익숙해지면 늘려요.

왜 필요해요AI가 말로만 알려 주면 결국 {{owner:이}} 직접 화면을 열고 칸을 채워야 해요. 손을 달아 주면 반복 입력·자료 모으기는 AI가 하고, {{owner}}는 마지막 확인만 하면 돼요.
이게 뭐예요말로만 조언하던 비서에게 마우스와 키보드를 쥐여 주는 거예요. 시킨 화면을 열고, 칸을 채우고, 중요한 버튼 앞에서는 멈춰 기다려요.

순서누가무엇을
1 · 지시직원 채팅 (예: 09 배달앱·매장 개선01 플레이스 매니저)할 일을 '작업 지시서'로 써요. 어느 손, 열 곳, 넣을 값, 멈출 곳, 결과 남길 곳이 들어가요
2 · 실행세 가지 손 중 하나지시서대로 열고 채우고 읽어요. 저장·제출·발송 앞에서 멈춰요
3 · 기록손결과를 장부 탭이나 드라이브 '수집' 폴더에 날짜와 함께 남겨요
4 · 결정{{owner}} (텔레그램 승인함 강의)버튼 하나로 '해요 / 그대로'. 결정도 장부에 남아요
5 · 기억업무일지 강의5줄로 남기면 다음 주 브리핑과 다른 직원 채팅이 이어서 읽어요
  1. {{place}} 일만 하는 브라우저를 하나 따로 둬요. 그래야 개인 메일·쇼핑과 섞이지 않아요.
    자세히 따라 하기접기
    1. Claude 데스크톱 앱(맥)을 설치하고 {{place}} 계정으로 로그인해요. 채팅에서 "브라우저로 스마트플레이스 열어줘"라고 하면 앱 안에 브라우저 창이 열려요
    2. ChatGPT 입력창의 + → 에이전트 모드를 고르고 "스마트플레이스 열어줘"라고 보내요. 로그인 화면이 나오면 화면을 넘겨받아 {{owner:이}} 직접 로그인해요
    3. 처음 한 번 스마트플레이스·카카오맵 매장관리·배달앱 사장님 사이트에 {{owner:이}} 직접 로그인해 둬요비밀번호·인증번호는 채팅에 쓰지 않아요. 로그인 화면이 나오면 AI는 멈추고 기다려요.
  2. 이미 로그인해 둔 사이트를 그대로 쓰니 빨라요. 대신 AI가 들어갈 수 있는 사이트를 좁게 정해요.
    자세히 따라 하기접기
    1. 크롬 웹 스토어에서 'Claude' 확장 프로그램(크롬에 붙이는 추가 기능)을 설치하고 로그인해요. 확장 설정에서 쓸 사이트만 허락해요(smartplace.naver.com, 배달앱 사장님 사이트, 거래처 몰)
    2. ChatGPT Atlas를 설치(맥)하고 로그인해요. 사이드바의 에이전트에게 지금 보는 화면 일을 맡겨요
    3. 자세한 신호등 규칙(읽기·채우기·손으로만)은 강의에 있어요
  3. 터미널은 글자로 컴퓨터에 명령하는 까만 창이에요. 터미널 AI는 맥 안의 '{{place}}자동화' 폴더에서 일해요. 스크립트를 만들고, 시험하고, 고치는 일을 대신해요. 명령을 실행하기 전마다 허락을 물어요.
    자세히 따라 하기접기
    1. Finder → 응용 프로그램 → 유틸리티 → 터미널을 열어요
    2. Claude Code를 설치해요. 아래 '설치 명령' 첫 줄을 붙여 넣고 Enter를 눌러요. 끝나면 claude를 입력하고 {{place}} 계정으로 로그인해요막히면: 'command not found'가 뜨면 터미널을 닫았다가 다시 열고 claude를 쳐 봐요. 그래도 안 되면 화면을 캡처해 AI에게 보여 줘요.
    3. Codex를 설치해요. 아래 '설치 명령' 둘째 줄을 붙여 넣고 Enter를 눌러요. 끝나면 codex를 입력하고 ChatGPT 계정으로 로그인해요
    4. 윈도우라면 시작 → PowerShell을 열어요. Claude Code는 '설치 명령' 셋째 줄 · Codex는 Node.js 설치 후 둘째 줄을 붙여 넣어요. 맥 봇 자리는 윈도우 작업 스케줄러가 대신해요(launchd 대신)
    5. 폴더를 만들어요. mkdir ~/{{place}}자동화 && cd ~/{{place}}자동화를 붙여 넣고 Enter. 그다음 터미널 AI에게 아래 '{{place}} 규칙 파일'을 CLAUDE.md 또는 AGENTS.md 이름으로 저장해 달라고 부탁해요
    6. 허락 질문이 나오면 무엇을 하려는지 읽고 '예'를 눌러요. "모두 자동 허용"은 켜지 않아요login·token·credentials 파일은 이 폴더 안 'secret' 폴더에만 두고, 채팅이나 다른 사람에게 보내지 않아요.

    AI에게 보내는 글이 아니에요. 내 AI에 맞는 한 줄만 복사해서 터미널(윈도우는 PowerShell)에 붙여 넣고 Enter를 눌러요.

  4. 손은 지시가 분명해야 엉뚱한 버튼을 누르지 않아요. 직원 채팅에서 할 일을 정하면 아래 '작업 지시서 부탁문'을 보내요. 받은 지시서를 손에게 붙여요. 지시서 하나에 멈출 곳과 결과 남길 곳이 꼭 들어가요.
  5. 작은 일 하나로 손이 잘 움직이는지 봐요. Claude 앱 내장 브라우저 또는 ChatGPT 에이전트 모드로 네이버 플레이스 화면을 읽게 해요. 장부 '지도정보' 탭과 다른 곳을 찾아 달라고 해요. 결과를 '09' 채팅에 붙여 업무일지 5줄로 남겨요. 여기까지 되면 연결 끝이에요.

- 손: 내장 브라우저 / 크롬 / 터미널·봇 중 알맞은 것과 이유 한 줄
- 열 곳: 사이트나 파일 이름
- 넣을 값 또는 읽을 것: 표로
- 멈출 곳: 저장·제출·발송·결제 버튼 앞
- 결과 남길 곳: 장부 탭 이름이나 드라이브 '수집' 폴더, 날짜 붙이기
- 끝나면: 승인함 한 줄(필요할 때)과 업무일지 5줄
손에게 그대로 붙일 수 있게 한 덩어리로 써줘.

# 우리 {{place}} 자동화 규칙
- {{place}}: {{biz}}. 장부는 구글 드라이브 '우리{{place}} 장부' 폴더의 '매장 장부' 시트
- 알림: 텔레그램 봇(tg, ask). 결정이 필요하면 승인함에 한 줄
- 비밀: 토큰·로그인 파일은 secret 폴더와 스크립트 속성에만. 코드·채팅·깃허브에 쓰지 않기
- {{customer}} 이름·전화·주소는 모으지 않기. 장부 숫자는 사람 확인 없이 바꾸지 않기
- 돈·발송·삭제·약관 동의는 사람이. 보안문자·차단 경고가 나오면 멈추기
- 새 자동화를 켜면 '자동화' 탭에 한 줄, 끝나면 업무일지 5줄 초안

토큰 아끼기강의
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
