준비 운동 · 약 30분 · PC와 휴대폰

이 코스에서 가장 많이 하는 손동작 네 가지

이 코스는 복사 버튼 → AI 채팅에 붙여 넣기 → 화면 캡처해서 보여 주기 → 받은 파일 찾기를 계속 반복해요. 이 네 가지만 손에 익으면 나머지 강의가 훨씬 쉬워져요. 맥·윈도우·휴대폰 방법을 모두 적었어요.

왜 필요해요복사·캡처·파일 찾기가 서툴면 AI에게 한 번 부탁하는 데도 한참 걸리고 중간에 지쳐요. 이 네 가지 손동작만 익혀 두면 이후 모든 강의가 훨씬 빠르고 쉬워져요.
이게 뭐예요AI에게 일을 시킬 때 쓰는 '손발'이에요. 말로 설명하기 어려운 건 캡처 한 장이 대신 말해 줘요.
끝나면부탁문을 복사해 붙이고, 화면을 찍어 AI에게 보여 주고, 내려받은 파일을 찾을 수 있어요

되돌리기⌘ + ZCtrl + Z(앱마다 다름)
화면 일부 캡처⌘ + Shift + 4 → 끌어서 고르기윈도우키 + Shift + S → 끌어서 고르기아이폰: 옆 버튼 + 볼륨 올리기 / 갤럭시: 옆 버튼 + 볼륨 내리기

⌘는 맥 키보드의 'command' 키예요. 윈도우는 키보드 왼쪽 아래 'Ctrl' 키를 써요.

  1. 강의 속 회색 상자 오른쪽 위의 복사 버튼을 누르면 상자 글 전체가 복사돼요. AI 채팅 입력 칸을 한 번 누르고 붙여넣기 하면 끝이에요.
    자세히 따라 하기접기
    1. 아래 '연습용 부탁문'의 복사 누르기 → 버튼 글자가 '복사됨'으로 바뀌면 성공
    2. AI 채팅창(강의) 입력 칸을 한 번 누르고 붙여넣기 → 보내기
    3. ○○처럼 비워 둔 자리는 보내기 전에 우리 {{place}} 값으로 고쳐요막히면: 복사 버튼이 안 되면 글을 길게 눌러(PC는 끌어서) 직접 고르고 복사해요.
  2. "이 화면에서 뭘 눌러야 해?"는 이 코스에서 제일 많이 쓰는 질문이에요. 캡처한 그림은 채팅 입력 칸에 붙여넣기 하거나, 클립(📎) 모양을 눌러 올려요.
    자세히 따라 하기접기
    1. 위 표의 단축키로 캡처 → 맥은 바탕화면, 윈도우는 알림 창에서 열 수 있어요
    2. AI 채팅 입력 칸에 붙여넣기 (또는 📎 → 파일 고르기)
    3. 그림과 함께 "이 화면에서 ○○하려면 어디를 눌러?"라고 쓰기막히면: 손님 이름·전화번호가 보이는 화면은 그 부분을 가리고 찍어요.
  3. 엑셀·PDF를 내려받으면 대부분 다운로드 폴더로 가요. 크롬에서는 오른쪽 위 아래 화살표(↓)를 누르면 방금 받은 파일이 보여요.
    자세히 따라 하기접기
    1. 맥: 화면 아래 줄의 파란 얼굴(Finder) → 왼쪽 '다운로드'
    2. 윈도우: 노란 폴더(파일 탐색기) → 왼쪽 '다운로드'
    3. 휴대폰: 아이폰 '파일' 앱 → 다운로드 / 갤럭시 '내 파일' 앱 → 다운로드
  4. 구글 드라이브에 '{{place}} AI' 폴더를 하나 만들고 받은 자료를 모두 거기에 넣어요. 나중에 AI에게 "그 폴더 자료를 봐 줘"라고 하면 끝나요.

토큰 아끼기강의
  • PDF는 그대로 올리면 무거워요. markitdown 파일.pdf -o 파일.md로 바꿔 필요한 쪽만 붙여 넣어요. 스캔한 PDF는 그대로 올려요.
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
