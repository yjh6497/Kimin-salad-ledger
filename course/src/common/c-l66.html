단축어 한 번으로 이번 주 안내 문자를

{{place}} 휴대폰이 아이폰이고 맥북을 쓴다면, 맥의 메시지 앱과 단축어로 이번 주 안내 대상에게 한 명씩 문자를 보낼 수 있어요. 상대가 아이폰이면 아이메시지(파란 말풍선), 아니면 아이폰을 거쳐 일반 문자(초록)로 가요. 연락처 파일은 맥 안에서만 쓰고 지워요.

단축어 '안내 문자'한 줄씩 메시지 앱으로 보내기

전화번호가 클라우드·AI로 가지 않게 나눠 두는 흐름이에요.

  1. 자세히 따라 하기접기
    1. 맥과 아이폰을 같은 Apple 계정으로 로그인
    2. 아이폰 설정 → 앱 → 메시지 → 문자 메시지 전달 → 맥 이름 켜기(메뉴 위치는 iOS 버전에 따라 조금 달라요)
    3. 맥 메시지 앱 → 설정 → iMessage에서 {{place}} 휴대폰 번호가 '연락 받을 주소'로 체크돼 있는지 확인
    4. 맥 메시지 앱에서 {{owner}} 다른 번호로 문자 한 통 보내 보기{{place}} 번호가 개인 번호와 같은 휴대폰이면, {{place}} 전용 아이폰이나 업무용 번호를 쓰는 걸 권해요.
  2. 월요일 재방문 메일(강의)에서 채널이 '문자'이고 동의 Y인 줄만 필터로 걸러, 고객번호와 안내 문구 두 칸을 복사해요.
  3. 차트고객 명단(예약·포스 프로그램)에서 이번 주 대상의 고객번호·전화를 엑셀로 내보내 맥의 '{{place}} 발송' 폴더에 저장 → Numbers(또는 엑셀)로 열어 복사한 문구를 고객번호로 맞춰 붙여요(VLOOKUP·XLOOKUP). 마지막 열에 =전화&"|"&문구 → 그 열만 복사해 텍스트 편집기에 붙여 발송목록.txt로 저장.
    합치기 수식이 어렵다면접기
    1. AI에게 전화번호 없이 "A열 고객번호, B열 전화, D열 고객번호, E열 문구. B와 E를 고객번호로 맞춰 '전화|문구' 한 칸으로 만드는 Numbers 수식"이라고 물어요
    2. 전화번호가 담긴 파일은 AI 채팅·구글 드라이브에 올리지 않아요
  4. 자세히 따라 하기 (맥 단축어 앱)접기
    1. 맥 단축어 앱 → + → 이름 안내 문자
    2. 파일 선택(발송목록.txt) → 텍스트 가져오기 → 텍스트 분할: 새로운 줄
    3. 각 항목을 반복 안에: 텍스트 분할: 사용자 지정 '|' → 목록에서 항목 가져오기: 첫 번째 항목(전화) → 목록에서 항목 가져오기: 마지막 항목(문구) → 메시지 보내기(메시지=문구, 받는 사람=전화) → 대기 3초
    4. 반복 끝 뒤에 알림 보기: 보내기 끝
    5. 처음엔 '메시지 보내기'의 실행할 때 보기를 켠 채로, {{owner}} 번호 2줄만 든 파일로 시험익숙해진 뒤에도 한 번에 보내는 양은 적게. 하루 수십 건이 넘으면 통신사 스팸 차단이 생길 수 있어 문자 발송 서비스나 알림톡이 맞아요.
  5. 재방문 탭 I열(연락한 날)에 날짜, 발송목록.txt와 연락처 엑셀은 삭제. 답장("예약할게요", "그만 받을게요")은 실장님이 메시지 앱에서 보고 차트·시트에담당 {{staff:이}} 메시지 앱에서 보고 고객 명단·시트에 반영해요.

개인 휴대폰 문자도 같은 규칙이에요. 진료 안내는 진료에 필요한 범위로,예약·이용 안내는 꼭 필요한 범위로, 광고가 섞이면 사전 동의·밤 9시~아침 8시 제한·수신거부 안내가 필요해요(정보통신망법 제50조, 강의). 보내는 사람 이름([{{place}} 이름])은 첫머리에.
