인스타그램 자동화 ③ 사진은 페이지로, 차례는 알림이

자동 게시 봇(강의)을 오래 편하게 돌리는 구조예요. 직원과 사장님이 휴대폰 사진 보내기 페이지로 사진을 올리면 이름이 자동으로 붙어요. 사진이 비거나 승인이 밀리면 알림이 와요. 승인도 승인함 페이지에서 버튼 하나로 해요. 휴무·품절 같은 긴급 공지도 여기서 바로 올려요.

무료 플랜사진 보내기·승인함 페이지와 알림은 구글 앱스 스크립트 웹앱이라 무료예요. 게시는 앞 강의의 맥 봇이 해요.

유료 플랜같은 구조에 AI 예약 작업으로 주간 성과 해설과 다음 주 계획을 붙여요.

왜 필요해요단톡방으로 사진을 받으면 사진이 묻히고, 올릴 날 사진이 없어 게시가 빠지기 쉬워요. 사진 받기·승인·알림을 한곳에 모으면 사장님은 휴대폰에서 버튼만 누르면 돼요.
이게 뭐예요가게 단톡방 대신 '사진 우체통'과 '결재함'을 휴대폰에 하나씩 두는 거예요. 직원은 우체통에 사진만 넣고, 사장님은 결재함에서 버튼만 눌러요. 빠진 게 있으면 알림이 먼저 알려 줘요.
끝나면휴대폰 홈 화면의 '인스타 자동화실'(사진 보내기·승인함·긴급 공지), 사진 은행 폴더, 사진·승인·주간 요약 알림 메일 세 가지가 남아요.

1단계 · 사진 보내기·승인함 페이지

  1. 누가 사진을 올렸는지, 언제까지 필요한지 알아야 알림을 보낼 수 있어요. L열에 사진 올린 사람, M열에 사진 기한(게시 2일 전, 수식으로)을 더해요. 상태 드롭다운에는 사진 도착, 수정요청, 제안을 더해요.
    자세히 따라 하기접기
    1. '게시계획' L1에 사진 올린 사람, M1에 사진 기한을 써요
    2. M2 칸에 =IF(A2="","",A2-2)를 입력해요. M2를 복사해 아래 줄에 붙여 넣어요
    3. H열 상태 드롭다운을 데이터 → 데이터 확인에서 열어 옵션을 추가해요. 초안, 사진 도착, 꾸밈완료, 수정요청, 승인, 게시됨, 지연, 실패, 제안
  2. 바쁜 날엔 사진을 못 찍을 수도 있어요. 그래서 비상용 사진을 모아 둬요. 드라이브 'SNS/사진은행'에 언제 써도 되는 사진(매장 전경, 대표 메뉴 기본 컷, 재료 클로즈업)을 20장쯤 넣어요. 기한까지 사진이 없을 때 대신 쓸 수 있어요.
    자세히 따라 하기접기
    1. 드라이브 '우리가게 장부/SNS' 안에 사진은행 폴더를 만들어요
    2. 사진 이름 앞에 종류를 붙여요. 예: 전경_01, 웜볼_기본, 재료_로메인
    3. 석 달에 한 번 계절에 맞게 몇 장씩 바꿔요
  3. 웹앱(주소로 여는 우리 가게 전용 작은 앱)을 AI에게 만들어 달라고 해요. '08 자동화·연결' 채팅에 아래 '인스타 자동화실 웹앱 부탁문'을 보내요. 그러면 Code.gs와 index.html 두 파일 코드를 줘요. 직원 웹앱(강의)과 같은 방식이에요.
    자세히 따라 하기접기
    1. '매장 장부'에서 확장 프로그램 → Apps Script를 열어요. 왼쪽 파일 +로 받은 파일 두 개를 만들어 붙여 넣어요 (이미 있는 스크립트와 이름이 겹치지 않게 AI가 정해 줘요)
    2. 배포 → 새 배포 → 웹 앱을 눌러요. 실행: 나, 액세스: 모든 사용자로 고르고 배포해요. 권한을 허용해요막히면: '확인되지 않은 앱' 창이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용을 눌러요. 내가 붙인 코드라 괜찮아요.
    3. 받은 주소를 휴대폰으로 열어 사장님 PIN으로 들어가 봐요. 사진 보내기와 승인함 두 화면이 보이면 성공이에요
    4. Safari 공유 버튼 → 홈 화면에 추가를 누르고 이름을 '인스타 자동화실'로 해요주소를 아는 사람은 페이지를 열 수 있어요. 그래서 PIN이 꼭 필요하고, 이 웹앱은 장부의 '게시계획'과 '직원' 시트만 읽게 만들어요. 매출 숫자는 절대 보이지 않게 부탁문에 적혀 있어요.
  4. 직원이 볼 화면은 적을수록 헷갈리지 않아요. 알바생에게는 사진 보내기 화면만 보여요. 승인함은 사장님(원하면 매니저)만 봐요. 권한은 직원 시트의 역할을 그대로 써요(강의).
    자세히 따라 하기접기
    1. 직원 단톡방에 주소와 사용법 3줄을 보내요 (AI에게 "직원용 사진 보내기 안내 3줄"을 부탁해요)
    2. 첫 주는 사장님이 직접 한 장 올려 보여 줘요. 할 일 카드 → 사진 찍기 → 올리기 → '받았어요'
    3. 좋은 사진을 올린 직원은 게시물 캡션이나 단톡방에서 이름을 불러 고마움을 전해요. 계속 올리게 하는 가장 쉬운 방법이에요직원 얼굴이 나온 사진은 본인 동의를 받은 것만 승인해요. 손님 얼굴이 나온 사진은 쓰지 않아요.

이 글을 그대로 복사해서 '08 자동화·연결' 채팅에 붙여 넣으세요. ○○ 자리만 우리 가게 값(폴더 ID, 매니저 허용 여부, 대표색)으로 바꿔요.

인스타 자동화실 웹앱 부탁문 · 자동화 엔지니어
'매장 장부' 구글 시트에 붙일 휴대폰용 웹앱 '인스타 자동화실'을 앱스 스크립트로 만들어줘. Code.gs와 index.html로 나눠서, 붙이는 곳과 배포 방법까지 순서대로 알려줘.
- 로그인: '직원' 시트(이름, 역할, PIN, 상태)의 PIN으로. 상태가 '퇴사'면 못 들어오게. 5번 틀리면 10분 잠금
- 이 웹앱은 '게시계획'과 '직원' 시트만 읽고 쓰기. 다른 시트(매출·지출·급여)는 절대 열지 마
- 화면 1 · 사진 보내기 (모든 역할): 게시일이 오늘~7일 뒤이고 원본 사진이 없는 줄을 카드로 (게시일, 주제, 메모의 사진 구도). 카드마다 사진 찍기/고르기 버튼(여러 장 가능)
  올린 사진은 드라이브 폴더 ○○(SNS/원본 폴더 ID)에 계획의 원본 사진 이름으로 저장 (여러 장이면 _1, _2). 상태 '사진 도착', L열에 올린 사람 이름. 한 장 15MB 넘으면 안내
  아래쪽에 '아이디어 사진 보내기': 사진 + 한 줄 메모 → 게시계획에 새 줄, 상태 '제안'
- 화면 2 · 승인함 (역할 '사장'만, 매니저 허용은 ○○): 상태 '꾸밈완료' 줄을 카드로. 완성 이미지 미리보기(폴더 ○○), 게시일·시각, 캡션·해시태그
  버튼: [승인] → 상태 '승인' / [수정 요청] → 메모 입력 후 상태 '수정요청' / [시각 바꾸기] / [사진 은행에서 고르기] → 폴더 ○○(SNS/사진은행) 사진 목록에서 골라 원본으로 복사, 상태 '사진 도착' / [앱에서 직접 올리기] → 이미지 열기 + 캡션 복사 버튼
- 화면 3 · 긴급 공지 (사장만): 문구 한 줄 입력 → 게시계획에 새 줄 (형식 '스토리', 게시일·시각 지금, 썸네일 문구 = 입력한 문구, 상태 '승인', 메모 '긴급')
- 휴대폰 기준 큰 버튼, 다크 모드, 글씨 16px 이상. 디자인 가이드 색 ○○

  1. 사장님이 매일 시트를 열어 보지 않아도 되게, 할 일이 생기면 메일로 알려 줘요. 같은 Apps Script 프로젝트에 아래 '자동화실 알림 부탁문'으로 받은 코드를 붙여요. 그리고 트리거(정해진 시간에 저절로 실행되게 하는 알람) 세 개를 걸어요. 문제가 있을 때만 알림이 와요.
    자세히 따라 하기접기

    2. 왼쪽 시계 모양 트리거 → 트리거 추가를 눌러요. 사진 알림 함수 · 시간 기반 · 일 단위 · 오전 9~10시로 골라요
    3. 같은 방법으로 두 개 더 걸어요. 승인 알림 함수는 오후 5~6시, 주간 요약 함수는 주 단위 · 월요일 오전 8~9시예요
    4. 세 트리거 모두 실패 알림 설정 → 즉시 알림으로 해요
    5. '자동화' 시트(강의)에 세 줄 적어요휴대폰 Gmail 앱에서 알림 메일에 별표 라벨을 자동으로 붙이는 필터를 만들면(보낸사람 나, 제목 [인스타]), 중요 알림만 소리 나게 할 수 있어요.

    자세히 따라 하기접기
    1. '08 자동화·연결' 채팅에 decorate.py, post.py를 첨부하고 아래 '봇 수정 부탁문'을 보내요
    2. 받은 코드로 바꾸고 터미널에서 python decorate.py --row 행번호로 한 줄 시험해요막히면: 오류 글자가 나오면 그대로 복사해 같은 채팅에 붙이고 "이 오류 고쳐 줘"라고 해요.

이 강의 자동화도구 고르는 법은 강의
  • 웹앱
    사진 보내기·승인함·긴급 공지직원은 사진만 올리고, 사장님은 버튼으로 승인해요. 이름 붙이기·상태 바꾸기는 웹앱이 해요.
  • 스크립트 트리거
    09시 사진 · 17시 승인 · 월요일 요약시간 트리거 세 개. 할 일이 있을 때만 메일이 와요.
  • 맥 봇
    15분마다 꾸미기 → 게시사진이 올라오면 30분 안에 승인함에 들어와요. 승인하면 정해진 시각에 게시돼요. 긴급 공지는 다음 실행에 바로 스토리로 올라가요.
  • AI 예약 작업
    성과 해설과 다음 달 계획유료매달 마지막 주 예약 작업이 인스타성과를 보고 다음 달 게시계획 표를 보내요.무료Claude 무료는 예약 작업이 없어요. 매달 마지막 주 휴대폰 반복 알림이 울리면 그 채팅에 한 줄 보내요.ChatGPT 무료 예약 작업으로 매달 마지막 주 받아요. 시간은 대략적으로 정해지고 동시에 3개까지예요.Claude 무료는 매달 마지막 주 휴대폰 알림 + 한 줄, ChatGPT 무료는 예약 작업(하루 1번 이하, 3개까지)으로 받아요.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
