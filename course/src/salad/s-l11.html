채소 시세가 매일 장부에 들어오게

가장 쉬운 길은 세 단계예요. API 키(자료를 받아 갈 수 있는 출입증) 받기 → AI가 짜 준 앱스 스크립트(시트에 붙이는 작은 프로그램) 붙여 넣기 → 트리거(정해진 시간에 저절로 실행되게 하는 알람)로 매일 실행.

왜 필요해요채소 값을 매번 사이트에서 찾아 적으면 귀찮아서 결국 안 하게 돼요. 매일 아침 시세가 장부에 저절로 쌓여, 값이 오른 날을 바로 알고 원가를 미리 챙겨요.
이게 뭐예요장부에 '알람 시계'를 달아 두는 거예요. 매일 아침 6시가 되면 시트가 알아서 나라 사이트에서 채소 시세를 받아 적어요.
끝나면로메인·양상추·토마토·오이 가격이 날짜별로 쌓이는 '시세' 탭
필요한 것PC, 구글 계정, 휴대폰 본인 인증, 첫 설정 1시간(키 승인까지 며칠) · 코드 붙이기가 처음이면 강의 먼저
공공데이터포털API 키 발급
앱스 스크립트AI가 짠 코드, 매일 6시
'시세' 탭날짜별로 자동 기록
  1. 시세 자료를 받으려면 먼저 나라 사이트에 "이 자료 쓸게요" 하고 신청해야 해요. PC에서만 신청할 수 있어요.
    자세히 따라 하기접기
    1. data.go.kr 오른쪽 위 회원가입 → 개인회원 → 휴대폰 본인 인증
    2. 로그인 후 농수축산물 유통단계별 가격 페이지 열기
    3. 활용신청 → 활용 목적에 "매장 식자재 시세 참고" 입력 → 약관 동의 → 신청
    4. 같은 방법으로 상가(상권)정보도 신청 (상권 분석용)
  2. 인증키는 자료를 받아 갈 때 보여 주는 출입증이에요. 코드에 넣어야 하니 미리 복사해 둬요.
    자세히 따라 하기접기
    1. 마이페이지 → 데이터활용 → Open API → 활용신청 현황
    2. 신청한 API를 눌러 일반 인증키(Decoding) 복사
    3. 휴대폰 메모에 '공공데이터 키'로 저장. 다른 사람에게 보내지 마세요승인 직후에는 키가 바로 안 될 수 있어요. 몇 시간 뒤 다시 시도하세요.
  3. 코드는 직접 짜지 않고 AI에게 받아요. '08 자동화·연결' 채팅에 아래 '채소 시세 자동 수집 부탁문'을 보내요.
  4. 자세히 따라 하기접기
    1. '매장 장부' 파일 맨 아래 +로 시트를 하나 추가하고 이름을 시세로 (새 파일 아님)
    2. 시트 위쪽 메뉴 확장 프로그램 → Apps Script
    3. 새 창에 있던 글자를 모두 지우고 AI가 준 코드를 붙여 넣기 → 키 자리에 내 인증키 붙여 넣기
    4. 위쪽 디스크 모양 저장 → 실행
    5. 권한 창이 뜨면 권한 검토 → 내 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동 → 허용'Google에서 확인하지 않은 앱' 경고는 내가 만든 스크립트라서 뜨는 정상 안내예요.
    6. '시세' 탭에 숫자가 들어왔는지 확인막히면: 빨간 오류가 나면 오류 문장을 그대로 복사해 '08 자동화·연결' 채팅에 붙여 넣어요. 키 오류라면 승인 직후라 아직 안 되는 것일 수 있어요.
  5. 매번 실행 버튼을 누르지 않으려고 알람을 맞춰요.
    자세히 따라 하기접기
    1. Apps Script 왼쪽의 시계 모양 트리거
    2. 오른쪽 아래 + 트리거 추가
    3. 실행할 함수: AI가 알려 준 이름 / 이벤트 소스: 시간 기반 / 유형: 일 단위 타이머 / 시간: 오전 6시~7시 → 저장
  6. AI가 다른 서비스 도구를 직접 쓰게 하는 연결선이에요. 처음이면 건너뛰어도 돼요. 쓰려는 서비스가 원격 MCP 서버 주소를 줄 때만 연결해요. 한국 서비스로는 카카오의 PlayMCP(카톡 나와의 채팅방, 톡캘린더, 카카오맵 등)가 대표적이에요. Claude는 설정 → 커넥터 → 사용자 지정 커넥터 추가에서 등록해요. ChatGPT는 유료 플랜의 개발자 모드에서 등록해요. 무료 플랜은 사용자 지정 커넥터를 1개까지 쓸 수 있으니 가장 필요한 것 하나만 고르세요. 무료 플랜은 개발자 모드가 없으니 이 단계는 건너뛰고 앱스 스크립트로 연결하세요.

이 글을 그대로 복사해서 '08 자동화·연결' 채팅에 붙여 넣으세요. 채소 이름은 우리 가게에서 많이 쓰는 것으로 바꿔도 돼요. 아래 포스사 문의 문장은 ○○ 자리에 가게 이름을 넣어 포스 회사 고객센터에 보내요.

채소 시세 자동 수집 부탁문
공공데이터포털 '농수축산물 유통단계별 가격' API를 구글 시트 Apps Script로 매일 호출해서 '시세' 탭에 로메인, 양상추, 토마토, 오이 소매가격을 날짜별로 쌓는 코드를 만들어줘. 인증키 넣을 자리를 표시하고, 실행할 함수 이름과 트리거 설정 방법도 초보 기준으로 단계별로 알려줘.
포스사 연동 문의 문장
안녕하세요, ○○매장입니다. 매출·메뉴별 판매 데이터를 엑셀 정기 다운로드나 API로 받을 수 있는지 문의드립니다. 가능하다면 신청 방법과 비용, 제공 항목(결제수단, 채널, 메뉴, 시간대)을 알려 주세요.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
  • 코드를 고칠 때는 "전체 다시" 대신 "바뀐 함수만" 달라고 해요. 오류는 빨간 줄 몇 줄만 복사해 보내요.
