매일 아침, 봇이 주문내역을 장부에 쌓아요

배민·요기요 사장님 사이트의 주문내역에는 엑셀 내려받기 버튼이 없어요. 그래서 봇(대신 일하는 작은 프로그램)이 사람처럼 주문내역 화면을 열어 목록을 읽어요. 읽은 내용은 Google Sheets API(프로그램이 구글 시트에 글을 쓰는 통로)로 장부에 바로 적어요. 처음 한 번 최근 30일을 모아요. 그다음부터는 매일 아침 자동으로 쌓아요.

무료 플랜파이썬, Playwright, Google Sheets API, 맥 예약 실행 모두 일반 사용 범위에서 무료예요. 코드는 AI 채팅에서 받는데, 무료 사용량이 모자라면 플랫폼 하나씩 나눠서 부탁하세요.

유료 플랜코드를 길게 주고받아도 사용량이 넉넉해서, 사이트 화면이 바뀌었을 때 고치는 대화가 끊기지 않아요.

왜 필요해요매일 배달앱 화면을 보고 장부에 옮겨 적으면 하루 20~30분이 들고, 숫자를 잘못 옮기기도 쉬워요. 봇이 새벽에 대신 모아 두면 아침엔 합계만 확인하면 돼요.
이게 뭐예요매일 새벽 알바생이 배달앱 주문 화면을 보고 장부에 옮겨 적는 일을, 사장님 맥 속 로봇이 대신 하는 거예요.
끝나면매일 아침 6시에 배민·요기요 주문이 저절로 쌓이는 '주문원장' 시트와, 날짜별·플랫폼별 합계 시트가 생겨요.
필요한 것맥, 배민·요기요 사장님 계정, 구글 계정, 하루 · 심화 강의예요. 코드 붙이기가 처음이면 강의, 막히면 강의를 먼저 봐요.

로그인과 본인 인증은 사람이 직접 하고, 봇은 그 로그인 상태를 빌려 써요. 손님 이름·전화·주소는 읽지도 저장하지도 않아요.

먼저 알아 둘 것

지킬 것이유
내려받기가 되면 그게 먼저사이트가 엑셀·CSV 내려받기를 주는 메뉴(예: 정산 내역)는 화면 읽기보다 정확하고 덜 깨져요. 화면 읽기는 내려받기가 없는 주문내역에만 써요
로그인은 사람이 직접. 봇은 저장된 로그인 상태만 써요아이디·비밀번호를 코드에 넣지 않아요. 로그인 확인, 보안 문자(캡차), 추가 인증이 나오면 봇은 멈추고 사장님에게 알려요. 우회하지 않아요
하루 한 번, 사람 속도로짧은 시간에 많이 접속하면 계정이 잠길 수 있어요. 아침에 한 번, 페이지 사이에 몇 초씩 쉬어요
약관 확인각 앱 사장님 사이트 이용 조건에 자동 조회 제한이 있을 수 있어요. 경고를 받으면 봇을 멈추고 포스 연동이나 매출 통합 앱으로 바꿔요
손님 개인정보는 가져오지 않기주문 목록에 보이는 손님 이름·전화번호·주소·요청사항은 장부에 필요 없어요. 봇이 아예 읽지 않게 해요
열쇠 파일 3종은 금고처럼로그인 저장 파일, 구글 인증 파일(credentials.json), 토큰(token.json, 로그인한 상태를 담은 출입증)은 맥 밖으로 보내지 마세요. AI에도 올리지 마세요. 맥의 FileVault(디스크 암호화)를 켜 두세요

1단계 · 장부에 시트 4개 만들기

이 코스는 AI 비서가 '매장 장부' 한 파일만 읽어요. 그래서 파일을 따로 만들지 않고 '매장 장부' 안에 시트 4개를 붙여요.

  1. 봇이 적을 자리를 먼저 만들어요. 주문원장은 주문 한 건이 한 줄인 원본이에요. 봇만 적고, 사람은 고치지 않아요. 수집로그는 봇이 언제 무엇을 했는지 남기는 일지예요.
    자세히 따라 하기접기
    1. '매장 장부' → 아래 이름표 왼쪽 + → 이름 주문원장 → A1에 아래 '주문원장 제목 줄' 붙여 넣기
    2. 같은 방법으로 수집로그 시트 → A1에 '수집로그 제목 줄' 붙여 넣기
    3. 두 시트 모두 보기 → 고정 → 1행
    4. 장부 주소창의 /d/와 /edit 사이 긴 글자(시트 ID)를 복사해 메모해 두기. 봇 부탁문에 넣어요주문원장의 고유키(L열)는 '배민-12345'처럼 플랫폼과 주문번호를 합친 값이에요. 같은 주문번호가 두 플랫폼에 있어도 섞이지 않아요.
    주문원장 제목 줄
    주문일시 | 주문번호 | 플랫폼 | 주문금액 | 할인금액 | 고객 결제액 | 배달비 | 수수료 | 정산액 | 주문상태 | 최종 확인일 | 고유키
    수집로그 제목 줄
    실행 시각 | 플랫폼 | 조회 기간 | 읽은 건수 | 새로 추가 | 갱신 | 결과 | 오류 내용
  2. 날짜별 매출·주문 수·취소 수·정산액, 배민과 요기요 비교는 주문원장을 보고 수식이 알아서 계산해요. 첫 수집이 끝난 뒤 4단계에서 만들어요.

금액 세 가지는 달라요. 주문금액(메뉴 합계), 고객 결제액(할인 뒤 손님이 낸 돈), 정산액(수수료·배달비를 빼고 사장님이 받는 돈)은 따로 적어요. 주문내역 화면에 정산액이 없으면 빈칸으로 둬요. 그 값은 앞 강의의 '배달매출'(정산 파일)으로 맞춰 봐요.

2단계 · 맥에 작업실과 구글 시트 연결

  1. 터미널은 글자로 맥에 일을 시키는 창이에요. 봇이 쓸 폴더와 도구를 여기서 한 번에 깔아요. 아래 '작업실 만들기 명령'을 그대로 붙여 넣으면 돼요. 아직 봇은 없고, 돌릴 준비만 하는 단계예요.
    자세히 따라 하기접기
    1. ⌘ + 스페이스 → 터미널 → 엔터
    2. python3 --version을 치고 엔터를 눌러요. 버전 숫자가 나오면 통과예요. '명령어 개발자 도구' 설치 창이 뜨면 설치한 뒤 다시 해요
    3. '작업실 만들기 명령' 붙여 넣고 엔터. 몇 분 걸려요실패하면 터미널 화면을 캡처해 '08 자동화·연결' 채팅에 보내고 "어디서 막혔어?"라고 물어보세요.
  2. 봇이 사장님 구글 계정으로 장부에 쓸 수 있게 허락받는 단계예요. 메뉴가 많아 보여도 한 번만 하면 돼요. 이 허락 방식을 OAuth라고 불러요.
    자세히 따라 하기접기
    1. console.cloud.google.com 접속 → 장부와 같은 구글 계정 → 위쪽 프로젝트 선택 → 새 프로젝트 → 이름 baedal-bot → 만들기
    2. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → Google Sheets API 검색 → 사용
    3. API 및 서비스 → OAuth 동의 화면(또는 Google 인증 플랫폼) → 시작하기 → 앱 이름 baedal-bot, 지원 이메일 내 메일 → 대상 외부 → 연락처 내 메일 → 만들기
    4. 대상(Audience) → 테스트 사용자 → 사용자 추가 → 내 Gmail 주소
    5. 클라이언트 → 클라이언트 만들기 → 애플리케이션 유형 데스크톱 앱 → 이름 아무거나 → 만들기 → JSON 다운로드
    6. 받은 파일 이름을 credentials.json으로 바꿔 ~/baedal-bot 폴더에 넣기 (Finder에서 이동 → 폴더로 이동 → ~/baedal-bot)'테스트' 상태로 두면 일주일마다 구글 로그인이 풀려요. 다 되면 대상 → 앱 게시로 '프로덕션'으로 바꾸세요. 나만 쓰는 앱이라 첫 로그인 때 '확인되지 않은 앱' 경고가 뜨면 고급 → baedal-bot(으)로 이동을 누르면 돼요.

아래 명령은 그대로 복사해서 터미널에 붙여 넣고 엔터를 누르세요. 고칠 곳은 없어요.

작업실 만들기 명령 · 터미널
mkdir -p ~/baedal-bot/login ~/baedal-bot/rec ~/baedal-bot/errors
cd ~/baedal-bot
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install playwright pandas google-api-python-client google-auth-httplib2 google-auth-oauthlib
playwright install chromium

3단계 · 로그인 한 번, 주문내역 화면 녹화 한 번

  1. 봇이 비밀번호 없이 들어가게 하려고 해요. 봇 전용 창이 열리면 평소처럼 로그인하고 닫아요. 그러면 로그인 상태가 파일로 남아요.
    자세히 따라 하기접기
    1. 아래 '로그인 저장 명령'의 배민 두 줄 붙여 넣기 → 새 창에서 로그인, 휴대폰 인증이 있으면 진행 → 사장님 첫 화면이 보이면 창 닫기
    2. 요기요 두 줄도 똑같이 (쿠팡이츠를 넣고 싶으면 그 줄도)
    3. 확인: ls ~/baedal-bot/login → baemin.json, yogiyo.json이 보이면 끝사이트 주소가 다르면 평소 쓰는 사장님 사이트 주소로 바꿔 넣으세요. '로그인 상태 유지'가 있으면 체크하면 덜 풀려요.
  2. 봇이 따라 할 길을 보여 주는 단계예요. 주문내역 메뉴, 기간 고르기, 다음 페이지 넘기기를 한 번씩 눌러 줘요.
    자세히 따라 하기접기
    1. 아래 '화면 녹화 명령'의 배민 두 줄 붙여 넣기 → 로그인된 브라우저와 'Playwright Inspector' 창이 같이 열려요
    2. 브라우저에서: 주문내역 메뉴 → 기간을 어제로 → 조회 → (있으면) 다음 페이지나 더보기 → 주문 하나를 눌러 상세 보기
    3. Inspector의 Pick locator(과녁 모양)를 누르고 주문번호, 주문금액, 상태 글자를 하나씩 눌러 보기. 그 칸을 찾는 이름이 코드에 남아요
    4. Inspector 코드를 전부 복사 → ~/baedal-bot/rec/baemin.txt로 저장. 요기요도 똑같이 yogiyo.txt
    5. 주문 목록 화면을 캡처하고, 맥 미리보기의 마크업 → 사각형으로 손님 이름·전화·주소를 가린 뒤 저장 (AI에게 보낼 화면 예시)녹화 파일에 fill이 들어간 줄에 아이디·비밀번호나 손님 정보가 있으면 그 줄을 지우세요. 녹화 중 로그인 화면이 나오면 로그인 저장부터 다시 하세요.

아래 명령은 두 줄씩 복사해 터미널에 붙여 넣으세요. 사이트 주소가 평소 쓰는 곳과 다르면 주소만 바꿔요.

로그인 저장 명령 · 터미널
cd ~/baedal-bot && source venv/bin/activate
playwright open --save-storage=login/baemin.json https://self.baemin.com

cd ~/baedal-bot && source venv/bin/activate
playwright open --save-storage=login/yogiyo.json https://ceo.yogiyo.co.kr
화면 녹화 명령 · 터미널
cd ~/baedal-bot && source venv/bin/activate
playwright codegen --target=python --load-storage=login/baemin.json https://self.baemin.com

cd ~/baedal-bot && source venv/bin/activate
playwright codegen --target=python --load-storage=login/yogiyo.json https://ceo.yogiyo.co.kr

4단계 · 봇 받아서 시험하고, 30일 처음 수집

  1. 코드는 직접 쓰지 않고 AI에게 받아요. '08 자동화·연결' 채팅에 녹화 파일(rec 폴더)과 가린 캡처를 첨부해요. 그리고 아래 '주문내역 수집 봇 부탁문'을 보내요. login 폴더, credentials.json, token.json은 절대 첨부하지 않아요.
  2. 틀린 값이 장부에 들어가지 않게 시험부터 해요. 봇이 칸을 제대로 읽는지 터미널 화면으로만 확인해요.
    자세히 따라 하기접기
    1. AI가 준 bot.py를 ~/baedal-bot에 저장
    2. 터미널: cd ~/baedal-bot && source venv/bin/activate && python bot.py --dry-run --show
    3. 처음엔 구글 로그인 창이 떠요. 장부 계정을 고르고 허용을 눌러요. 그러면 token.json이 생겨요막히면: '확인되지 않은 앱' 경고가 뜨면 고급 → baedal-bot(으)로 이동을 눌러요.
    4. 터미널에 나온 주문 5건을 사이트 화면과 한 칸씩 비교: 주문번호, 금액, 상태가 맞는지틀리면 터미널 출력(손님 정보 없음)을 '08 자동화·연결' 채팅에 붙여 넣고 "주문금액 자리에 배달비가 들어가"처럼 무엇이 틀렸는지 말해 주세요.
  3. 지난 한 달 치를 한 번에 채워 두는 단계예요. 한 번만 해요. 끝나면 사이트에 나온 주문 수와 장부 주문 수를 맞춰 봐요.
    자세히 따라 하기접기
    1. 터미널: python bot.py --backfill 30
    2. '수집로그' 시트에 플랫폼마다 한 줄씩, 결과 '성공'인지 확인
    3. 사이트에서 지난 30일 주문 건수를 보고, '주문원장'에서 그 플랫폼 줄 수와 같은지 확인 (필터: 플랫폼)
    4. 같은 명령을 한 번 더 돌려 '새로 추가'가 0인지 확인. 0이면 중복 방지가 잘 되는 거예요
  4. 주문원장만으로는 하루 매출이 한눈에 안 보여요. 그래서 합계 시트를 따로 둬요. '01 장부·정산' 채팅에 아래 '주문 집계 수식 부탁문'을 보내요. 받은 수식을 각 시트 A1 칸에 붙여 넣어요.

아래 부탁문은 그대로 복사해서 제목 '·' 뒤에 적힌 채팅에 붙여 넣으세요. ○○ 자리만 우리 가게 값(시트 ID, 아이폰 번호, 주문상태 글자)으로 바꿔요.

맥에서 매일 아침 돌릴 '배달앱 주문내역 수집 봇'을 파이썬 Playwright로 만들어줘. 배민·요기요 주문내역 화면에는 내려받기 버튼이 없어서 화면의 주문 목록을 읽어야 해. 나는 코딩 초보라 저장할 파일 이름과 터미널 명령까지 순서대로 알려줘.
첨부: 사이트별 주문내역 화면 녹화 코드, 손님 정보를 가린 주문 목록 캡처
- 작업 폴더 ~/baedal-bot, 가상환경 venv. 로그인은 login/baemin.json, login/yogiyo.json 저장 상태를 불러와서 써. 아이디·비밀번호는 코드에 넣지 마
- 주문내역에서 기간을 정해 조회하고, 다음 페이지나 더보기가 있으면 끝까지. 주문마다 주문일시, 주문번호, 주문금액, 할인금액, 고객 결제액, 배달비, 수수료, 정산액, 주문상태를 읽고, 화면에 없는 값은 빈칸
- 손님 이름·전화번호·주소·요청사항은 읽지도 저장하지도 마
- 고유키 = 플랫폼-주문번호. 구글 시트 '매장 장부'(시트 ID: ○○)의 '주문원장' 시트에 없는 키는 추가, 있는 키는 상태나 금액이 바뀌었을 때 갱신하고 최종 확인일을 오늘로. Google Sheets API와 credentials.json, token.json 사용
- 옵션: --backfill 30 은 최근 30일 처음 수집, 옵션이 없으면 최근 3일을 다시 확인(늦게 들어오는 취소·환불 반영), --dry-run 은 시트에 쓰지 않고 처음 5건만 화면에 출력, --show 는 브라우저 보이게
- 화면에 총 건수가 나오면 읽은 건수와 비교해서 다르면 실패로 처리
- 로그인 화면, 보안 문자, 추가 인증이 나오면 그 플랫폼은 멈추고 '다시 로그인 필요'. 비밀번호 자동 입력이나 보안 문자 우회는 하지 마
- 페이지 사이에 몇 초씩 쉬기. 실패하면 오류 문장과 화면 캡처를 ~/baedal-bot/errors 에 저장
- 실행마다 '수집로그' 시트에 플랫폼별 한 줄: 실행 시각, 플랫폼, 조회 기간, 읽은 건수, 새로 추가, 갱신, 결과, 오류 내용. 실패를 성공으로 적지 마
- 끝나면 맥 알림, 실패가 있으면 내 아이폰으로 iMessage 한 통 (번호 ○○)
- 매일 오전 6시에 실행하는 launchd 설정 파일과 등록·해제 명령, 5시 55분에 맥을 깨우는 pmset 명령도
주문 집계 수식 부탁문 · 장부 과장
'매장 장부'의 '주문원장' 시트(열: 주문일시, 주문번호, 플랫폼, 주문금액, 할인금액, 고객 결제액, 배달비, 수수료, 정산액, 주문상태, 최종 확인일, 고유키)를 보고 수식만으로 계산되는 시트 두 개를 만들어줘.
1) '주문일별': 날짜별 주문 수, 취소 수, 주문금액 합계, 고객 결제액 합계, 정산액 합계. 취소된 주문은 매출 합계에서 빼기. 최근 날짜가 위로
2) '플랫폼비교': 이번 달과 지난달, 플랫폼별 주문 수, 매출, 객단가, 취소율
주문상태에 실제로 쓰이는 글자는 ○○(예: 배달완료, 주문취소)야. A1 칸에 붙여 넣을 QUERY 수식과 붙이는 순서를 알려줘.

5단계 · 매일 아침 자동으로

  1. 매일 손으로 돌리지 않게 맥에 알람을 걸어요. AI가 준 launchd(맥에서 정해진 시각에 프로그램을 돌리는 예약 기능) 설정 파일을 넣고 등록해요. 매일 최근 3일을 다시 확인해서 늦게 들어온 취소·환불도 반영돼요.
    자세히 따라 하기접기
    1. 설정 파일(…plist)을 Finder 이동 → 폴더로 이동 → ~/Library/LaunchAgents에 저장
    2. AI가 준 등록 명령을 터미널에 붙여 넣기
    3. 맥 깨우기: AI가 준 sudo pmset repeat … 명령 → 맥 로그인 비밀번호 입력 (글자는 안 보여요)
    4. 다음 날 아침 '수집로그'에 오전 6시 줄이 생겼는지 확인맥이 잠자기거나 꺼져 있으면 그날은 건너뛰어요. 노트북은 충전기를 꽂고 덮개를 연 채 두거나, 늘 켜 두는 맥을 쓰세요. 실행 시각은 주문 반영이 끝나는 시간에 맞춰 바꿔도 돼요.
  2. 사이트 로그인은 가끔 풀려요. 그럴 땐 3단계의 그 사이트 '로그인 저장 명령'만 다시 해요. 구글 로그인이 풀렸다면 token.json을 지워요. 그다음 봇을 한 번 손으로 돌려 다시 허용해요.
  3. 특강의 자동 점검을 만들었다면 점검 목록에 '주문원장 1일', '수집로그 1일'을 더해요. 봇이 하루라도 멈추면 바로 알 수 있어요. 사이트 화면이 바뀌어 봇을 고쳐야 하면 '개선요청'에 올리고 승인 후 고쳐요 (강의).
선택 · 정산 엑셀이 받아지는 메뉴가 있다면 (배민 암호 풀기)접기
  1. 정산 내역처럼 엑셀 내려받기가 되는 메뉴는 봇이 같이 받아 앞 강의의 '배달앱 받은 파일' 폴더(데스크톱용 Google Drive로 맥에 연결)에 넣을 수 있어요
  2. 배민 엑셀 비밀번호는 코드가 아니라 맥 키체인에 넣어요. 터미널: security add-generic-password -a "$USER" -s baemin-excel -w → 비밀번호 두 번 입력 (화면에 안 보여요)
  3. 터미널에서 pip install msoffcrypto-tool을 하고, 수집 봇 부탁문 끝에 "정산 내역 메뉴에서 어제 엑셀도 받아서, 잠겨 있으면 키체인 'baemin-excel' 비밀번호로 msoffcrypto를 써서 풀고 ○○ 폴더에 배민_날짜.xlsx로 저장해줘"를 덧붙이기
윈도우 PC라면접기
  1. 파이썬과 Playwright는 윈도우에서도 같아요. 부탁문의 '맥'을 '윈도우'로, launchd를 '작업 스케줄러'로, iMessage를 '메일 알림'으로 바꿔 보내세요
  2. 코딩 없이 녹화만으로 하고 싶으면 윈도우의 무료 Power Automate Desktop 레코더로 주문내역 화면을 따라 하게 할 수도 있어요. 다만 목록을 장부에 정확히 쌓는 일은 파이썬 쪽이 더 안정적이에요

봇이 멈춰도 장부는 안전하게. 사이트 화면이 바뀌면 봇은 언제든 멈출 수 있어요. 그래서 실패는 반드시 '수집로그'에 실패로 남겨요. 주문원장은 봇만 고쳐요. 멈춘 날은 다음 날 봇이 최근 3일을 다시 확인하면서 채워요. 더 길게 멈췄다면 python bot.py --backfill 7처럼 기간을 넣어 다시 모아요.

토큰 아끼기강의
  • 시트·엑셀은 통째로 말고 필요한 탭·열만 CSV로 내려받아 올려요. 엑셀 파일은 markitdown 파일.xlsx -o 파일.md로 표 글자로 바꿀 수 있어요.
  • 캡처는 "어디를 눌러야 하나"처럼 화면 모양이 필요할 때만. 화면의 글자는 복사해서 붙여 넣는 게 훨씬 가벼워요. 사진은 여러 장 대신 꼭 필요한 한두 장만.
  • 웹페이지는 주소만 주고 "전체 읽어 줘" 대신, 필요한 부분 글자를 복사해 주거나 markitdown 페이지.html -o 페이지.md로 바꿔 줘요.
