배달앱 매출이 메일·폴더로 들어오면 장부가 알아서

배민·쿠팡이츠·요기요의 주문·수수료·정산 금액을 장부의 '배달매출' 시트로 자동으로 모아요. 자동화는 세 단계로 올려요. ① 폴더에 넣으면 자동 반영, ② 메일로 오면 자동 저장, ③ 빠지면 알림. 다 하면 사장님 손은 '메일 한 통 보내기'로 끝나요. 정기 메일이면 그마저도 없어요.

이게 뭐예요배달앱 정산 파일을 '받은 편지 바구니'에 넣기만 하면, 장부가 알아서 꺼내 정리해 주는 거예요.
끝나면배민·쿠팡이츠·요기요 매출과 수수료가 한 시트에 모이고, 빠진 앱이 있으면 메일로 알림이 와요.

처리가 끝난 파일은 '처리 완료' 폴더로 옮겨져서 두 번 들어가지 않아요.

먼저 알아 둘 것

배달앱 3사는 사장님이 직접 쓸 수 있는 공개 API(프로그램끼리 자료를 주고받는 창구)를 주지 않아요. 주문 연동 API는 포스 회사 같은 제휴사만 써요. 그래서 자동화하는 길은 아래 표와 같아요. 이 강의는 비용이 들지 않는 ③을 실습해요. ①·②를 쓰면 파일 받는 일까지 줄어요.

길어떻게사장님 손비용
① 포스 배달 연동토스 포스처럼 포스에 배달앱을 연결하면 배달 매출이 포스 매출 리포트에 합쳐지고, 엑셀도 앱별로 나뉘어 나와요포스 엑셀 하나만 받기포스마다 다름
② 매출 통합 앱캐시노트·오늘얼마 같은 앱에 배달앱 사장님 계정을 연결하면 3사 매출이 자동으로 모여요. 앱에서 자료를 내려받아요통합 자료 하나만 받기앱·기능마다 다름
③ 폴더 자동 반영 (이 강의 1단계)받은 파일을 드라이브 폴더에 넣으면 앱스 스크립트(시트에 붙이는 작은 프로그램)가 읽어서 장부에 정리주 1회 파일 받아 폴더에 넣기 (5분)무료
⑤ 주문내역 수집 봇 (다음 강의)주문내역은 내려받기 버튼이 없어요. 사장님 맥에서 매일 아침 봇이 배민·요기요 주문 목록을 화면에서 읽어 장부 '주문원장' 시트에 바로 쌓아요몇 주에 한 번 다시 로그인무료 (맥이 켜져 있어야 해요)
④ 메일 자동 수집 (이 강의 2단계)정기적으로 오는 매출 자료 메일, 또는 휴대폰에서 '나에게 보낸' 메일의 첨부파일을 Gmail이 분류하고 스크립트가 폴더로 옮겨요메일 한 통 보내기, 정기 메일이면 없음무료

배달앱 아이디·비밀번호를 구글 스크립트나 AI 채팅에 넣지 마세요. 로그인 정보가 남의 서버에 남아요. 사이트 원본이 꼭 필요하면 ⑤처럼 사장님 맥에서만 도는 봇을 써요. 로그인은 사람이 직접 해요. 자동 접속을 막는 약관이 있을 수 있어요. 그래서 ①·②가 되면 그쪽이 먼저예요. ② 같은 통합 앱에 계정을 연결할 때도 믿을 수 있는 회사만 써요. 비밀번호를 바꾸면 다시 연동해야 해요.

1단계 · 폴더에 넣으면 장부에 자동 반영

  1. 배달앱 주문 한 건이 한 줄이 돼요.
    자세히 따라 하기접기
    1. 드라이브에서 '매장 장부' 파일 열기 (새 파일 아님)
    2. 맨 아래 시트 이름표 왼쪽 + → 새 이름표를 두 번 눌러 배달매출
    3. A1 칸을 누르고 아래 '배달매출 제목 줄' 복사 → 붙여 넣기
    배달매출 제목 줄
    날짜 | 배달앱 | 주문번호 | 주문금액 | 할인 | 중개수수료 | 배달비 | 광고비 | 결제수수료 | 정산금액 | 원본파일
  2. '배달앱 받은 파일'과 '처리 완료'
    자세히 따라 하기접기
    1. 드라이브 '우리가게 장부' 폴더 안에서 + 새로 만들기 → 새 폴더 → 배달앱 받은 파일
    2. 같은 방법으로 처리 완료 폴더 만들기
    3. PC에서 '배달앱 받은 파일' 폴더를 열고 인터넷 주소창을 보면 …/folders/1AbC…xyz처럼 나와요. folders/ 뒤의 긴 글자를 복사해 메모. '처리 완료' 폴더도 똑같이주소 끝에 ?usp=… 같은 글자가 붙어 있으면 ? 앞까지만 복사하세요.
  3. 한 번 받아 봐야 AI가 파일 모양을 알고 맞는 스크립트를 짜 줘요. 메뉴 이름은 앱 업데이트로 바뀔 수 있어요.
    자세히 따라 하기접기
    1. 배민: PC에서 배민 사장님광장(ceo.baemin.com) 로그인 → 우리가게관리 → 정산·주문에서 정산 명세나 주문 내역을 지난주 기간으로 조회 → 엑셀 다운로드
    2. 쿠팡이츠: 쿠팡이츠 사장님 사이트(또는 앱)의 정산 메뉴 → 지난주 기간 → 다운로드
    3. 요기요: 요기요 사장님 사이트의 정산 내역 메뉴 → 지난주 기간 → 다운로드
    4. 받은 파일 3개를 '배달앱 받은 파일' 폴더로 끌어다 놓기다운로드 버튼을 못 찾겠으면 그 화면을 캡처해 '08 자동화·연결' 채팅에 보내고 "정산 내역을 엑셀로 받는 버튼이 어디야?"라고 물어보세요. ①포스 연동이나 ②통합 앱을 쓰면 그 파일 하나만 넣어도 돼요.
  4. 파일 모양에 맞는 코드를 받으려고 해요. '08 자동화·연결' 채팅에 받은 파일 3개를 첨부하고 아래 부탁문을 보내요. 파일마다 어느 열이 날짜·금액·수수료인지 AI가 맞춰 줘요.
  5. 자세히 따라 하기접기
    1. '매장 장부' 메뉴 확장 프로그램 → Apps Script → 왼쪽 + → 스크립트 → 이름 배달매출 → AI가 준 코드 붙여 넣기
    2. 코드 맨 위의 폴더 ID 두 자리에 메모해 둔 ID 붙여 넣기
    3. 엑셀(.xlsx)을 읽으려면 왼쪽 서비스 → + → Drive API → 추가 (AI가 필요하다고 하면)
    4. 저장 → 실행 → 권한 창에서 권한 검토 → 내 계정 → 고급 → 이동 → 허용막히면: '확인하지 않은 앱' 경고는 내가 만든 스크립트라 뜨는 정상 화면이에요. '고급'을 눌러야 '이동'이 보여요.
    5. '배달매출' 시트에 줄이 생기고, 파일이 '처리 완료' 폴더로 옮겨졌는지 확인빨간 오류가 나면 오류 문장과 함께 "어느 파일에서 났는지"를 그대로 채팅에 보내세요.
  6. 사장님이 실행 버튼을 누르지 않아도 되게 해요. Apps Script 왼쪽 시계 아이콘 트리거 → + 트리거 추가 → 실행할 함수: AI가 알려 준 이름 → 시간 기반 → 시간 단위 타이머 → 1시간마다 → 저장
  7. 월요일 아침 3사 사이트에서 지난주 파일을 받아 폴더에 넣어요. 휴대폰이라면 Google Drive 앱에서 폴더 열기 → + → 업로드. 1시간 안에 장부에 들어가고, 월요일 브리핑이 그 숫자로 실수익률을 계산해요.
  8. '01 장부·정산' 채팅에 "배달매출 시트의 지난주 앱별 정산금액 합계를 알려줘" → 각 사장님 사이트의 정산 합계와 같은지 확인해요.

이 글을 그대로 복사해서 '08 자동화·연결' 채팅에 붙여 넣으세요. ○○ 자리만 메모해 둔 폴더 ID로 바꿔요.

배달매출 자동 반영 부탁문 · 자동화 엔지니어
첨부한 파일은 배달의민족, 쿠팡이츠, 요기요 사장님 사이트에서 받은 정산(주문) 파일이야. 나는 코딩 초보야.
구글 시트 '매장 장부'에 붙일 Apps Script를 만들어줘.
- 드라이브 폴더 '배달앱 받은 파일'(ID: ○○)에 새 파일이 있으면 읽어서 '배달매출' 시트에 한 줄씩 추가
- 시트 열: 날짜, 배달앱, 주문번호, 주문금액, 할인, 중개수수료, 배달비, 광고비, 결제수수료, 정산금액, 원본파일
- 파일 이름이나 첫 줄 모양으로 어느 배달앱 파일인지 알아내고, 각 파일의 열 이름을 위 열에 맞춰줘. 없는 항목은 빈칸
- 엑셀(.xlsx)은 Drive 고급 서비스로 구글 시트로 바꿔서 읽고, CSV도 읽을 수 있게
- 같은 배달앱·주문번호가 이미 있으면 건너뛰기 (중복 방지)
- 다 읽은 파일은 '처리 완료' 폴더(ID: ○○)로 옮기기
- 끝나면 몇 건을 넣었는지 내 메일로 알려 주기
코드 전체와 함께, 붙여 넣는 곳·Drive API 추가 방법·1시간 트리거 설정을 단계별로 알려줘.

2단계 · 메일로 오면 자동으로 폴더에 저장

배달앱 3사가 정산 파일을 메일로 정기 발송한다는 공식 안내는 찾지 못했어요. 그래서 두 가지 메일을 써요. 첫째는 정기적으로 오는 매출 자료 메일이에요. 예를 들어 토스의 부가세 매출 자료 받기는 배달앱 3사와 카드 매출을 이메일로 보내 줘요. 포스·매출 통합 앱의 리포트 메일, 세금계산서 메일도 여기에 들어가요. 둘째는 사장님이 휴대폰에서 '나에게' 보내는 메일이에요. 휴대폰으로 파일을 받은 그 자리에서 공유 → Gmail로 한 번 보내면 돼요. 드라이브 폴더를 찾아 올리는 일이 없어져요.

내아이디+delivery@gmail.com정기 메일 수신 주소 · 나에게 보내기
Gmail 필터'배달매출자료' 라벨 자동
스크립트 (1시간마다)첨부파일 → 폴더 → 1단계 반영
  1. Gmail은 아이디 뒤에 +단어를 붙여도 같은 메일함으로 받아요. 예: 내아이디+delivery@gmail.com. 새 계정을 만들 필요가 없어요.
    자세히 따라 하기접기
    1. 내 Gmail이 salad123@gmail.com이라면 전용 주소는 salad123+delivery@gmail.com
    2. 매출 자료를 메일로 보내 주는 서비스(토스 매출 자료, 포스·매출 통합 앱 리포트, 세무 기장 서비스 등)의 받는 주소를 이 주소로 바꾸기
    3. 휴대폰 연락처에 '매출자료함'이라는 이름으로 이 주소 저장 (나에게 보낼 때 쓰기 쉽게)회사·학교 계정이면 + 주소가 막혀 있을 수 있어요. 개인 gmail을 쓰세요.
  2. 그 주소로 온 메일에 '배달매출자료' 라벨이 자동으로 붙게 해요. PC에서 해요.
    자세히 따라 하기접기
    1. PC에서 Gmail 열기 → 맨 위 검색창 오른쪽의 검색 옵션 표시 아이콘
    2. 받는사람 칸에 salad123+delivery@gmail.com, 첨부파일 있음 체크
    3. 아래 필터 만들기 → 라벨 적용 → 새 라벨 → 이름 배달매출자료 → 만들기
    4. '받은편지함 건너뛰기'는 체크하지 않아도 돼요 → 필터 만들기정기 메일이 + 주소로 오지 않고 원래 주소로 온다면, '보낸사람' 칸에 그 서비스의 메일 주소를 넣어 같은 라벨을 붙이는 필터를 하나 더 만드세요.
  3. '08 자동화·연결' 채팅에 아래 '메일 자동 수집' 부탁문을 보내요. 1단계 스크립트와 같은 프로젝트에 붙여서, 저장이 끝나면 바로 장부 반영까지 이어지게 해요.
  4. 자세히 따라 하기접기
    1. '매장 장부' → 확장 프로그램 → Apps Script → + → 스크립트 → 이름 메일수집 → 코드 붙여 넣기 → 저장
    2. 실행 → 권한 창에서 Gmail 읽기 권한까지 허용. 내가 만든 스크립트라 '확인하지 않은 앱' 경고가 뜨는 건 정상이에요
    3. 트리거: 실행할 함수는 AI가 알려 준 이름, 시간 기반 → 시간 단위 타이머 → 1시간마다
    4. 시험: 휴대폰에서 배민 파일 하나를 '매출자료함' 주소로 보내고, 1시간 안에 '배달매출' 시트에 들어오는지 확인메일에 '처리됨' 라벨만 붙고 시트에 안 들어오면, 첨부파일이 비밀번호로 잠겨 있지 않은지 확인하세요. 스크립트는 비밀번호 걸린 파일을 열지 못해요.
  5. 배달앱 사장님 앱이나 사이트에서 파일을 받으면 공유 → Gmail → 받는사람: 매출자료함 → 보내기. 이게 사장님이 하는 일의 전부예요.
  6. 첨부파일 없이 본문에 '정산 예정 금액 ○○원' 같은 숫자만 오는 메일이 있다면, 그 메일 하나를 복사해 AI에게 주고 "이 모양 메일에서 날짜·배달앱·금액을 뽑아 '메일정산' 시트에 쌓는 코드를 추가해줘"라고 부탁해요.

이 글을 그대로 복사해서 '08 자동화·연결' 채팅에 붙여 넣으세요. ○○ 자리만 폴더 ID와 1단계 함수 이름으로 바꿔요.

메일 자동 수집 부탁문 · 자동화 엔지니어
Gmail 라벨 '배달매출자료'가 붙은 메일의 첨부파일(.xlsx, .xls, .csv)을 드라이브 폴더 '배달앱 받은 파일'(ID: ○○)에 저장하는 Apps Script를 만들어줘. 나는 코딩 초보야.
- 검색 조건은 반드시 label:배달매출자료 has:attachment 이고, '처리됨' 라벨이 없는 메일만 (다른 메일은 절대 읽지 않기)
- 저장할 때 파일 이름 앞에 받은 날짜와 보낸사람을 붙여 구분
- 저장이 끝난 메일에는 '처리됨' 라벨 붙이기
- 저장 후 같은 프로젝트에 있는 배달매출 반영 함수(이름: ○○)를 이어서 실행
- 비밀번호로 잠긴 파일은 건너뛰고, 건너뛴 파일 이름을 내 메일로 알려 주기
코드 전체와, 붙여 넣는 곳, 권한 허용, 1시간 트리거 설정 방법을 단계별로 알려줘.

3단계 · 빠진 날 알림과 AI 점검

자동화는 조용히 멈추는 게 가장 무서워요. 들어오지 않았을 때 사장님이 바로 알 수 있게 알림을 붙여요.

  1. 지난주 배민·쿠팡이츠·요기요 중 '배달매출' 시트에 한 건도 없는 앱이 있으면 "쿠팡이츠 지난주 파일이 아직 없어요" 메일을 보내요. 아래 '점검 알림' 부탁문으로 코드를 받아, 트리거를 주 단위 타이머 → 월요일 → 낮 12시~오후 1시로 설정해요.
  2. 파일이 들어오면 "배민 132건, 정산 412만 원 반영" 같은 한 줄 메일을 받아요. 숫자가 이상하면 그날 바로 알 수 있어요.
  3. 월요일 브리핑에 한 줄을 덧붙여 AI가 메일함과 장부를 함께 확인하게 해요.
    자세히 따라 하기 · Claude접기
    1. 설정 → 커넥터에서 Gmail 연결 (Google Drive와 같은 방법)
    2. '02 월요일 브리핑' 예약 작업 지시문 맨 아래에 "Gmail에서 지난주 '배달매출자료' 라벨 메일이 앱마다 왔는지 확인하고, 장부 '배달매출' 시트 합계와 다르면 알려줘" 추가
    자세히 따라 하기 · ChatGPT접기
    1. 설정 → 앱에서 Gmail 연결
    2. Claude 유료 플랜은 위 한 줄을 붙인 월요일 브리핑 예약 작업이 그대로 점검해 줘요.ChatGPT 유료 플랜이면 메일이 올 때 바로 실행되는 예약 작업도 만들 수 있어요. 대화창에 "Gmail에 '배달매출자료' 라벨 메일이 오면 첨부 내용을 요약해서 알려줘"
    3. 무료 플랜이어도 메일 수집과 장부 반영은 위의 구글 스크립트가 다 해요. AI 점검은 월요일 알림이 올 때 "브리핑 해줘"에 같이 들어가요무료 예약 작업(하루 1번 이하)으로 월요일 아침에 받아요
    4. 월요일 브리핑 지시문에도 "지난주 '배달매출자료' 메일이 앱마다 왔는지 확인해줘" 한 줄 추가

이 글을 그대로 복사해서 '08 자동화·연결' 채팅에 붙여 넣으세요. 바꿀 자리는 없어요.

점검 알림 부탁문 · 자동화 엔지니어
매장 장부 '배달매출' 시트(날짜, 배달앱, 주문번호, 정산금액 …)를 확인하는 Apps Script를 만들어줘.
1) 월요일 낮에 실행: 지난주(월~일) 배달의민족·쿠팡이츠·요기요 중 한 건도 없는 앱이 있으면 "○○ 지난주 파일이 아직 없어요"라고 내 메일로 보내기
2) 배달매출 반영 함수가 끝날 때마다: 이번에 넣은 앱별 건수와 정산금액 합계를 한 줄로 메일 보내기. 지난주 같은 요일보다 50% 넘게 차이 나면 '확인 필요' 표시
트리거 설정 방법(주 단위 월요일 낮 12시)도 초보 기준으로 알려줘.

메일 권한은 좁게. 메일 수집 스크립트는 Gmail을 읽을 수 있는 권한을 받아요. 그래서 검색 조건이 '배달매출자료' 라벨로만 되어 있는지 꼭 확인해요. 이 스크립트가 든 장부는 다른 사람에게 편집 공유하지 마세요.
