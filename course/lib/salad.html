숫자는 엑셀로 받아서 폴더에 넣어요

소규모 매장은 포스·배달앱 데이터를 API로 직접 받기 어려워요. 엑셀로 내려받아 장부 폴더에 넣으면 AI가 읽습니다.

  1. 결제 시트(일자·시각, 채널, 금액, 결제수단, 취소)와 상품 주문 시트(상품명, 옵션, 수량, 할인, 실판매금액)가 들어 있어요.
    자세히 따라 하기접기
    1. 포스 화면 왼쪽 위 ≡ 메뉴 → 매출 리포트 → 매출현황
    2. 엑셀 내보내기 누르기 → 기간 고르기(지난주 월~일)
    3. 파일 만들기 → 파일 비밀번호 정하기 → 받기
    4. 받은 파일을 드라이브 '우리가게 장부' 폴더에 올리기AI에게 올리기 전에 비밀번호로 한 번 열어 다시 저장하면 잠금이 풀려요.
  2. 배달 3사 주문이 포스 매출에 합쳐져서 엑셀 하나로 볼 수 있어요.
    자세히 따라 하기접기
    1. 설정 → 배달 매출 설정메뉴가 안 보이면 포스를 껐다 켜세요.
    2. 쓰는 배달앱 옆 연결하기 → 배달앱 계정으로 로그인
    3. 연결한 날 이후 주문부터 합쳐진다는 점 기억하기
  3. 매출구분(카드·현금·기타), 매출, 부가세, 합계
    자세히 따라 하기접기
    1. PC에서 배민 사장님광장(ceo.baemin.com) 로그인
    2. 우리가게관리 → 정산·주문 → 부가세 신고자료
    3. 기간 선택(한 번에 최대 3개월) → 조회 → 다운로드만나서결제(카드·현금)는 여기 안 나와요. 별도 메뉴에서 확인하세요.
  4. 각 사장님 사이트의 정산 메뉴에서 다운로드 버튼을 찾으세요.
  5. 카드매출 통합조회와 홈택스는 조회 기간 제한이 있어 매달 받아 두는 게 좋아요.

매주 손으로 받기 번거롭다면. 받은 파일을 폴더에 넣기만 하면 장부에 자동으로 들어가게 만드는 방법이 강의에 있어요.

끝나면탭 6개와 요약 탭이 있는 '매장 장부' 시트, 마감 때 휴대폰으로 매출을 넣는 입력 화면

AI 비서장부 구조를 만들었어요.
  • 매출·지출·고정비·거래처·알바근무·메뉴원가 탭 6개
  • 배민·쿠팡이츠·요기요 칸과 월 요약 수식
  • 휴대폰 입력용 구글 폼 만드는 법
  1. 이름은 '매장 장부'로 해 주세요. 뒤에 나오는 부탁문들이 이 이름을 써요.
    자세히 따라 하기접기
    1. 드라이브의 '우리가게 장부' 폴더 안으로 들어가기
    2. + 새로 만들기 → Google 스프레드시트
    3. 왼쪽 위 '제목 없는 스프레드시트' 글자를 눌러 매장 장부로 바꾸고 엔터저장 버튼은 없어요. 입력하는 순간 자동으로 저장돼요.
  2. 매출, 지출, 고정비, 거래처, 알바근무, 메뉴원가. 파일은 '매장 장부' 하나, 그 안에 시트가 6개예요.
    +≡매출지출고정비거래처알바근무메뉴원가
    화면 맨 아래 모습이에요. 앞으로 '장부에 ○○ 탭 만들기'가 나오면 이 줄에 이름표를 하나 더 붙이면 돼요.
    자세히 따라 하기접기
    1. 화면 맨 아래 '시트1' 글자를 두 번 눌러 매출로 바꾸기
    2. 그 왼쪽의 + 버튼을 눌러 새 탭 만들기 → 같은 방법으로 이름 바꾸기
    3. 지출, 고정비, 거래처, 알바근무, 메뉴원가까지 6개가 될 때까지 반복
  3. 칸마다 무엇을 적을지 정해 두려고 해요. 아래 상자의 '복사'를 누르고 각 탭의 A1 칸에 붙여 넣어요. 칸마다 나뉘어 들어가요.
    자세히 따라 하기접기
    1. 매출 탭을 열고 맨 왼쪽 위 칸(A1)을 한 번 누르기
    2. 아래 '매출 탭 제목 줄'의 복사 누르기
    3. PC는 Ctrl+V(맥은 ⌘+V), 휴대폰은 칸을 길게 눌러 '붙여넣기'
    4. 지출, 알바근무 탭도 같은 방법으로한 칸에 다 들어갔다면 그 칸을 누르고 데이터 → 텍스트를 열로 분할을 누르세요.
  4. 계산기를 따로 두드리지 않으려고 해요. 월별 합계와 순이익, 식재료 원가율을 저절로 계산하는 '요약' 탭을 만들어요.
    자세히 따라 하기접기
    1. 새 대화에 아래 '장부 수식 만들기' 부탁문을 붙여 넣고 보내기
    2. 같은 파일 맨 아래 +로 시트를 하나 더 추가하고 이름을 요약으로 바꾸기
    3. AI가 적어 준 칸(예: B2)에 수식을 그대로 복사해 붙여 넣기. 숫자가 나오는지 확인해요.#ERROR! 같은 글자가 나오면 그 글자와 수식을 그대로 AI에게 보내 "고쳐줘"라고 하세요.
  5. 마감 때 PC를 켜지 않아도 되게 하려고 해요. 휴대폰으로 숫자만 넣으면 시트에 쌓여요.
    자세히 따라 하기접기
    1. 시트 위쪽 메뉴 도구 → 새 양식
    2. 질문 추가: 날짜(날짜형), 카드, 현금, 계좌이체, 배민, 쿠팡이츠, 요기요(모두 단답형)
    3. 오른쪽 위 보내기 → 링크 아이콘 → 복사를 눌러요. 그 주소를 카카오톡 '나와의 채팅'에 보내요.
    4. 휴대폰에서 그 링크를 열고 홈 화면에 추가해요.
    5. 폼 답은 시트에 새 탭('설문지 응답')으로 쌓여요. 탭 이름을 매출입력으로 바꿔요. 그다음 AI에게 "매출입력 탭을 매출 탭으로 합쳐 주는 수식 알려줘"라고 부탁해요.폼을 시트에서 바로 못 찾으면 forms.google.com에서 만든 뒤 응답 → 스프레드시트에 연결을 누르세요.

    1. '게시계획' L1에 사진 올린 사람, M1에 사진 기한

    자세히 따라 하기접기

    2. 사진 이름 앞에 종류를 붙이기: 전경_01, 웜볼_기본, 재료_로메인

  4. 알바생은 사진 보내기 화면만, 승인함은 사장님(원하면 매니저)만 보여요. 권한은 직원 시트의 역할을 그대로 써요(강의).
    자세히 따라 하기접기
    1. 직원 단톡방에 주소와 사용법 3줄 보내기 (AI에게 "직원용 사진 보내기 안내 3줄" 부탁)
    2. 첫 주는 사장님이 직접 한 장 올려 보여 주기: 할 일 카드 → 사진 찍기 → 올리기 → '받았어요'
    3. 좋은 사진을 올린 직원은 게시물 캡션이나 단톡방에서 이름을 불러 고마움을 전해요. 계속 올리게 하는 가장 쉬운 방법이에요직원 얼굴이 나온 사진은 본인 동의를 받은 것만 승인해요. 손님 얼굴이 나온 사진은 쓰지 않아요.

매일 아침, 봇이 주문내역을 장부에 쌓아요

배민·요기요 사장님 사이트의 주문내역에는 엑셀 내려받기 버튼이 없어요. 그래서 봇이 사람처럼 주문내역 화면을 열어 목록을 읽고, Google Sheets API로 장부에 바로 적어요. 처음 한 번 최근 30일을 모으고, 그다음부터는 매일 아침 자동으로 쌓아요.

무료 플랜파이썬, Playwright, Google Sheets API, 맥 예약 실행 모두 일반 사용 범위에서 무료예요. 코드는 AI 채팅에서 받는데, 무료 사용량이 모자라면 플랫폼 하나씩 나눠서 부탁하세요.

유료 플랜코드를 길게 주고받아도 사용량이 넉넉해서, 사이트 화면이 바뀌었을 때 고치는 대화가 끊기지 않아요.

약관 확인각 앱 사장님 사이트 이용 조건에 자동 조회 제한이 있을 수 있어요. 경고를 받으면 봇을 멈추고 포스 연동이나 매출 통합 앱으로 바꿔요
손님 개인정보는 가져오지 않기주문 목록에 보이는 손님 이름·전화번호·주소·요청사항은 장부에 필요 없어요. 봇이 아예 읽지 않게 해요
열쇠 파일 3종은 금고처럼로그인 저장 파일, 구글 인증 파일(credentials.json), 토큰(token.json)은 맥 밖으로 보내지 말고 AI에도 올리지 마세요. 맥의 FileVault(디스크 암호화)를 켜 두세요

1단계 · 장부에 시트 4개 만들기

구축안에서는 '배달 주문 통합 관리' 파일을 따로 만들지만, 이 코스는 AI 비서가 '매장 장부' 한 파일만 읽어요. 그래서 '매장 장부' 안에 시트 4개를 붙여요.

  1. 주문원장은 주문 한 건이 한 줄인 원본이에요. 봇만 적고, 사람은 고치지 않아요.
    자세히 따라 하기접기
    1. '매장 장부' → 아래 이름표 왼쪽 + → 이름 주문원장 → A1에 아래 '주문원장 제목 줄' 붙여 넣기
    2. 같은 방법으로 수집로그 시트 → A1에 '수집로그 제목 줄' 붙여 넣기
    3. 두 시트 모두 보기 → 고정 → 1행
    4. 장부 주소창의 /d/와 /edit 사이 긴 글자(시트 ID)를 복사해 메모해 두기. 봇 부탁문에 넣어요주문원장의 고유키(L열)는 '배민-12345'처럼 플랫폼과 주문번호를 합친 값이에요. 같은 주문번호가 두 플랫폼에 있어도 섞이지 않아요.
    주문원장 제목 줄
    주문일시 | 주문번호 | 플랫폼 | 주문금액 | 할인금액 | 고객 결제액 | 배달비 | 수수료 | 정산액 | 주문상태 | 최종 확인일 | 고유키
    수집로그 제목 줄
    실행 시각 | 플랫폼 | 조회 기간 | 읽은 건수 | 새로 추가 | 갱신 | 결과 | 오류 내용
  2. 날짜별 매출·주문 수·취소 수·정산액, 배민과 요기요 비교는 주문원장을 보고 수식이 알아서 계산해요. 첫 수집이 끝난 뒤 4단계에서 만들어요.

금액 세 가지는 달라요. 주문금액(메뉴 합계), 고객 결제액(할인 뒤 손님이 낸 돈), 정산액(수수료·배달비를 빼고 사장님이 받는 돈)은 따로 적어요. 주문내역 화면에 정산액이 없으면 빈칸으로 두고, 앞 강의의 '배달매출'(정산 파일)으로 맞춰 봐요.

2단계 · 맥에 작업실과 구글 시트 연결

  1. 아래 '작업실 만들기 명령'을 그대로 붙여 넣어요. 수집 프로그램 자체는 아직 없고, 돌릴 준비만 하는 단계예요.
    자세히 따라 하기접기
    1. ⌘ + 스페이스 → 터미널 → 엔터
    2. python3 --version 입력 → 버전 숫자가 나오면 통과. '명령어 개발자 도구' 설치 창이 뜨면 설치 후 다시
    3. '작업실 만들기 명령' 붙여 넣고 엔터. 몇 분 걸려요실패하면 터미널 화면을 캡처해 '08 자동화·연결' 채팅에 보내고 "어디서 막혔어?"라고 물어보세요.
  2. 봇이 사장님 구글 계정으로 장부에 쓸 수 있게 허락받는 단계예요. 한 번만 해요.
    자세히 따라 하기접기
    1. console.cloud.google.com 접속 → 장부와 같은 구글 계정 → 위쪽 프로젝트 선택 → 새 프로젝트 → 이름 baedal-bot → 만들기
    2. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → Google Sheets API 검색 → 사용
    3. API 및 서비스 → OAuth 동의 화면(또는 Google 인증 플랫폼) → 시작하기 → 앱 이름 baedal-bot, 지원 이메일 내 메일 → 대상 외부 → 연락처 내 메일 → 만들기
    4. 대상(Audience) → 테스트 사용자 → 사용자 추가 → 내 Gmail 주소
    5. 클라이언트 → 클라이언트 만들기 → 애플리케이션 유형 데스크톱 앱 → 이름 아무거나 → 만들기 → JSON 다운로드
    6. 받은 파일 이름을 credentials.json으로 바꿔 ~/baedal-bot 폴더에 넣기 (Finder에서 이동 → 폴더로 이동 → ~/baedal-bot)'테스트' 상태로 두면 일주일마다 구글 로그인이 풀려요. 다 되면 대상 → 앱 게시로 '프로덕션'으로 바꾸세요. 나만 쓰는 앱이라 첫 로그인 때 '확인되지 않은 앱' 경고가 뜨면 고급 → baedal-bot(으)로 이동을 누르면 돼요.
작업실 만들기 명령 · 터미널
mkdir -p ~/baedal-bot/login ~/baedal-bot/rec ~/baedal-bot/errors
cd ~/baedal-bot
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install playwright pandas google-api-python-client google-auth-httplib2 google-auth-oauthlib
playwright install chromium

3단계 · 로그인 한 번, 주문내역 화면 녹화 한 번

  1. 봇 전용 창이 열리면 평소처럼 로그인하고 닫아요. 로그인 상태가 파일로 남아요.
    자세히 따라 하기접기
    1. 아래 '로그인 저장 명령'의 배민 두 줄 붙여 넣기 → 새 창에서 로그인, 휴대폰 인증이 있으면 진행 → 사장님 첫 화면이 보이면 창 닫기
    2. 요기요 두 줄도 똑같이 (쿠팡이츠를 넣고 싶으면 그 줄도)
    3. 확인: ls ~/baedal-bot/login → baemin.json, yogiyo.json이 보이면 끝사이트 주소가 다르면 평소 쓰는 사장님 사이트 주소로 바꿔 넣으세요. '로그인 상태 유지'가 있으면 체크하면 덜 풀려요.
  2. 봇이 따라 할 길을 보여 주는 단계예요. 주문내역 메뉴, 기간 고르기, 다음 페이지 넘기기를 한 번씩 눌러 줘요.
    자세히 따라 하기접기
    1. 아래 '화면 녹화 명령'의 배민 두 줄 붙여 넣기 → 로그인된 브라우저와 'Playwright Inspector' 창이 같이 열려요
    2. 브라우저에서: 주문내역 메뉴 → 기간을 어제로 → 조회 → (있으면) 다음 페이지나 더보기 → 주문 하나를 눌러 상세 보기
    3. Inspector의 Pick locator(과녁 모양)를 누르고 주문번호, 주문금액, 상태 글자를 하나씩 눌러 보기. 그 칸을 찾는 이름이 코드에 남아요
    4. Inspector 코드를 전부 복사 → ~/baedal-bot/rec/baemin.txt로 저장. 요기요도 똑같이 yogiyo.txt
    5. 주문 목록 화면을 캡처하고, 맥 미리보기의 마크업 → 사각형으로 손님 이름·전화·주소를 가린 뒤 저장 (AI에게 보낼 화면 예시)녹화 파일에 fill이 들어간 줄에 아이디·비밀번호나 손님 정보가 있으면 그 줄을 지우세요. 녹화 중 로그인 화면이 나오면 로그인 저장부터 다시 하세요.

cd ~/baedal-bot && source venv/bin/activate
playwright open --save-storage=login/baemin.json https://self.baemin.com

cd ~/baedal-bot && source venv/bin/activate
playwright open --save-storage=login/yogiyo.json https://ceo.yogiyo.co.kr

cd ~/baedal-bot && source venv/bin/activate

4단계 · 봇 받아서 시험하고, 30일 처음 수집

  1. '08 자동화·연결' 채팅에 녹화 파일(rec 폴더)과 가린 캡처를 첨부하고 아래 '주문내역 수집 봇 부탁문'을 보내요. login 폴더, credentials.json, token.json은 절대 첨부하지 않아요.
  2. 봇이 칸을 제대로 읽는지 터미널 화면으로만 확인해요.
    자세히 따라 하기접기
    1. AI가 준 bot.py를 ~/baedal-bot에 저장
    2. 터미널: cd ~/baedal-bot && source venv/bin/activate && python bot.py --dry-run --show
    3. 처음엔 구글 로그인 창이 떠요 → 장부 계정 선택 → 허용. token.json이 생겨요
    4. 터미널에 나온 주문 5건을 사이트 화면과 한 칸씩 비교: 주문번호, 금액, 상태가 맞는지틀리면 터미널 출력(손님 정보 없음)을 '08 자동화·연결' 채팅에 붙여 넣고 "주문금액 자리에 배달비가 들어가"처럼 무엇이 틀렸는지 말해 주세요.
  3. 한 번만 해요. 끝나면 사이트에 나온 주문 수와 장부 주문 수를 맞춰 봐요.
    자세히 따라 하기접기
    1. 터미널: python bot.py --backfill 30
    2. '수집로그' 시트에 플랫폼마다 한 줄씩, 결과 '성공'인지 확인
    3. 사이트에서 지난 30일 주문 건수를 보고, '주문원장'에서 그 플랫폼 줄 수와 같은지 확인 (필터: 플랫폼)
    4. 같은 명령을 한 번 더 돌려 '새로 추가'가 0인지 확인. 0이면 중복 방지가 잘 되는 거예요
  4. '01 장부·정산' 채팅에 아래 '주문 집계 수식 부탁문'을 보내고, 받은 수식을 각 시트 A1에 붙여 넣어요.
