내 오토캐드에서 되는지 먼저 봐요. 일반 오토캐드는 윈도우·맥 모두 AutoLISP가 돼요. AutoCAD LT는 2024 윈도우판부터 AutoLISP를 지원해요.

맥에서는 일부가 안 돼요. 맥용 오토캐드는 ActiveX(윈도우 전용 연결 기술)가 없어서, 이름이 vla-, vlax-로 시작하는 함수가 대부분 안 돌아요. Visual LISP 편집기도 윈도우 전용이에요. 그래서 부탁문에 "맥용, vla- 함수 쓰지 마"를 꼭 넣어요. AutoCAD LT 맥판은 LISP를 지원하지 않는다는 사용자 답변이 많으니 메뉴에서 먼저 확인하세요.

  1. 스크립트는 한 번에 도면 전체를 바꿔요. 원본 옆에 '도면이름_시험.dwg'를 만들고 거기서만 연습해요.막히면: 파일 탐색기(맥은 Finder)에서 도면을 고르고 복사·붙여넣기 한 뒤 이름만 바꾸면 돼요.
  2. 아래 '레이어 정리 부탁문'의 괄호를 우리 사무소 레이어 이름으로 바꿔 보내요. 도면 파일은 올리지 않아도 돼요. 레이어 이름 목록만 있으면 충분해요.
    자세히 따라 하기접기
    1. 오토캐드에서 LAYER 입력 → 레이어 관리자 화면을 캡처(강의)
    2. 캡처에 건축주 이름이나 현장 주소가 보이면 가리고 보내요
    3. 받은 코드 전체를 복사
  3. 자세히 따라 하기접기
    1. 메모장 열기 → 붙여넣기 → 파일 → 다른 이름으로 저장 → 파일 형식 '모든 파일', 이름 tempoff.lsp, 인코딩은 AI가 알려 준 대로
    2. 텍스트 편집기 열기 → 포맷 → 일반 텍스트로 만들기 → 붙여넣기 → 이름 tempoff.lsp로 저장'.txt를 붙일까요?' 창이 뜨면 '.lsp 사용'을 눌러요.
    3. 사무소 공용 폴더에 'LISP' 폴더를 만들어 모아 두기
    4. 오토캐드 명령행에 APPLOAD → 파일 고르기 → 로드 → 닫기막히면: '보안 경고' 창이 뜨면 내가 만든 파일일 때만 '한 번 로드'를 눌러요. 남이 보낸 파일이면 AI에게 "이 코드가 무슨 일을 해?"라고 먼저 물어요.
  4. 명령행에 TEMPOFF 입력 → 레이어가 바뀌었는지 확인 → 일부러 UNDO를 한 번 눌러 되돌아가는지도 봐요. 스크립트 시작에 UNDO 묶음을 넣어 달라고 했으면 한 번에 전부 되돌아가요.

레이어 정리 부탁문
나는 건축사사무소 소장이고 코딩은 몰라. (오토캐드 2027 / 윈도우 또는 맥 / LT인지 일반인지) 를 써.
현재 도면에서 이름에 'TEMP'가 들어간 레이어를 모두 끄고, 치수 레이어(이름: A-DIMS)의 색을 8번으로 바꾸는 AutoLISP를 만들어 줘.
- 명령어 이름은 TEMPOFF
- 시작할 때 UNDO 묶음(_UNDO _Begin)을 걸고 끝에 _End, 그래서 UNDO 한 번에 전부 되돌아가게
- 끝나면 명령행에 '꺼진 레이어 ○개, 색 바꾼 레이어 ○개'라고 보여 줘
- 맥이거나 LT라면 vla-·vlax- 함수와 Express Tools(acet-) 함수는 쓰지 마
불러오는 법(APPLOAD)과 실행 명령어를 순서대로 알려 주고, 고칠 때는 전체 코드를 다시 줘.

면적 합계 부탁문
같은 조건으로 AutoLISP를 하나 더 만들어 줘. 명령어 이름은 AREASUM.
- 레이어 A-AREA에 있는 닫힌 폴리선마다 면적(㎡, 도면 단위가 mm면 1,000,000으로 나눠서)을 구해
- 폴리선 안의 문자(실 이름)를 찾아 같이 적고, 없으면 '이름 없음'
- 층 구분은 폴리선이 있는 레이아웃이 아니라 문자 'F1', 'F2' 같은 층 표시 레이어 A-FLOR 기준
- 결과를 도면과 같은 폴더에 '면적표_날짜.csv'로 저장(층, 실 이름, 면적, 소수 둘째 자리)
- 열린 폴리선은 세지 말고 '열린 선 ○개 건너뜀'이라고 알려 줘
도면은 고치지 말고 읽기만 해 줘.

1) 층별면적: 층 | 용도 | 바닥면적(㎡) | 용적률 제외(㎡) | 제외 사유 | 산정용 면적(㎡). 맨 아래 연면적·산정용 연면적 합계

    자세히 따라 하기접기
    1. 검색창에 행정표준코드관리시스템 법정동코드를 넣어요. 공식 사이트(code.go.kr)에서 동 이름을 검색해요
    2. 10자리 코드에서 앞 5자리는 시군구코드 칸에, 뒤 5자리는 법정동코드 칸에 적어요

  3. 조회를 대신 해 줄 작은 프로그램을 시트에 다는 거예요. '09 자동화·연결' 채팅에 아래 부탁문을 보내면 앱스 스크립트 코드가 나와요. 붙이는 법은 강의와 같아요. 부탁문에 '대지조회' 메뉴를 만들어 달라고 적었어요. 그래서 시트 위 메뉴를 버튼처럼 눌러 쓰면 돼요.막히면: 처음 실행 때 '권한 검토' 창이 뜨면 사무소 계정 → 고급 → 이동 → 허용을 눌러요. 결과가 비어 있으면 인증키가 아직 활성화 전일 수 있어요. 한두 시간 뒤 다시 해 봐요.

용도지역과 필지 경계를 시트와 지도로

브이월드(공간정보 오픈플랫폼) API에 PNU(필지마다 붙은 고유번호)를 넣어요. 그러면 필지의 용도지역·지목·면적·공시지가가 와요. 필지 경계도 지도 파일로 받아요. 이 파일은 배치 스터디 바탕으로도 써요.

이게 뭐예요필지 번호만 넣으면 시트가 '토지 신상 카드'를 알아서 채우는 거예요. 용도지역·지목·면적·공시지가를 하나씩 찾아 옮겨 적지 않아도 돼요.
끝나면메뉴 한 번으로 채워지는 '토지정보' 탭, 그리고 원하면 필지 경계 지도 파일
필요한 것PC, '사무소 대장' 시트(대지 탭에 PNU), 브이월드 회원가입, 반나절 · 코드 붙이기가 처음이면 강의 먼저
  1. 인증키는 브이월드 자료를 꺼내 쓸 수 있는 '출입증'이에요. 먼저 이것부터 받아요.
    자세히 따라 하기접기
    1. PC 크롬에서 vworld.kr에 들어가 회원가입하고 로그인해요.
    2. 오픈API → 인증키 발급으로 가요. 서비스 분류에서 데이터 API(2D 데이터)를 골라요. 활용 URL 칸은 화면 안내에 따라 입력해요.막히면: 활용 URL에 무엇을 쓸지 모르겠으면 그 화면을 캡처해 AI에게 "구글 앱스 스크립트에서 쓸 건데 여기 뭐라고 써?"라고 물어요.
    3. 발급된 인증키를 복사해 둬요. 채팅에는 붙이지 말고, 나중에 스크립트 속성에만 넣어요.인증키에는 사용 기간이 있어요. 만료 안내 메일이 오면 같은 메뉴에서 연장하세요.
  2. 조회 결과가 들어올 자리예요. '사무소 대장' 아래쪽 +로 새 탭을 만들고 이름을 '토지정보'로 바꿔요. A1 칸에 아래 '토지정보 탭 제목 줄'을 붙여 넣어요.막히면: 제목 줄이 한 칸에 몰려 들어가면, 붙여 넣은 뒤 나오는 작은 아이콘에서 '열로 분할'을 눌러요.
  3. 조회를 대신 해 줄 작은 프로그램을 AI에게 받아요. 아래 부탁문을 '09 자동화·연결' 채팅에 보내요. 브이월드는 기능별로 데이터 이름이 달라요. 그래서 AI에게 브이월드 API 레퍼런스(사용 설명서)를 확인해 맞추라고 부탁문에 적어 두었어요. 받은 코드는 대장 → 확장 프로그램 → Apps Script에 붙여 넣고 저장해요. 인증키는 톱니바퀴(프로젝트 설정) → 스크립트 속성 추가에서 VWORLD_KEY로 넣어요. 시트를 새로 고치면 위쪽에 '대지조회' 메뉴가 생겨요.막히면: '권한 검토' 창이 뜨면 내 계정 → 고급 → 이동 → 허용 순서로 눌러요(강의). 메모에 '조회 결과 없음'만 나오면 PNU 자릿수(19자리)와 인증키를 확인하고, 오류 문구를 캡처해 같은 채팅에 보여 줘요.
  4. 연속지적도 데이터를 GeoJSON(지도용 파일 형식)으로 받으면 구글 어스나 QGIS에서 열 수 있어요. 시트 메뉴 대지조회 → 필지 경계 저장을 누르면 드라이브에 저장돼요. CAD로 가져갈 때는 좌표계를 꼭 확인해요. 이 파일은 측량 성과를 대신하지 못해요.
  5. 토지정보 탭 한 줄을 대지 검토 메모 부탁문(강의)에 함께 줘요. 그러면 PDF 없이도 첫 메모가 나와요. 다만 행위제한·지구단위계획은 여전히 토지이음 열람으로 확인해요.

제목 줄은 '토지정보' 탭 A1 칸에, 부탁문은 '09 자동화·연결' 채팅에 그대로 복사해 붙여 넣으세요. 고칠 곳은 없어요.
